PETSA: Parameter-Efficient Test-Time Adaptation for Time Series Forecasting

arxiv 2506.23424 · arXiv 2026 · link · Appears in: Signal/Time Series, Test-Time Training

What

A parameter-efficient test-time adaptation method for time-series foundation models. When the test distribution diverges from training, PETSA updates only small calibration modules — low-rank adapters plus dynamic gating mechanisms — rather than the full model. It uses a three-part specialized loss: a robust reconstruction term that tolerates outliers, a frequency-domain term that preserves spectral structure, and a patch-wise structural term that maintains local temporal patterns. The method achieves competitive forecasting accuracy with significantly fewer updated parameters than full-model test-time adaptation baselines.

Why

Time-series foundation models (PatchTST, Sundial, Chronos) are pretrained on broad data distributions but degrade when deployed on out-of-distribution signals. Full-model test-time adaptation is computationally expensive and risks catastrophic adaptation on small test batches. Parameter-efficient adaptation that updates only a small fraction of the model is essential for on-device deployment where compute is limited and data is non-stationary.

How

PETSA inserts low-rank adapter modules at each transformer layer of the frozen foundation model. A dynamic gating mechanism determines how much each adapter contributes, allowing the model to selectively adapt different layers based on the nature of the distribution shift. At test time, only the adapter weights and gating parameters are updated using the three-part loss. The robust reconstruction term uses a Huber-like loss that reduces sensitivity to outlier time points. The frequency-domain term computes the spectral divergence between the model's predicted spectrum and the observed test spectrum, catching distribution shifts that manifest as frequency changes (e.g., heart rate variability changes, seasonal pattern shifts). The patch-wise structural term enforces local temporal consistency within each patch, complementing the global frequency-domain term.

Solves vs predecessors

PatchTST and Sundial assume a fixed data distribution between training and deployment. TTT for Abstract Reasoning demonstrated test-time adaptation but updated the full model, which is expensive and risky on small test batches. PETSA solves both problems: it adapts to distribution shift (unlike frozen foundation models) while updating only a small parameter subset (unlike full-model TTT).

Method vs predecessors

The key departures are the low-rank adapter architecture for test-time adaptation and the three-part loss function. TTT methods typically use a single self-supervised loss (usually reconstruction); PETSA adds frequency-domain and patch-structural terms that are specific to time-series data. The dynamic gating is also novel — it allows different layers to adapt at different rates, which is important because distribution shifts in time-series data affect low-level features (signal amplitude, noise floor) and high-level features (seasonal patterns, trend components) differently.
