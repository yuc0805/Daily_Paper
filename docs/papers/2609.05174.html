SMILE: Self-Explainable Multimodal Information Bottleneck for Medical Diagnosis

Yang, Schmatz, Ma, Choi, Jenssen, Yu · arXiv 2026-09-04 · arXiv:2609.05174 · Appears in: LLM-Health

What

SMILE formulates self-explainable multimodal medical diagnosis inside the information bottleneck framework and optimises predictive performance and modality-specific explanation jointly, in a single learning paradigm, rather than attaching an explanation after training. The model identifies the most informative elements inside each modality that contribute to the diagnostic decision, so the explanation is reported per modality instead of as one attribution map over a fused representation. Optimisation uses a matrix-based Renyi alpha-order entropy functional to keep the bottleneck term tractable and stable, under the stated assumption that the encoders are sufficiently expressive.

Why

Explainability is treated as a requirement rather than a feature in safety-critical clinical decision-making, but most explainability methods in healthcare are post-hoc and were designed for a single modality. Diagnostic settings are increasingly multimodal, and the two limitations compound: a post-hoc attribution computed over a fused representation cannot report which modality carried the decision, which is the question a clinician asks first when the prediction disagrees with their own reading. Prior interpretable-by-design work either fixes an explanation vocabulary in advance, which does not transfer across modalities, or is restricted to a single input type.

How

The information bottleneck objective compresses the representation of each modality against the label, so the elements that survive compression are by construction the ones the model used. Making this per modality rather than over the fusion is what produces modality-specific explanation. The difficulty is that the bottleneck term is an entropy quantity that is normally intractable and estimated with a variational bound, which is where instability enters; the matrix-based Renyi alpha-order entropy functional is used instead, computed directly from the representation Gram matrix, which removes the variational approximation. Prediction and explanation share one objective, so there is no separate explanation module to train or calibrate.

Solves vs predecessors

UNI produced a strong single-modality representation and left interpretation to whatever attribution method is attached afterwards, which fails in the multimodal case because the attribution is computed over the fused vector and cannot be decomposed back to the inputs that produced it. Concept Bottleneck Models put the explanation inside the model but require a predefined concept vocabulary, so the explanation is only as good as the concept set and the set has to be rebuilt for every new modality. SHAP is always available because it is model-agnostic, and always approximate for the same reason. The specific failure SMILE fixes is that none of these can answer which modality carried the decision, which is the failure that matters when the modalities disagree.

Method vs predecessors

Compared to UNI, the change is in the objective rather than the encoder: the encoder is assumed expressive and the contribution is what is optimised on top of it. Compared to Concept Bottleneck Models, the bottleneck is information-theoretic rather than semantic, so no concept vocabulary is needed and the method transfers across modalities without curation, at the cost that the explanation is a set of informative input elements rather than named concepts. Compared to SHAP, model-agnosticism is given up in exchange for an explanation the optimisation actually enforced during training. The entropy estimator is the enabling detail, since the same formulation with a variational bound is what made earlier multimodal information bottleneck work unstable.
