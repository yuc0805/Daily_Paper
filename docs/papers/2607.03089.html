STELLA: Efficient Sensor-to-LLM Translation for On-Device Human Activity Recognition

Bao et al. · arXiv 2026 · link · Appears in: Signal/Time Series

What

STELLA runs human activity recognition by translating raw wearable sensor streams into compact, activity-aware tokens that a frozen large language model then reads. A light hierarchical tokenizer does the translation, and a local personalization step adapts the system to one user on the device. The design keeps the language model frozen so that recognition can run in real time on a phone or watch without shipping private data off the device.

Why

Earlier language-model approaches to activity recognition either fed sensor data through long text prompts or fine-tuned large backbones, both of which are too heavy for edge hardware and both of which risk moving private physiological data to a server. Prior sensor-to-text systems produced good descriptions but relied on trainable backbones that do not fit an edge compute budget. The problem STELLA sets up is to keep the language model's reasoning while cutting the cost enough to run on-device.

How

STELLA reframes the task as sensor tokenization: a hierarchical tokenizer turns multi-scale sensor windows into activity-aware tokens, which are passed to a frozen language model, and a per-user personalization layer adapts the tokenizer locally. Only the tokenizer and personalization layer are learned, so the language model's weights never change. The paper reports that this produces stronger sensor representations than generic time-series tokenizers and stays practical for real-time on-device use.

  • SSL for HAR (Yuan 2024)Self-supervised sensor encoders on 700K person-days; STELLA feeds a frozen LLM instead of fine-tuning an encoder.
  • LLMs are Few-Shot Health Learners (Liu 2023)Showed a general language model can read physiological signals with few examples; STELLA makes that practical on-device.

Solves vs predecessors

Sensor2Text produced language from sensors with heavy trainable backbones that do not fit an edge device. STELLA fixes that by freezing the language model and learning only a small hierarchical tokenizer plus a personalization layer, which cuts compute and memory enough for real-time on-device recognition while keeping user data local. It also produces stronger sensor tokens than generic time-series tokenizers, which was the failure mode of naive prompting.

Method vs predecessors

Where SSL for HAR pretrained an encoder to be fine-tuned downstream, STELLA never fine-tunes the language model and instead treats the whole problem as learning activity-aware tokens for a frozen reader. This extends the Sensor2Text to LLMs-Few-Shot-Health bridge already in the library, pushing the sensor-to-language line toward a cost budget a watch can meet rather than toward larger models.
