From Pixels to States: Rethinking Interactive World Models as Game Engines

Li, Meng, Shi, Zhai, Tan, Li, Zhang · arXiv 2026 · link · Appears in: World Model / RL

What

This paper reviews interactive world models through the lens of a conventional game engine, which runs a recurrent action-state-observation loop: player actions update an explicit game state by fixed rules, and observations are rendered from that state. It organizes existing methods along four axes (player action control, game state dynamics, state-observation persistence, and real-time generation) and discusses the trade-offs of each family. It also releases a data engine for Black Myth: Wukong with over 90 hours of gameplay carrying frame-aligned actions, ground-truth states, and observations.

Why

Video generative models can predict future frames from user actions and are increasingly viewed as next-generation game engines, but a real interactive world needs outcomes that follow rules over evolving conditions, consequences that persist over long horizons, and a loop that runs in real time. Models that predict pixels directly tend to drift and forget, because they carry no explicit state. The field lacked both a clear organizing framework and a dataset with ground-truth states to train and measure against.

How

The paper takes the game engine's action-state-observation loop as an organizing lens and, for each of the four dimensions, states the capability an interactive world needs, groups existing approaches into families, and weighs their strengths and costs. It complements this with a scalable data engine that records Black Myth: Wukong gameplay, aligning each frame with the player action, the ground-truth game state, and the visual observation, plus structured and semantic annotations, so models can be trained toward explicit, persistent state rather than pixel reconstruction alone.

Builds on

  • World Models (Ha & Schmidhuber 2018)Introduced a compact latent recurrent state predicting future observations; this paper argues that state should be explicit and rule-following.
  • Navigation World ModelsApplied learned world models to action-conditioned navigation.
  • Offline Reinforcement Learning (Levine 2020)Learning policies from logged interaction, relevant to the released gameplay dataset.

Solves vs predecessors

The original World Models keep an implicit latent state, and recent generative world models predict pixels directly; neither maintains an explicit rule-following state, so long-horizon consequences are not guaranteed to persist. This paper reframes the target as the game engine's explicit state loop and supplies a dataset with ground-truth states, so persistence can be trained and measured rather than hoped for.

Method vs predecessors

Where prior world models compress dynamics into a learned latent or into a pixel predictor, this work treats the explicit game state as the object to model and evaluate, and it frames the whole space along four engine-inspired axes. The contribution is an organizing framework plus a state-annotated dataset, not a single new architecture.
