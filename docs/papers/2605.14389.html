Nexus: An Agentic Framework for Time Series Forecasting

Das, Goyal, Parmar, Peng, Tirumalashetty, Li, Zhang, Yoon, Pfister · 2026 · arXiv:2605.14389 · Appears in: Signal (Time Series)

What

A multi-agent framework that decomposes time series forecasting into specialized stages: isolating macro-level temporal fluctuations (trend, seasonality), micro-level residual patterns, and integrating contextual information from unstructured text. A synthesis agent combines outputs into a final forecast with explicit reasoning traces.

Why

Time series foundation models handle numerical patterns well but ignore real-world textual context (news, events, domain knowledge). LLMs can do zero-shot forecasting but perform unevenly because monolithic prompting conflates numerical extrapolation with contextual reasoning. The LLM TS Survey (Zhang 2024) identified this gap but no prior system cleanly separated these reasoning stages.

How

Nexus assigns each forecasting sub-problem to a dedicated agent: one for trend and seasonality decomposition, one for micro-level residual modeling, and one for contextual grounding from text. A synthesis agent merges these outputs without relying on external statistical anchors. Evaluation uses data strictly after LLM knowledge cutoffs (Zillow real estate, stock equities) to prevent data contamination.

Solves vs predecessors

ChatTS and TS-Agent both used a single model or agent to handle all reasoning about time series, which conflates trend extraction, residual modeling, and contextual grounding into one pass. This leads to uneven performance when the context changes (e.g., event-driven volatility). Nexus fixes this by giving each reasoning type its own specialized agent, so the trend agent is not distracted by news interpretation and vice versa.

Method vs predecessors

Where ChatTS trained a unified representation that maps TS tokens into the LLM vocabulary and TS-Agent used tool-calling to let one LLM interact with statistical functions, Nexus uses no shared representation or tools. Instead, it routes the problem through a pipeline of independent agents that each produce intermediate outputs. This is closer to ADaPT-style task decomposition from the agent literature than to the TS-specific approaches of its predecessors.
