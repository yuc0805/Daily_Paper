Nexus: An Agentic Framework for Time Series Forecasting

Das, Goyal, Parmar, Peng, Tirumalashetty, Li, Zhang, Yoon, Pfister · arXiv 2026 · link · Appears in: Signal/Time Series, Agent

What

Nexus is a multi-agent forecasting framework that decomposes time series prediction into specialized stages: isolating macro-level and micro-level temporal fluctuations, integrating contextual information (news, events), and synthesizing a final forecast. It shows that LLMs have stronger intrinsic forecasting ability than previously recognized when reasoning is properly organized.

Why

Time Series Foundation Models (TSFMs) handle numerical patterns well but ignore real-world textual signals. LLMs can incorporate context but their forecasting performance is uneven when given monolithic prompts. Prior work either adapted LLMs with fine-tuning (ChatTS) or used LLMs as controllers over statistical tools (TS-Agent), but neither fully exploited the LLM's own numerical reasoning through structured decomposition.

How

Nexus uses a multi-agent pipeline where each agent handles a specific reasoning subtask: one isolates seasonal/macro patterns, another handles micro-level volatility, and a third integrates available contextual information. A synthesis agent combines the outputs. No fine-tuning is needed; the decomposition is achieved through prompt design. Evaluation uses data strictly after LLM knowledge cutoffs (Zillow real estate, stock equities) to ensure genuine forecasting rather than memorization.

Builds on

  • TS-Agent (Liu 2025)LLM as controller over tools; Nexus uses LLM as forecaster via decomposition.
  • ChatTS (Xie 2025)Fine-tuned LLM for TS alignment; Nexus achieves this zero-shot via multi-agent prompting.
  • ADaPT (Prasad 2023)Task decomposition for planning; Nexus applies the same principle to forecasting.

Solves vs predecessors

TS-Agent relies on the LLM only for tool selection, deferring numerical computation to external statistical methods. This limits the LLM's contribution to orchestration. Nexus shows the LLM itself can perform competitive numerical forecasting when the reasoning is decomposed, removing the dependency on external statistical tools. ChatTS requires fine-tuning to align time series tokens with language; Nexus achieves comparable or better results with no training at all.

Method vs predecessors

Where TS-Agent uses a single LLM agent that selects tools from a predefined toolkit, Nexus uses multiple specialized agents that each handle a different temporal scale or information type. Where ChatTS modifies the LLM's input representation to accept time series tokens, Nexus feeds time series as text (numbers in prompts) and relies on decomposition to manage complexity. The multi-agent design is borrowed from the general agent literature (ADaPT) but adapted specifically for the temporal decomposition structure of forecasting.
