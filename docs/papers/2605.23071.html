The Efficiency Frontier: A Unified Framework for Cost-Performance Optimization in LLM Context Management

arXiv 2026-05 · arXiv:2605.23071 · Appears in: LLM

What

This paper frames LLM context management as a single cost-performance optimization problem and proposes "The Efficiency Frontier," a unified way to reason about the trade-off. Instead of ad hoc rules such as truncation, summarization, or caching, a system can choose a context strategy on the frontier rather than by guesswork.

Why

Long-context processing raises both compute and dollar cost, and teams usually manage it with disconnected heuristics that are hard to compare. There has been no common way to state the trade-off between how much context is kept and how much accuracy it buys, so decisions are made per system without a shared frame. The paper's motivation is to give that shared frame.

How

The framework treats context cost as an explicit budget and accuracy as the objective, then characterizes the set of strategies that are not dominated (the efficiency frontier). A system can then select a point on the frontier matched to its cost ceiling, rather than applying a fixed truncation or summarization rule everywhere.

Builds on

  • Attention Is All You Need (Vaswani 2017)Introduced self-attention, whose cost grows with the square of context length — the cost this framework manages.

Solves vs predecessors

The Transformer (Vaswani 2017) pays attention cost quadratic in context length, and existing practice fights that cost with one-off rules. This work fixes the lack of a common decision rule: it makes the cost an explicit budget optimized against accuracy, so context strategies can be compared on a single frontier instead of being chosen ad hoc.

Method vs predecessors

Where the Transformer pays attention cost mechanically and prior context-saving methods cut cost without a shared objective, this paper approaches long-context cost from the systems side as an optimization problem. It complements modeling-side methods such as MemReread (2605.10268), which reduce cost through linear streaming plus selective rereading rather than through context selection.
