TS-Haystack: A Multi-Scale Retrieval Benchmark for Time Series Language Models

TS-Haystack authors · arXiv 2026 · arXiv:2602.14200 · Appears in: Signal/Time Series

What

TS-Haystack is a benchmark that tests whether a time-series language model can locate a specific pattern inside a long signal. It poses retrieval at several scales, from a short local motif to a long-range trend, so a model cannot pass by attending only to a small window. This summary is based on the paper abstract; the full text was not retrievable at digest time.

Why

Existing evaluations of time-series LLMs mostly use short clips and reward pattern recognition, not long-context search. That leaves a gap: for long recordings with rare events, the property that matters is whether the model can find the right segment at all. TS-Haystack isolates that skill.

How

The benchmark places a target pattern (the "needle") at controlled positions inside long series (the "haystack") and varies the scale of the target, then measures whether the model retrieves it. It reports performance as a function of context length and target scale, in the style of needle-in-a-haystack tests used for text models.

Builds on

  • ChatTS (Xie 2025)Built a time-series-aware LLM; TS-Haystack measures whether such models can retrieve over long context.
  • TS-Agent (Liu 2025)Reasons over a series via operator calls; the benchmark tests the retrieval such agents depend on.
  • LLMs for Time Series: A Survey (Zhang 2024)Flagged evaluation gaps that this benchmark targets.

Solves vs predecessors

Prior time-series LLM benchmarks reward short-window pattern recognition and do not separate retrieval from reasoning. TS-Haystack fixes that by forcing the model to find a target whose position and scale are controlled, so a high score cannot come from attending to a single short clip. It measures the long-context retrieval failure mode that the survey named but earlier benchmarks did not test.

Method vs predecessors

Where ChatTS and TS-Agent contribute models, TS-Haystack contributes measurement. It adapts the text-domain needle-in-a-haystack protocol to time series and adds a multi-scale axis, so the benchmark probes both where the target sits and how large it is, rather than testing a single fixed window.
