Code-Based Message Authentication with Statistical Guarantees via Coordinate Selection and Masking

Hsuan-Po Liu, Hessam Mahdavifar · 2026 · Explore · arXiv:2611.31178

Why recommended

Picked for exploration — from another field, outside your usual research areas.

Abstract

We study message authentication over a public channel against a computationally unbounded adversary. Motivated by low-complexity applications, we consider schemes that leverage off-the-shelf binary linear codes already used for error correction in communication systems. Existing code-based constructions derive an authentication tag primarily from a single symbol in a $q$-ary code, which limits the tag length. However, selecting several binary coordinates allows a fixed binary linear code to support different tag lengths. We characterize how coordinate selection and ordering affect the statistical guarantees against impersonation and substitution attacks. In particular, we explore three methods: the subset selector, the ordered selector, and the independent selector. They read uniformly chosen coordinates in a fixed public or a secret random order, or with replacement, and add a uniform mask. With a fresh key per message, all three achieve the optimal impersonation probability $2^{-l_t}$ for $l_t$-bit tags. We bound the subset selector's substitution probability using only nonzero weights. Those of the other two depend only on the code length $n$, $l_t$, and the nonzero weight farthest from $n/2$. The independent selector achieves $2^{-l_t}$ for substitution when all nonzero weights equal $n/2$. Finally, we evaluate first-order Reed-Muller and Bose-Chaudhuri-Hocquenghem dual subcodes.
