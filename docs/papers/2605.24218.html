QUEST: Training Frontier Deep Research Agents with Fully Synthetic Tasks

Xie, Lin, Wang, Su, Sun et al. · arXiv 2026 · link · Appears in: Agent

What

QUEST is an open family of deep research agents, from 2B to 35B parameters, built for long-horizon search: fact seeking, citation grounding, and report synthesis. Using only 8K synthesized tasks, it approaches or surpasses closed-source agents across eight deep-research benchmarks and is the best open-weight agent reported. Models, data, and training scripts are released.

Why

Frontier deep research systems are proprietary, and existing open agents generalize poorly across task types, so it is unclear how to train a broadly capable research agent. A central obstacle is data: long-horizon search trajectories with reliable rewards are hard to collect and annotate, which limits both supervised and reinforcement learning.

How

The recipe combines mid-training, supervised fine-tuning, and reinforcement learning. The key component is a data-synthesis pipeline built on unified rubric trees, which generate tasks across different types with verifiable rewards and no human labels. A built-in context-management mechanism supports long-horizon reasoning and knowledge synthesis across many search steps.

Builds on

  • Agent AI Survey (Durante 2024)Mapped multimodal agent capabilities that QUEST instantiates for research search.
  • Memory Mechanisms Survey (Huang 2026)Framed memory and context handling for foundation agents, which QUEST addresses with built-in context management.
  • DeepSeek-V3 (2024)RL post-training at model scale; QUEST reuses RL but on synthetic verifiable tasks.

Solves vs predecessors

The surveys describe what agents should do but do not provide training data; DeepSeek-V3 showed RL post-training but for general capability, not long-horizon search. QUEST fixes the missing-data failure mode with rubric-tree synthesis, which produces checkable rewards across task types so the agent can be trained end to end without hand-labeled trajectories.

Method vs predecessors

Earlier agent work relied on human-curated tasks or imitation of proprietary systems. QUEST replaces that with synthetic tasks carrying verifiable rewards, then trains with a staged mid-training, fine-tuning, and RL pipeline. The context-management mechanism is built into the model rather than bolted on as an external retriever, which is what lets it sustain long search horizons at modest task counts (8K).
