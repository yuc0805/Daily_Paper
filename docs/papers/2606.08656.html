From Player to Master: Enhancing Test-Time Learning of LLM Agents via Reinforcement Learning over Memory

Cai, Guo, Huang, Du, Tang, Sun et al. · arXiv 2026-06-07 · ICML 2026 · arXiv:2606.08656 · Appears in: Agent

What

The paper introduces MemoPilot, a plug-in memory copilot that learns how to update an LLM agent's explicit memory so a frozen base model improves over a long run of interactions. Memory updating is framed as a multi-turn decision problem and trained end-to-end with multi-turn GRPO, using a turn-wise reward and a context-independent, turn-level advantage estimate for finer credit assignment. On two repeated-game testbeds, Rock-Paper-Scissors and Limit Texas Hold'em, MemoPilot ranks first in Elo (1762 on Hold'em, 1590 on RPS) and beats hand-designed memory rules and proprietary models including DeepSeek-V3.2.

Why

LLM agents are increasingly run in long-lived settings where they should improve from experience at test time. The common fix is to keep an explicit memory and update it after each interaction, but most methods update memory using hand-written prompting rules. Hand-written rules are hard to align with a downstream objective over many steps, so the memory may not store what actually helps later decisions.

How

MemoPilot treats the memory-update process as a learned policy rather than a fixed rule. It formulates updating as a multi-turn decision problem and optimizes it with multi-turn GRPO. Two training choices support this: a turn-wise reward so feedback is attached to individual turns, and a context-independent, turn-level advantage estimate computed across rollouts, which gives finer credit assignment and more stable training over multi-step horizons. The base LLM stays frozen; only the memory-update policy is trained.

Solves vs predecessors

The memory survey (Huang 2026) described update mechanisms that depend on hand-designed prompting rules, which cannot be tuned to a long-horizon objective. MemoPilot fixes that specific limitation by making the update an RL action optimized for downstream reward, so the agent learns what is worth writing to memory instead of following a fixed heuristic.

Method vs predecessors

DeepSeek-R1 (2025) applied GRPO to a single reasoning trace. MemoPilot extends GRPO to a multi-turn setting and adds turn-level credit assignment so the reward attaches to the right memory edit rather than to a whole rollout. This paper also extends the DeepSeek-R1 to Chain-of-Thought bridge already in your library: it moves reasoning-via-RL from one-shot reasoning to long-horizon control of an external memory.
