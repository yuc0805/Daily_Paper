MemoPilot: Enhancing Test-Time Learning of LLM Agents via Reinforcement Learning over Memory

Authors (see paper) · arXiv 2026 · arXiv:2606.08656 · Appears in: Agent

What

MemoPilot is a plug-in memory copilot that trains the memory-update process of a frozen LLM agent using multi-turn GRPO. It formulates memory updating as a sequential decision problem and optimizes it end-to-end, introducing turn-wise reward signals and context-independent advantage estimation for stable multi-turn training.

Why

LLM agents deployed in long-running settings need to improve through experience, typically by maintaining explicit memory. Most existing methods use hand-designed prompting rules for memory updates, making it difficult to align the updates with downstream objectives over multi-step horizons. There is no principled way to train the memory-update process itself.

How

MemoPilot separates the "player" (frozen base LLM) from the "copilot" (trainable memory-update policy). After each interaction turn, the copilot observes the outcome and decides how to modify the memory state. This is optimized via multi-turn GRPO with turn-level advantage estimation computed independently across rollouts for finer-grained credit assignment. The copilot is trained on sequential game-playing tasks and evaluated on Elo ratings against baselines.

Solves vs predecessors

The Memory Mechanisms survey (Huang 2026) identified a gap between hand-designed memory prompts and optimal memory policies. MemoPilot fills that gap by making the memory-update process trainable with RL. Where LATS searches over action trajectories at inference time, MemoPilot trains a separate policy that improves memory between turns, keeping the base LLM frozen and the approach modular.

Method vs predecessors

Compared to LATS, which uses Monte Carlo tree search over action sequences, MemoPilot uses GRPO over memory updates — a fundamentally different optimization target. Compared to hand-crafted memory prompts used in most agent systems, MemoPilot learns the update rule from data. The turn-wise reward signal and context-independent advantage estimation are the main technical novelties over standard GRPO, adapted for the multi-turn memory-update setting.
