Olivia: Harmonizing Time Series Foundation Models with Power Spectral Density

Fei, Yi, Wang, Wen, Zhu, Fan · ICML 2026 · arXiv:2605.17340 · Appears in: Signal/Time Series

What

Olivia is a time series foundation model that uses spectral harmonization to handle heterogeneous temporal patterns across pretraining domains. A Harmonizer module reshapes the power spectral density of different datasets into a shared spectral space, and a HarmonicAttention mechanism performs self-attention in a low-dimensional resonator-based interaction space.

Why

Time series foundation models pretrain over diverse datasets, but these datasets have very different spectral characteristics (e.g., financial data is dominated by low frequencies, while sensor data has strong high-frequency components). This spectral mismatch can hurt pretraining effectiveness and reduce transferability. Prior foundation models (Chronos, Sundial, PatchTST) do not explicitly address this heterogeneity.

How

The Harmonizer module computes the normalized PSD of each input batch and applies a learned spectral reshaping to align it with a target spectral profile. The theoretical analysis shows this corresponds to reparameterizing second-order temporal correlations across datasets. Token interactions under this harmonization can be mediated by a compact set of resonators, which motivates the HarmonicAttention design: self-attention is performed in a low-dimensional space defined by these resonators, reducing computation while preserving cross-domain transferability. SOTA results on TSLib, GIFT-Eval, and 6 GluonTS datasets across zero-shot, few-shot, and full-shot settings.

Builds on

  • Sundial (Liu 2025)TS foundation model using flow-matching; Olivia addresses a different bottleneck (spectral heterogeneity).
  • Chronos (Ansari 2024)Pretrained probabilistic TS model via tokenization; Olivia adds spectral normalization before processing.
  • PatchTST (Nie 2023)Established patching for TS transformers; Olivia adds PSD harmonization on top of patch-based input.

Solves vs predecessors

Prior TS foundation models assume that a single transformer can learn from spectrally heterogeneous datasets without explicit normalization. This assumption fails when pretraining mixes domains with very different frequency characteristics. Olivia fixes this by harmonizing PSDs before attention, ensuring that the model sees a more uniform spectral landscape during training.

Method vs predecessors

Compared to Sundial's flow-matching approach and Chronos's quantization, Olivia's key novelty is in the preprocessing: the Harmonizer is a learned spectral reshaping module that operates before the transformer sees the data. The HarmonicAttention mechanism is a structural change to attention itself, performing it in a resonator-defined subspace. This is different from PatchTST's channel-independent patching and TimesNet's 2D period-based reshaping.
