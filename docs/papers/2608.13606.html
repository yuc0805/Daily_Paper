MobileMem: Learning from a Year of Mobile Experiences

Deng, Xue, Ru, Xu, Qiao, Wang, et al. · arXiv 2026-08-11 · arXiv:2608.13606 · Appears in: Agent, Signal/Time Series

What

MobileMem is a benchmark and framework for on-device long-term memory in personal assistant agents, grounded in a year-scale collection of mobile experiences. A knowledge-grounded synthesis pipeline turns raw user-app sessions into coherent, temporally consistent long-horizon trajectories. The benchmark offers text-only and multimodal settings and tests multi-hop and temporal reasoning, knowledge updating when facts about the user change, and inference of preferences the user never stated explicitly.

Why

Agent memory research has been evaluated on conversation-length histories, where retrieval over a few thousand tokens is enough. Real personal assistants accumulate heterogeneous, multimodal, evolving records over months, and the hard cases are stale facts that must be revised and preferences that are only implicit. GLOBEM showed that year-scale longitudinal collection is feasible for behaviour prediction, and MindScape showed sensing can condition an LLM, but neither framed the problem as memory, and the memory literature had no benchmark at that time span.

How

The pipeline synthesises long-horizon trajectories from real user-app sessions, using knowledge grounding to keep facts consistent across the year and to introduce controlled updates where a fact legitimately changes. Tasks are then generated over these trajectories in four families: multi-hop retrieval, temporal reasoning, knowledge updating, and implicit preference inference. Both a text-only and a multimodal variant are provided, so a system can be scored on whether it remembers the past, understands the present state, and adapts as the user changes.

Builds on

  • Memory Mechanisms of Foundation Agents (Huang 2026)Surveyed agent memory mechanisms and flagged the absence of long-horizon evaluation; MobileMem supplies that evaluation.
  • GLOBEM (Xu 2023)Established multi-year longitudinal personal data collection as a workable protocol; MobileMem uses a comparable time span for a memory task rather than a prediction task.
  • MindScape (Nepal 2024)Paired behavioural sensing with an LLM over a fixed window; MobileMem requires state carried across a year and revised over time.

Solves vs predecessors

The memory survey could compare mechanisms only on benchmarks short enough that naive retrieval works, so differences between mechanisms were not separable. MobileMem lengthens the horizon until retrieval alone fails and updating becomes necessary. Against GLOBEM and MindScape, the fix is different: those datasets support prediction from sensing but contain no task that asks whether a system retained and revised what it learned about the person, which is the failure mode a persistent assistant actually has.

Method vs predecessors

Where GLOBEM collected passive sensor streams directly, MobileMem synthesises trajectories from app sessions with a knowledge-grounding step that enforces temporal consistency, trading some ecological realism for controllable ground truth about what the agent should remember. Where MindScape conditions one generation step on a recent sensing window, MobileMem evaluates a full read-write memory loop, and where the Huang survey organised mechanisms conceptually, this work turns the distinctions into scored tasks.
