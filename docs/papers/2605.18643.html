Post-Trained MoE Can Skip Half Experts via Self-Distillation (ZEDA)

Lv et al. (Tsinghua, Shanghai AI Lab, Kuaishou) · arXiv 2026 · paper · Appears in: MoE

What

ZEDA (Zero-Expert Self-Distillation Adaptation) converts an already-trained static Mixture-of-Experts model into a dynamic one that skips up to half its experts on easy inputs. A learnable router decides per-token how many experts to activate, using the original full model as teacher via self-distillation.

Why

Static MoE models activate a fixed number of experts regardless of input difficulty, wasting compute on easy tokens. Existing dynamic MoE approaches require pre-training from scratch or task-specific adaptation, which is impractical for large deployed models. The gap is converting fully trained MoE models to dynamic routing post-hoc.

How

ZEDA adds a lightweight dynamic router on top of the existing static router. The full model serves as its own teacher: the dynamic router learns to predict which experts can be skipped while preserving the teacher's output distribution. Training uses KL-divergence between the dynamic (fewer experts) and static (all experts) outputs. The method requires no changes to the pretrained weights and operates as a post-hoc adaptation stage.

Builds on

  • DeepSeek-V3 (DeepSeek-AI 2024)The static MoE architecture that ZEDA converts to dynamic routing.

Solves vs predecessors

DeepSeek-V3 uses fixed expert activation per token. ZEDA adds input-adaptive expert skipping without retraining the base model, achieving roughly 50% reduction in activated parameters on routine inputs while preserving accuracy on hard inputs that genuinely need all experts.

Method vs predecessors

Where DeepSeek-V3 selects a fixed top-k set of experts per token, ZEDA learns a per-token budget via a lightweight secondary router trained through self-distillation. The key distinction from prior dynamic MoE work is that ZEDA operates entirely post-hoc on already-trained models rather than requiring architectural changes at pre-training time.
