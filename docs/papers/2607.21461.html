AREX: Towards a Recursively Self-Improving Agent for Deep Research

Lu, Li, Luo et al. (BAAI) · arXiv 2026 · link · Appears in: Agent, Reasoning

What

AREX is a family of deep-research agents that use a discovery-verification asymmetry: finding an answer that satisfies many constraints is costly, but checking a candidate splits into cheap constraint-wise tests. The agent alternates an inner loop that gathers evidence and drafts a provisional answer with an outer loop that audits the draft constraint by constraint and launches targeted follow-up research on the unresolved parts. It ships as a dense 4B model and a 122B-A10B mixture-of-experts model and outperforms comparable-scale baselines on BrowseComp, WideSearch, DeepSearchQA, and Humanity's Last Exam.

Why

Deep-research questions require answers that jointly satisfy multiple constraints, and simply searching longer does not reliably find them. Prior agents search harder within a single pass but do not systematically verify intermediate answers or use the verified state to steer the next round of research. AREX is built on the observation that verification is cheaper than discovery, so an agent should spend effort auditing and refining rather than only extending search.

How

The inner loop gathers evidence and constructs a provisional answer; the outer self-improvement loop audits the answer constraint-wise, identifies unresolved claims, and launches targeted follow-up research. To sustain this over long horizons, AREX learns an autonomous context-update tool that compresses growing interaction history into a compact state that keeps verified evidence and open constraints, without an external model. Training uses verified synthetic tasks and high-quality trajectories through agentic mid-training and long-horizon reinforcement learning, with emphasis on key steps where decisive evidence is found or wrong directions are corrected to counter sparse final rewards.

Solves vs predecessors

LATS searches a tree of actions and backtracks within a single pass but has no mechanism to verify an answer and re-plan from the verified remainder. AREX adds that outer loop, so failed constraints trigger targeted research instead of a fresh full search, which fits tasks where checking is cheaper than discovery. It also fixes the long-horizon memory problem that undoes many agents by learning a context-update tool that preserves verified evidence rather than letting history overflow the context window.

Method vs predecessors

Where ToolkenGPT learned to call external tools, AREX learns a tool that manages its own memory, compressing interaction history into an improvement state with no external model. Where the Agent AI Survey described a single perceive-plan-act loop, AREX nests two loops and trains the whole system with long-horizon reinforcement learning that rewards decisive intermediate steps. The result extends the planning-decomposition line in the library toward verification-guided refinement.
