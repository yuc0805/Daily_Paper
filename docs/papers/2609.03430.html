Random Attention: Rethinking KV Cache Eviction for Efficient Reasoning

Wang, Qiu, Zhao, Qian, Yang, Han, Ji, Savarese, Heinecke, Wang (Salesforce AI Research) · arXiv 2026-09-03 · arXiv:2609.03430 · Appears in: LLM

What

Random Attention is a KV cache eviction rule that computes no score at all: it keeps the prompt and evicts uniformly at random within each attention head. Across four models and six reasoning tasks it matches the strongest prior evictor, and it serves 32 to 43 percent higher throughput than that evictor in vLLM deployment because it skips the scoring pass. Two controlled experiments supply the explanation rather than leaving the result as a curiosity.

Why

Long chains of thought make the KV cache a memory bottleneck, and every published compression method addresses this the same way: score each cached token by an estimate of how much it will matter later, keep the top-scoring ones. The methods differ in the estimator and are compared against each other on downstream accuracy. That comparison never included a no-score control, so the field had no measurement of how much the selection signal itself contributes. Without that control, improvements attributed to better scoring could have come from any correlated property of the rule.

How

The rule is uniform random eviction within each head, with the prompt exempt. The two supporting experiments isolate why it works. First, the prompt is shown to be the fragile part of the cache, and most of the measured gap between competing scorers reduces to whether their signal happened to retain it. Second, the reasoning trace is shown to be redundant at two levels: in the text, because the model restates what it still needs as it works, and across attention heads, because each head keeps its own copy of the trace. Once the prompt is protected, a random draw therefore retains enough copies of whatever the model still needs.

Solves vs predecessors

The failure mode this paper fixes is not a performance failure but a measurement failure in the eviction literature. By supplying the missing no-score control, it reassigns credit for a family of reported gains to a single confound, prompt retention, and shows that the elaborate part of each method was carrying almost none of the effect. The practical consequence is that the scoring pass, which costs latency at every decode step, can be deleted outright for 32 to 43 percent more throughput.

Method vs predecessors

Where DeepSeek-V2 reduces the per-token cost of the cache with a learned low-rank latent, Random Attention reduces the token count with no learning and no per-token computation. The deeper difference is in what each method assumes about the data. Latent compression assumes the cache content is dense and must be preserved in compressed form; Random Attention measures that the content of an RL-trained reasoning trace is duplicated across text positions and across heads, so preservation of specific tokens is unnecessary. That property is specific to traces of the kind DeepSeek-R1 introduced, which is why the result was not available earlier.
