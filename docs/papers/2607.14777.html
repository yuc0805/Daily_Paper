SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning

Wu, Yang, Lu et al. · arXiv 2026 · arXiv:2607.14777 · Appears in: Agent

What

SEED trains an LLM to act as a long-horizon agent for multi-turn, tool-using tasks. It keeps outcome-based reinforcement learning but adds a self-distillation loop. One policy checkpoint acts in the environment and collects its own on-policy trajectories; the same model then reads back its completed trajectories and writes short natural-language skills that capture a reusable workflow, a decisive observation, or a rule for avoiding a past failure; finally it distills the skill-induced change in action probabilities back into the plain policy. Teacher and student are the same evolving checkpoint, so the loop improves itself without a fixed stronger teacher.

Why

Outcome-based reinforcement learning gives an agent one reward at the end of a trajectory. That single trajectory-level signal says nothing about which intermediate decisions were good, leaving a supervision gap between the episode-level outcome and the token-level updates the policy needs. Prior agentic RL either lives with this sparse signal or relies on a separate stronger model to supply denser feedback, which is costly and does not adapt as the policy itself improves.

How

The method runs a three-stage self-evolving cycle. The policy first collects on-policy trajectories in the environment. It is then fine-tuned to analyze its own completed trajectories and produce natural-language skills describing what worked or what to avoid. The behavioral effect of a skill is measured as the shift it induces in the model's action probabilities, and the ordinary skill-free policy is trained to reproduce that shifted behavior. Repeating the cycle lets the same checkpoint serve as both actor and teacher, turning episode-level outcomes into token-level supervision. Code is released.

Builds on

  • DeepSeek-R1 (2025)Source of outcome-based RL for eliciting capability from a sparse final reward; SEED keeps this reward and adds hindsight distillation.
  • Chain-of-Thought Prompting (Wei 2023)Established intermediate reasoning; SEED persists the useful part of a trajectory into weights rather than regenerating it each run.
  • Memory Mechanisms Survey (Huang 2026)Catalogued agent memory stores; SEED moves memory into policy parameters through self-distillation.

Solves vs predecessors

DeepSeek-R1 showed reasoning can emerge from a sparse trajectory-level reward, but that reward gives no guidance on intermediate agent decisions. SEED fixes that specific failure mode by converting each completed trajectory into an explicit skill and distilling its effect back into the policy, so intermediate decisions receive token-level supervision that outcome-only RL cannot provide.

Method vs predecessors

Compared to Chain-of-Thought, SEED does not leave the useful reasoning as ephemeral text inside one forward pass; it writes it into a reusable skill and folds it into the weights. Compared to the external memory stores catalogued in the Memory Mechanisms Survey, SEED keeps no retrieved buffer at inference; the experience is compiled into the parameters. Compared to distillation that depends on a separate fixed teacher, SEED makes one evolving checkpoint teach itself, so the supervision signal keeps pace with the policy.
