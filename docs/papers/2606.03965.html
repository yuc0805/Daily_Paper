Agentic Chain-of-Thought Steering for Efficient and Controllable LLM Reasoning (ACTS)

Xia, Xie, Xu, Kang, Lamba, Gao, McAuley · arXiv 2026 · link · Appears in: Reasoning

What

ACTS formulates chain-of-thought reasoning control as a Markov decision process. A small controller agent observes the reasoning trace and remaining token budget of a frozen reasoning LLM, then issues a steering action (strategy label + steering phrase) that initiates the next reasoning step. The controller is trained from synthetic steering trajectories with multi-budget augmentation, then refined via RL with budget-conditioned reward shaping.

Why

Extended chain-of-thought reasoning improves LLM accuracy but spends tokens inefficiently and offers no inference-time control. Existing efficiency methods control trace length (shortening, early-stopping, compression) but leave the reasoning strategy implicit. There is no mechanism for a user or system to specify how the model should reason under a given compute budget.

How

The reasoning process is modeled as an MDP where states are partial reasoning traces plus remaining budget, actions are (strategy, steering phrase) pairs, and rewards reflect final-answer correctness penalized by budget overrun. The controller is initialized via supervised learning on synthetic steering trajectories generated by prompting a teacher model with explicit strategy labels. Multi-budget augmentation creates trajectories at varying budget levels. The controller is then optimized with RL using budget-conditioned reward shaping to learn budget-accuracy trade-offs.

Builds on

  • Chain-of-Thought Prompting (Wei 2023)Established that explicit step-by-step reasoning traces improve LLM accuracy on multi-step tasks.
  • DeepSeek-R1 (2025)Showed pure RL (no supervised demonstrations) can train LLMs to produce long reasoning traces with emergent self-verification.

Solves vs predecessors

Wei (2023) introduced chain-of-thought as a static prompting technique with no control over trace length or strategy. DeepSeek-R1 trained the reasoner itself to produce extended traces via RL, but the resulting traces are often unnecessarily long and offer no inference-time budget control. ACTS solves both problems by separating the reasoning controller from the reasoner: the controller dynamically selects strategies and manages budget, while the reasoner generates content without weight modification.

Method vs predecessors

Where prior work either prompted for reasoning (Wei 2023) or trained the reasoner end-to-end (DeepSeek-R1), ACTS introduces a two-model architecture: a frozen reasoner and a learned controller. The MDP formulation is new to this problem — earlier CoT compression methods used fixed rules (truncation, early stopping) rather than learned policies. The budget-conditioned reward shaping is also novel, enabling the controller to learn different strategies for different compute budgets rather than a single compression ratio.
