Compact Latent Manifold Translation: A Parameter-Efficient Foundation Model for Cross-Modal and Cross-Frequency Physiological Signal Synthesis

arXiv 2026-05-13 · arXiv:2605.13248 · Appears in: Signal/Time Series, LLM-Health

What

CLMT is a 0.09B-parameter framework for translating between different physiological signal modalities (ECG, PPG, EEG, EMG, etc.) and across different sampling frequencies. It uses a Universal Tokenizer with Hierarchical Residual Vector Quantization to map heterogeneous biosignals into discrete latent manifolds, then performs cross-modal translation in this shared space.

Why

Collecting certain physiological signals is more invasive or expensive than others (e.g., ECG requires chest electrodes, PPG only needs a wristband). If you can synthesize one modality from another with sufficient fidelity, you can reduce data collection burden. Prior work on physiological signal synthesis is mostly modality-specific and does not handle cross-frequency translation. The Foundation Models for Biosignals survey (Gu 2025) identified cross-modal alignment as an open problem.

How

The Universal Tokenizer uses Hierarchical Residual VQ to encode each signal modality into a shared discrete codebook. The hierarchical structure captures both coarse (global shape) and fine (local morphology) features. Translation between modalities is performed by mapping from one modality's latent codes to another's through a lightweight transformer decoder. Cross-frequency translation is handled by interpolating in the latent space rather than resampling raw signals.

Solves vs predecessors

The Biosignals survey (Gu 2025) identified that existing foundation models for physiological signals are modality-specific: one model for ECG, another for PPG, and so on. Cross-modal translation was listed as an open direction. CLMT directly solves this by providing a single framework that handles multiple modalities and frequencies in a unified latent space.

Method vs predecessors

Compared to SensorLM, which builds large sensor-language models requiring >59M hours of data, CLMT is parameter-efficient at 0.09B and does not need text supervision. The Hierarchical Residual VQ approach is imported from audio/speech codecs (similar to SoundStream and Encodec), adapted here for physiological signals. This is a different design path from Sensor2Text's student-teacher distillation approach.
