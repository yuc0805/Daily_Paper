AutoTrainess: Teaching Language Models to Improve Language Models Autonomously

Yu, Yin, Gao, He, Cai, Zhang · arXiv 2026 · arXiv:2606.31551 · Appears in: Agent

What

AutoTrainess is a language-model agent for autonomous post-training. It exposes the operations of a training pipeline — planning, data preparation, training, evaluation, and logging — as a repository of agent-computer interfaces with explicit workflows, rules, and execution constraints, rather than leaving the agent in a raw command-line environment. On PostTrainBench it scores 26.94 on average with GPT-5.4 (Codex) versus 23.21 for a command-line-only baseline, and it transfers across harnesses, lifting DeepSeek-V4-Flash (OpenCode) from 12.13 to 19.58.

Why

Training a model is still mostly manual even as agents get good at software tasks, because autonomous post-training is more than coding: the agent must plan iterations, build benchmark-aligned data, run stable training jobs, evaluate checkpoints, and keep experiment state across many hours. A raw command line leaves the action space underspecified, so agents drift or fail on these long-horizon runs. The paper externalizes prior human experience so the agent has reliable operations to work with.

How

Each pipeline operation is wrapped as a named interface that constrains what the agent can do and encodes the human workflow for that step. The agent plans over these interfaces instead of free-form shell commands, which keeps long training runs repeatable and preserves state across the interaction. The result is higher and more reliable scores than a command-line-only agent on the same tasks, and the gains hold across different base models and agent harnesses.

Solves vs predecessors

ADaPT decomposed tasks on demand and LATS searched over action trees, but both leave the low-level action space open, which is unreliable for a multi-hour training run where one bad command wastes the run. AutoTrainess fixes that by fixing the action space ahead of time as constrained, named interfaces, so the agent's long-horizon behavior becomes repeatable and its experiment state survives across hours.

Method vs predecessors

Compared to ADaPT and LATS, the technical move is to trade open-ended search for a curated interface layer that encodes human workflow and execution constraints. Compared to ToolkenGPT's atomic tool calls, AutoTrainess operates at the workflow level, chaining planning, data, training, evaluation, and logging into one autonomous loop with preserved state.
