Intern-S2-Mobius: Foundation Model with Decoupled Knowledge and Reasoning

Chen, Ding, Ding, Ge, Gu, Guo, et al. · arXiv 2026-08-14 · arXiv:2608.14290 · Appears in: LLM, MoE

What

Mobius-v0 restructures the transformer into a globally shared Memory block made of feed-forward layers holding knowledge vectors, plus several Reasoner blocks of self-attention that query that memory repeatedly, with hidden states acting as cache and carrier between them. A 7B model trained from scratch matches a 7B transformer baseline using 62.6 percent of the baseline's training data. Intern-S2-Mobius, continually pretrained from Qwen3.5-35B, matches downstream scores with close to a 4x end-to-end inference speedup.

Why

In a standard transformer, attention and feed-forward layers alternate at every depth, so factual storage and compositional computation are entangled throughout the stack. That entanglement means the same fact may be re-encoded at many depths, wasting parameters, and every forward pass must traverse the whole stack, wasting inference time. Sparse mixture-of-experts work such as DeepSeek-V3 and ST-MoE reduced the cost of the feed-forward position but kept the alternating stack, so the entanglement itself was never addressed.

How

Knowledge is consolidated into one shared Memory built from feed-forward layers, and reasoning is carried out by a small number of self-attention Reasoners that issue repeated queries into that memory. Retrieved knowledge vectors are transmitted back to the reasoning operators, and hidden states serve both as the cache for what has been retrieved and as the carrier between reasoning iterations. Because reasoning is iterative over a shared store rather than depth-serial through a fixed stack, the sequential compute path shortens, which is where the reported inference speedup comes from.

Builds on

  • Attention Is All You Need (Vaswani 2017)The interleaved attention plus feed-forward block that Mobius separates into memory and reasoning.
  • DeepSeek-V3 (2024)Showed sparse activation of feed-forward capacity buys efficiency at scale, while keeping the standard layer stack.
  • ST-MoE (Zoph 2022)Established stable sparse expert routing in the feed-forward position, the closest prior attempt to isolate knowledge capacity.

Solves vs predecessors

Sparse expert models reduce the compute cost of storing knowledge but do not stop knowledge from being duplicated across depths, and they do not shorten the sequential path a token must traverse. Mobius targets both: consolidating storage into a shared memory is what produces the data efficiency claim at 7B, and replacing depth-serial computation with iterative queries into that memory is what produces the inference speedup at 35B.

Method vs predecessors

DeepSeek-V3 and ST-MoE keep the alternating attention and feed-forward stack and route within it. Mobius changes the topology, making memory access an explicit repeated read issued by a small set of reasoners rather than a routed forward pass through many layers. Relative to the original transformer, the number of distinct reasoning operators is small and they are reused across iterations, so depth is traded for iteration count.
