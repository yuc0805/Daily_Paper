PerceptionDLM: Parallel Region Perception with Multimodal Diffusion Language Models

ByteDance, Peking University MSALab · arXiv 2026-06 · arXiv:2606.19534 · Appears in: Multi-Modal

What

PerceptionDLM is a multimodal model built on a discrete diffusion language backbone that decodes tokens in parallel rather than autoregressively. On top of a strong diffusion multimodal baseline, it adds prompting and structured attention masking so the model can describe several masked image regions at once, at both the sequence and token level. The result is an inference-efficiency gain over models that handle regions one after another, while keeping competitive perception quality.

Why

Most multimodal language models generate text autoregressively, one token at a time. That is slow when a task asks for captions of many image regions, because each region is processed in sequence. Prior region-perception models inherit this autoregressive bottleneck, so throughput drops as the number of regions grows. The paper sets out to use the parallel-decoding property of diffusion language models to remove that bottleneck.

How

The backbone is a discrete diffusion multimodal model that integrates a pretrained vision encoder with a diffusion language model through visual instruction tuning, and decodes many tokens together rather than left to right. PerceptionDLM adds an efficient prompting scheme and a structured attention mask so that several masked regions are perceived simultaneously, producing region descriptions in parallel. This converts the per-region sequential cost into a single parallel pass.

Solves vs predecessors

DiT applied diffusion to image generation, where the output is pixels. Autoregressive multimodal models apply transformers to perception, where the output is text but produced one token at a time. PerceptionDLM fixes the throughput failure of the autoregressive route by moving the diffusion-with-transformer idea onto the language output, so many regions are described in one parallel pass.

Method vs predecessors

Compared to DiT, the diffusion runs over discrete language tokens for perception rather than over pixels for synthesis. Compared to autoregressive multimodal models, decoding is parallel and guided by structured attention masking that isolates each region, rather than sequential. The contribution is the structured-masking-plus-prompting layer that lets the parallel decoder address several regions at once.
