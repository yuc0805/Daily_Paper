Resolving Action Bottleneck: Agentic Reinforcement Learning Informed by Token-Level Energy

He et al. · arXiv 2026 · link · Appears in: Reasoning

What

ActFocus is a token reweighting method for agentic RL that downweights gradients on reasoning tokens and upweights action tokens. It addresses the "action bottleneck" — the finding that in multi-turn agent trajectories, training signal concentrates on action tokens (a tiny fraction of the sequence) while standard methods like PPO and GRPO treat all tokens equally. ActFocus yields up to 65.2 percentage point success-rate improvements over PPO.

Why

Agentic RL trains LLMs on trajectories that interleave long reasoning traces with short environment-facing actions. Standard policy-gradient methods assign uniform credit across all tokens, which misallocates gradient signal. Prior work on token-level credit assignment in RL for LLMs (e.g., DeepSeek-R1) did not distinguish between reasoning and action tokens or analyze the energy landscape of different token types.

How

The authors analyze agentic RL trajectories from an energy-based modeling perspective, showing that token-level training signals concentrate sharply on action tokens. They then propose ActFocus, which computes token-level energy scores and uses them to reweight the policy gradient, giving action tokens proportionally more gradient signal. The method is a drop-in modification to PPO and GRPO.

Solves vs predecessors

DeepSeek-R1 demonstrated that RL can improve LLM reasoning but used uniform token weighting, which this paper shows wastes most gradient updates on reasoning tokens that carry little learning signal. ActFocus provides a principled fix based on energy-based analysis rather than heuristic approaches to credit assignment.

Method vs predecessors

Where DeepSeek-R1 applies uniform PPO across all tokens in the trajectory, ActFocus uses energy-based token scoring to create a non-uniform weighting. This is conceptually related to advantage-weighted methods in traditional RL but applied at the token level within a language trajectory rather than at the trajectory level.
