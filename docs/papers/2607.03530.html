MentalThink: Shaping Thoughts in Mental SVG World

Lin, Yin, Li, Yu et al. · arXiv 2026 · link · Appears in: Reasoning, Multi-Modal

What

MentalThink equips a multimodal language model with an executable drawing surface for reasoning. The model writes Scalable Vector Graphics (SVG) code as an intermediate step, renders it deterministically into an image, reads that image back, and revises the code across several turns. Training combines supervised fine-tuning for SVG syntax with multi-turn reinforcement learning that rewards inspection and revision of the drawn hypothesis. It reports 55.1% on VSIBench and 76.0% on MindCube.

Why

Multimodal models usually reason about an image by writing text about it. For spatial tasks such as folding, rotation, or path selection, text is a poor scratchpad because the model cannot look at its own intermediate guess and check whether it is geometrically consistent. Prior text-only reasoning methods have no mechanism to render and inspect a hypothesis, so errors in spatial imagination go uncorrected.

How

The method makes the intermediate reasoning object executable. Because a sketch is written as SVG code, it can be rendered exactly and then re-read, which turns each reasoning step into something the model can verify and edit. The two-stage training first teaches valid SVG generation, then uses reinforcement learning to encourage iterative revision: the model draws a spatial hypothesis, inspects the rendered result, and refines it, mimicking human mental imagery within a constrained geometric space.

Solves vs predecessors

Chain-of-Thought and DeepSeek-R1 both reason in text, so a wrong spatial assumption cannot be checked against a picture. MentalThink fixes this failure by producing a re-renderable intermediate: the model can inspect its own drawing and catch geometric errors before committing to an answer, which is why the gains concentrate on perspective-taking and scene-construction tasks.

Method vs predecessors

Where Chain-of-Thought adds a textual intermediate and DeepSeek-R1 adds a reinforcement-learning reward on final answers, MentalThink combines both but changes the medium: the intermediate is executable SVG rather than natural language, and the reinforcement-learning reward targets the quality of visual revision rather than only the final token sequence. This extends the R1-to-Chain-of-Thought bridge (reasoning via reinforcement learning versus via prompting) toward verifiable multimodal reasoning.
