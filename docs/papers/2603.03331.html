PulseLM: A Foundation Dataset and Benchmark for PPG-Text Learning

Pham et al. · arXiv 2026-06 · arXiv:2603.03331 · Appears in: Signal (Time Series)

What

PulseLM is a large-scale dataset and benchmark that pairs raw photoplethysmography (PPG) waveforms with natural-language question-answer items. It aggregates recordings from fifteen public sources, standardizes them into 10-second segments, and harmonizes the labels into twelve common physiological question-answering tasks. The release contains 1.31 million segments and 3.15 million closed-ended question-answer pairs, together with fixed preprocessing and evaluation protocols and baseline PPG-aware language models.

Why

PPG is the signal most wearables already collect, but public PPG datasets supply only numerical measurements or task-specific labels. That form of supervision does not support language-based reasoning over the waveform, so it is hard to train or test a model that answers natural-language questions about a PPG segment. Prior datasets are also fragmented, with mismatched annotations that prevent cross-dataset comparison. PulseLM sets out to give the field one shared dataset and one shared protocol.

How

The authors collect PPG from fifteen sources spanning clinical, laboratory, and in-the-wild settings, resample every record into a standardized 10-second segment, and map the heterogeneous labels onto twelve common question types. Each segment is paired with closed-ended question-answer items, so a model is scored on multiple-choice physiological questions rather than free text. They fix the preprocessing, supervision, and evaluation steps and build baseline models that combine a dedicated PPG encoder with an instruction-tuned language backbone.

Solves vs predecessors

Sensor2Text demonstrated waveform-to-language on a single activity-tracking setting but had no shared scoring protocol, so results could not be compared across datasets. PulseLM fixes that gap: it harmonizes fifteen sources into one closed-ended benchmark with three million pairs, so that a PPG-language model can be measured against a fixed standard instead of a one-off demonstration.

Method vs predecessors

Compared with Sensor2Text's free-text generation, PulseLM uses closed-ended question answering, which trades open description for graded, reproducible accuracy. Compared with the biosignals survey, which is descriptive, PulseLM is constructive: it delivers data, protocol, and baseline encoders-plus-language-backbone models. The technical core is the harmonization of twelve question types across heterogeneous sources rather than a new model architecture.
