TREK: Distill to Explore, Reinforce to Refine

Xu, Zhou, Behdin et al. · arXiv 2026 · link · Appears in: Reasoning, World Model / RL

What

TREK (Teacher-Routed Exploration via Forward KL) is a staged training procedure for reasoning models. It identifies prompts where the student has near-zero pass rate, queries a teacher for verified correct solutions, keeps the top candidates ranked by student likelihood, runs a short forward-KL phase to pull those solution modes into the student's sampling range, then returns to on-policy Group Relative Policy Optimization. With DeepSeek-V4 proposals, Qwen3-8B improves AIME 2025 from 36.9 to 40.3 and AIME 2024 from 47.9 to 51.1; ALFWorld rises from 75.8 to 82.8 and ScienceWorld from 12.5 to 26.7.

Why

Group Relative Policy Optimization only improves a model on prompts where it already samples some correct trajectories. On hard prompts whose correct solutions lie outside the model's current support, there is nothing to reward, so training stalls. Prior on-policy reinforcement learning cannot escape this because it never sees a correct answer to reinforce.

How

The method uses distillation for exploration rather than imitation. It consumes only verified output trajectories, so the teacher can be an external black-box model, a white-box model, or the same model given extra inference-time context. A short forward-KL phase pulls verified off-support solutions into the student's range, after which standard on-policy refinement takes over. Because it only needs verified outputs, it can also select which hard prompts are most worth consolidating without access to teacher internals.

Solves vs predecessors

DeepSeek-R1 and other GRPO methods cannot improve on prompts where the model never samples a correct solution, because the reward signal is empty there. TREK solves exactly this failure mode by importing verified correct modes through a brief distillation step before reinforcement, converting previously unlearnable prompts into learnable ones.

Method vs predecessors

Where the parents run reinforcement learning directly on whatever the policy samples, TREK inserts a targeted forward-KL warm start that expands the support first, then reinforces. Distillation here is not used to copy the teacher wholesale but to seed exploration only on the hardest prompts, which keeps the on-policy refinement stage intact while removing its blind spot.
