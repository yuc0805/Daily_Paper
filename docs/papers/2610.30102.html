Implementation of Dynamic Microsegmentation for a Multi-Robot Network

Vishwam Raval, Jaewon Kim, Ravi Pattabhi, Sandip Roy · 2026 · Explore · arXiv:2610.30102

Why recommended

Picked for exploration — from another field, outside your usual research areas.

Abstract

This report describes a laboratory instantiation of a dynamic microsegmentation function for an Internet-of-Things network, specifically a multi-robot network, using a commercial software-defined microsegmentation tool. Fine-grained dynamic segmentation policies are defined, where segments are adapted based on asset functional and health tags. Automated implementation of the dynamic policies in software is also undertaken. The microsegmentation solution is shown to automatically isolate an indicated threat in real time, while maintaining unaffected operations. The demonstration indicates that microsegmentation can be implemented in IoT networks, in a way that allows for robust operation in the face of threats and disruptions.
