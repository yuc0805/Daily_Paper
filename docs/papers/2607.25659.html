CoRT: Counterfactual Replay for Token-Level Rubric-Guided Policy Optimization

Zhang, He, Wang, Lv, Ma, Lin, Zhong, Guo · arXiv 2026-07-28 · arXiv:2607.25659 · Appears in: Reasoning

What

CoRT is a token-level credit weighting method for rubric-conditioned GRPO. It rescores the same sampled response twice, once under the rubric-conditioned prompt and once under a matched criteria-free prompt, and uses the token-by-token log-likelihood difference as a proxy for how much each token depends on the rubric. It maps these differences to bounded, response-normalized weights and redistributes the signed GRPO advantage across tokens, with no auxiliary scoring model and no change to the response-level reward. Across instruction-tuned models it improves over matched response-level GRPO by 4.4 percentage points on average.

Why

Rubric-based reinforcement learning scores an output against explicit criteria, but in GRPO-style pipelines those per-criterion judgments collapse into one response-level reward that is spread evenly across every token. This leaves no way to give more credit to the tokens that actually satisfied a criterion, even when different criteria are grounded in different spans or formatting choices. Learned token-scoring models can fix this but add a separate relevance-learning stage. The paper's goal is fine-grained credit without an auxiliary scorer.

How

For a sampled response, CoRT runs the same tokens through the model twice: once conditioned on the rubric and once on a matched prompt with the criteria removed. The difference in token log-likelihood between the two runs indicates how much each token relied on the rubric context. These contrasts are mapped to bounded, response-normalized weights that redistribute the existing GRPO advantage across tokens. Nothing else in the pipeline changes: the response-level reward, the sampling, and the update rule stay the same.

Builds on

  • DeepSeek-R1 (2025)Its GRPO training is exactly the pipeline CoRT modifies with token-level weights.
  • Chain-of-Thought Prompting (Wei 2023)Older anchor for exposing reasoning; CoRT does not change the text, it changes which tokens the update rewards.

Solves vs predecessors

DeepSeek-R1 assigns one advantage to the whole response, so every token gets the same credit regardless of whether it satisfied a rubric criterion. CoRT fixes the failure mode "uniform credit wastes rubric-level signal" by splitting the advantage across tokens using the model's own likelihood contrasts, which recovers within-response credit that response-level GRPO throws away.

Method vs predecessors

Compared to response-level GRPO, CoRT adds a token-weighting step derived from counterfactual replay rather than from a learned scorer. Compared to learned token-level credit baselines, it avoids a separate relevance-learning stage and stays competitive, keeping the simplicity and stability of GRPO while adding fine-grained credit.
