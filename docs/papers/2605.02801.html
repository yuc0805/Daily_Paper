Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces

arXiv 2026-05-04 · arXiv:2605.02801 · Appears in: Agent

What

Formalizes RL for LLM multi-agent systems by modeling interactions as orchestration traces: temporal interaction graphs whose events include sub-agent spawning, delegation, communication, tool use, return, aggregation, and stopping decisions. Identifies eight reward families, decomposes orchestration into five sub-decisions, and reveals that no explicit RL training method exists for the stopping decision.

Why

Prior work on LLM agents focused on single-agent planning and search. As multi-agent systems become common (e.g., coding assistants with specialized sub-agents), there is no formal framework for training the orchestration layer with RL. Without such a framework, orchestration decisions (whom to delegate to, when to stop) are hand-coded heuristics.

How

The paper defines orchestration traces as temporal interaction graphs and categorizes RL approaches along three axes: reward design (eight families including parallelism speedup and aggregation quality), credit assignment (eight granularity levels from token to team), and orchestration sub-decisions (spawn, delegate, communicate, aggregate, stop). A systematic gap analysis over the existing literature identifies missing coverage.

Builds on

  • ADaPT (Prasad 2023)As-needed decomposition for single agents; this paper extends decomposition to multi-agent orchestration.
  • LATS (Zhou 2024)Language agent tree search for single-agent planning; this paper lifts tree search to multi-agent interaction graphs.

Solves vs predecessors

ADaPT and LATS decomposed planning for a single agent but had no mechanism for inter-agent coordination. When multiple agents run in parallel, questions of delegation routing, communication protocols, and aggregation strategies arise that single-agent frameworks cannot address. This paper provides the first formal decomposition of these multi-agent orchestration decisions.

Method vs predecessors

ADaPT used as-needed task decomposition with a single LLM. LATS combined Monte Carlo tree search with LLM-based value estimation. This paper introduces temporal interaction graphs as the RL state representation, where nodes are agent events and edges are delegation/communication flows. The reward design taxonomy (eight families) is substantially richer than the single task-success reward used by ADaPT and LATS.
