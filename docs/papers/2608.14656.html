P2E-VQ: ECG-linked representation augmentation for PPG via discrete patch retrieval

Wu, Gao, Zhao, Zhou, Wang, Ding, Wang, Qin, Lip, Kirmani, Zheng (Liverpool) · arXiv 2026-07-31 · arXiv:2608.14656 · Appears in: Signal/Time Series, LLM-Health

What

P2E-VQ improves PPG representations by giving them access to ECG-derived information without ever requiring an ECG at inference. PPG is cut into patches, each patch is quantised into a discrete token, and that token is used as a key into a memory bank of ECG-linked representations built exclusively from the training split. The retrieved representation augments the PPG representation, so the model consumes only PPG when deployed. Evaluation covers five public datasets and six downstream tasks, spanning clinical endpoint prediction and affective state recognition, all under one frozen-feature linear-probing protocol, and the method beats pretrained baselines consistently across them.

Why

PPG is what consumer wearables actually collect, because an optical sensor at the wrist is cheap and tolerates continuous wear. What it measures is peripheral pulse dynamics, not cardiac electrical activity, so the morphological features that cardiac diagnosis depends on are not present in the signal. The field's standard response has been to reconstruct an ECG waveform from the PPG and then apply ECG methods to the reconstruction. That inverse mapping is ill-posed: many cardiac states are consistent with a given peripheral pulse, so the reconstruction is under-determined. The sharper objection this paper makes is that even a faithful reconstruction does not guarantee better downstream accuracy, because waveform fidelity and task-relevant information are different objectives and optimising the first does not optimise the second.

How

The method replaces generation with retrieval. A vector-quantisation codebook maps each PPG patch to a discrete index, which turns a continuous signal segment into a lookup key. During training, when paired ECG is available, the ECG-linked representation for each key is stored in a memory bank; at inference only the PPG is tokenised and the bank is queried. Because the bank is constructed from training data only, no test-time ECG leaks in, and because the augmentation happens in representation space, the ill-posedness of the waveform inverse problem is sidestepped rather than solved. Evaluation deliberately freezes the encoder and fits a linear probe, so the comparison isolates representation quality from downstream fitting capacity.

Solves vs predecessors

Sensor2Text and the PPG-to-ECG reconstruction line both treat the generated target modality as the deliverable, and both inherit that target's difficulty. When the mapping is ill-posed, as PPG to ECG is, the generative model spends capacity on details that the downstream classifier never reads, and the reported reconstruction metric stops predicting downstream accuracy. P2E-VQ removes the generation step, so none of that capacity is spent and the ill-posedness never has to be resolved. Against Yuan 2024, the failure mode addressed is different: more unlabelled PPG improves the encoder but cannot introduce information the modality does not carry, whereas a paired ECG corpus can, provided it is used as an index rather than as a reconstruction target.

Method vs predecessors

The technical import is discrete tokenisation plus retrieval augmentation, a pairing that has been standard in language modelling for several years, applied here to physiological signal. Where the predecessors used the paired modality as a supervision target inside a loss, this paper uses it as the contents of a non-parametric store keyed by quantised patches, which changes what the paired data is for. The design also has an asymmetric deployment profile that the predecessors do not: paired ECG is needed once at training time and never again, which fits the practical situation where clinical ECG exists in a research cohort but not on the wrist. The number to check on a close read is codebook utilisation, since a quantiser that collapses to few codes would make the memory bank degenerate into a class prior.
