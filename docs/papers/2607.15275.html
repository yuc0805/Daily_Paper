RoboTTT: Context Scaling for Robot Policies

Jiang, Chebotar, Zheng, Hu, Ge, Wu, Dai, Reed, Fei-Fei, Zhu, Fan (NVIDIA) · arXiv 2026 · arXiv:2607.15275 · Appears in: Test-Time Training

What

RoboTTT is a robot policy and training recipe that scales visuomotor context to 8,000 timesteps, three orders of magnitude beyond typical single-step or short-history policies, without growing inference latency. It integrates Test-Time Training into a Vision-Language-Action policy so the recurrent state is a set of fast weights — parameters updated by gradient descent during both training and inference — that compress history into weight space and retrieve context for long-horizon conditioning.

Why

Recent robot foundation models operate with single-step or short-history context, which limits them on multi-stage, long-horizon tasks and prevents one-shot imitation from long human-video demonstrations. Growing a token window raises latency and cost. The paper seeks long-context conditioning at constant inference latency, and asks whether context length is itself a useful scaling axis for robot policies.

How

The recurrent state is fast weights updated by gradient descent at every step, so thousands of timesteps are folded into the weights rather than kept as tokens. To train at long context, the recipe combines sequence action forcing with truncated backpropagation through time. On real-robot manipulation the method improves overall performance by 87% over a single-step baseline, fully completes a five-minute ten-stage assembly task that no baseline finishes, and an 8K-timestep model outperforms the same model pretrained at 1K by 62%, with steady closed-loop gains as pretraining context length grows.

Solves vs predecessors

Standard TTT adapts a model to a single test instance with one or a few gradient steps, which does not give a policy any long-term memory. RoboTTT fixes the specific limitation — "the policy only sees the last step or two" — by running the fast-weight update continuously across thousands of steps, so minutes of interaction are retained without a growing token window or added latency.

Method vs predecessors

Compared to the original TTT, the update is not a one-off adaptation but the policy's working memory, applied at both training and inference. Compared to standard VLA policies that condition on a short frame history, RoboTTT changes the memory mechanism from a bounded token window to fast weights, and adds a training recipe (sequence action forcing plus truncated backpropagation through time) that makes 8K-step context trainable.
