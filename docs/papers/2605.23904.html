SkillOpt: Executive Strategy for Self-Evolving Agent Skills

Microsoft Research · arXiv 2026-05 · arXiv:2605.23904 · Appears in: Agent

What

SkillOpt is a text-space optimizer for agent skills: a separate optimizer model turns scored rollouts into bounded add/delete/replace edits on a single skill document, and an edit is accepted only when it strictly improves a held-out validation score. Across six benchmarks, seven target models, and three execution harnesses, it is best or tied in all 52 evaluated (model, benchmark, harness) cells; on GPT-5.5 it lifts no-skill accuracy by +23.5 points in direct chat, +24.8 in Codex, and +19.1 in Claude Code. Code: github.com/microsoft/SkillOpt.

Why

Current agent skills are hand-crafted, generated one-shot, or evolved through loosely controlled self-revision, and none of these reliably improves over its starting point under feedback. Skill text drifts, regressions go undetected, and improvements do not transfer across models or harnesses.

How

The optimizer applies bounded edits under a textual learning-rate budget, keeps a rejected-edit buffer so failed directions are not retried, and uses epoch-wise slow/meta updates for stability. Validation gating makes every accepted edit a strict improvement on held-out tasks. The trained artifact is a plain skill document, so deployment adds zero inference-time model calls.

Builds on

Solves vs predecessors

The failure mode of self-revision approaches is unverified drift: an agent rewrites its own instructions and quietly gets worse. SkillOpt fixes this with validation-gated acceptance — no edit lands unless it strictly improves a held-out score — turning skill editing from open-ended generation into a controlled optimization step.

Method vs predecessors

Where ToolkenGPT trains embeddings (model-internal, model-specific, inference-coupled), SkillOpt trains text (model-external, portable across seven target models and three harnesses, zero inference overhead). It extends the tool-using-agents bridge in the library (ToolkenGPT to PyVision): that bridge crossed static embeddings and dynamic code tooling; SkillOpt pushes it into optimization of the text artifact itself.
