Reasoning for Mobile User Experience with Multimodal LLMs: Task, Benchmark, and Approach

Mao et al. · arXiv 2026 · link · Appears in: Multi-Modal

What

The paper introduces UXBench, a multimodal benchmark of 2,000 visual-question-answering samples built on real-world user-interface screenshots. Eight tasks require fine-grained diagnosis of user-experience problems across layout relationships, visual hierarchy, and content consistency. The benchmark is paired with a reasoning approach tuned for screen understanding.

Why

Multimodal models can describe a screen, but describing is not diagnosing. Prior agentic multimodal work reasons over general images without a ground-truth answer for what is wrong, so progress is hard to measure. A constrained domain with labeled faults turns open-ended description into a checkable task.

How

UXBench fixes the image type to user interfaces and labels specific faults, so a model must localize and explain a design problem rather than caption the screen. The eight tasks span layout relationships, visual hierarchy, and content consistency, giving fine-grained targets. The accompanying approach is tuned for this screen-reasoning setting.

Builds on

  • DeepEyesV2 (Hong 2026)Agentic multimodal model that looks at images and acts with tools.
  • PyVision (Zhao 2025)Agentic vision with dynamic tooling over general images.

Solves vs predecessors

Where DeepEyesV2 and PyVision reason over general images without a fixed correct answer, this paper constrains the domain to user interfaces and supplies labeled faults, so the reasoning becomes measurable. The failure mode it addresses is unverifiable, open-ended description.

Method vs predecessors

The parents add tools and dynamic action to a vision model; this paper instead invests in a task and dataset that demand fine-grained localization plus explanation, with the method built to fit that target. The portable idea is the diagnostic benchmark design, not a new agent architecture.
