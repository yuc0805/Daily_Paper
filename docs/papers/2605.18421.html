EvoMemBench: Benchmarking Agent Memory from a Self-Evolving Perspective

arXiv 2026-05-18 · arXiv:2605.18421 · Appears in: Agent

What

EvoMemBench is a benchmark built specifically for agent memory rather than for reasoning, planning, or execution. It organizes evaluation along axes that include memory scope (within a single episode versus across episodes) and how memory must evolve as the agent's situation changes, giving a structured way to rank memory mechanisms under shifting tasks instead of one aggregate score.

Why

Recent agent benchmarks mainly measure reasoning, planning, and execution, and test memory only indirectly. But memory is what lets an agent store, update, and retrieve information over time, and a method can look strong on an aggregate score while failing when the task keeps changing. The paper's motivation is to isolate memory as the thing being measured and to stress it under self-evolving conditions.

How

The benchmark defines tasks along a memory-scope axis (in-episode versus cross-episode) and varies the agent's situation over time so that stored information must be updated and retrieved correctly as conditions shift. Methods are scored on how well their memory holds up under these changes rather than on a single end-task accuracy.

Solves vs predecessors

The Memory Mechanisms Survey (Huang 2026) describes memory mechanisms qualitatively and names failure modes but cannot rank methods against them. EvoMemBench fixes that gap by operationalizing the taxonomy into measurable tasks and scoring methods under self-evolving conditions, so the field can compare memory mechanisms head to head rather than describe them.

Method vs predecessors

Where the survey is a map of mechanisms, EvoMemBench is a measurement instrument. Its distinguishing choice versus generic agent benchmarks is that it varies the situation over time and separates in-episode from cross-episode memory, so a method cannot score well by short-term recall alone. It is the natural test harness for memory methods such as MemReread (2605.10268), featured the same day.
