Cura 1T: Specialized Model for Agentic Healthcare

actAVA AI, Chen, Qi, Brown, Metelski, Xia, Lee, Wang, Riley, Wang, Yao · arXiv 2026 · link · Appears in: LLM-Health

What

Cura 1T is a healthcare-specialized language model trained through a human-gated self-evolution loop. In each round a training agent picks a target capability, trains the model, reads the benchmark trajectories, and rewrites the data mixture from the observed failures, rather than doing one generic medical-data update. Across a healthcare evaluation suite it ranks at or near the top among frontier baselines while staying competitive on out-of-domain reasoning and agentic benchmarks.

Why

A healthcare model must handle patient consultation, clinical reasoning over text and images, interactive diagnosis, and electronic health record tool use. These capabilities fail in different ways, and a narrow update aimed at one task can degrade another. A single generic medical fine-tune therefore cannot cover the full workflow without regressing some skill, which motivates a data-centered loop that targets observed failures.

How

The training agent runs rounds: plan a target capability, train, evaluate benchmark trajectories, and refine the data mixture from where the model failed, using targeted synthetic and curated examples. A human gate controls each round. The loop improves the model through repeated failure-driven data edits rather than one static update.

Solves vs predecessors

Liu 2023 showed few-shot health competence and CounselBench measured failure modes, but neither closed the loop between measured failures and the next training round. Cura 1T turns those failures into the training signal itself, addressing the regression problem where fixing one healthcare skill degrades another.

Method vs predecessors

Where Gu 2025 catalogued fixed biosignal encoders, Cura 1T is an agentic system whose data mixture changes each round, placing it on the self-improving-system branch rather than the fixed-encoder branch. Where earlier health models did one supervised fine-tune, Cura 1T runs iterative, failure-targeted data construction under a human gate.
