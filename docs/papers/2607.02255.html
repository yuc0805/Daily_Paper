AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents

Cheng, Jiang, Sun, Li, Li, Cao, Liu, Zhang, Jin, Zhang · arXiv 2026 · arXiv:2607.02255 · Appears in: Agent

What

AgenticSTS studies how memory should be handed to a long-horizon LLM agent. Instead of appending the whole past transcript to every prompt, it uses a bounded contract: each decision starts from a fresh prompt assembled by typed retrieval, so the prompt stays a fixed size and each memory layer can be turned off on its own. It is tested in Slay the Spire 2, a stochastic deck-building game needing hundreds of decisions per run, and ships 298 tagged trajectories as a reusable testbed.

Why

The simplest agent memory appends past observations, tool calls, and reflections to every prompt. That grows without bound and mixes everything together, so the effect of any single memory component cannot be isolated, and long runs blow past context limits. Prior memory surveys catalog designs but do not measure them under one controlled harness, so the field lacks clean ablations of what memory actually helps.

How

Every decision is made from a fresh user message built by typed retrieval, with no raw cross-decision transcript appended, so prompt length is bounded across runs of any length and any single layer can be ablated in isolation. The authors instantiate this in Slay the Spire 2 and run ablations; a fixed-A0 ablation with triggered strategic skills enabled shows the largest observed difference, moving the no-store baseline from 3/10 to 6/10 wins, which they call directional rather than statistically decisive at that sample size (Fisher exact p about 0.37).

Solves vs predecessors

The Memory Mechanisms Survey describes many memory designs but does not measure them under one controlled setup, so it cannot say which layer helps. AgenticSTS fixes that by building a harness where each memory layer can be ablated in isolation, and it reports the effect and its weak significance rather than overselling.

Method vs predecessors

Where LATS and ADaPT grow or branch their context as the task proceeds, AgenticSTS keeps the prompt bounded by rebuilding it through typed retrieval at each step. The contract framing — what each decision is allowed to see — makes memory an explicit, testable variable rather than an ever-growing transcript.
