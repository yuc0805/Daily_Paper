Vision as Unified Multimodal Generation (SenseNova-Vision)

Han, Li, Deng, Chen, Shi et al. (SenseNova) · arXiv 2026 · arXiv:2607.06560 · Appears in: Multi-Modal

What

SenseNova-Vision casts every computer-vision task as text-and-image generation inside one multimodal model, with no task-specific heads. Natural-language instructions plus optional visual prompts specify the task, the target region, and the output convention; the model then emits text for symbolic answers, images for dense predictions, or a mix for compositional tasks. One model covers detection, OCR, keypoints, segmentation, depth, surface normals, point maps, and camera pose, and matches task-specialized systems across these groups.

Why

Computer vision is usually served by separate models with task-specific prediction heads, one per task. That fragments engineering and blocks a single general model from covering the whole stack. Prior unified attempts still leaned on per-task heads or narrow output spaces. The open question is whether one generation formulation can express symbolic, dense-spatial, and compositional outputs at once.

How

The authors express heterogeneous tasks in the native text and image generation spaces of a unified multimodal model. They convert many vision annotations into instruction-response examples (the SenseNova-Vision Corpus, spanning text, image, and mixed targets), then continue training an off-the-shelf pretrained unified model mainly on this corpus, with auxiliary multimodal data mixed in to preserve general capability. No task-specific heads or architecture changes are added; the output channel is generation itself.

Builds on

  • DETR (Carion 2020)Removed hand-built detection components by casting detection as set prediction; SenseNova removes task-specific heads for the whole vision stack.
  • DiT (Peebles 2023)Showed a transformer can drive image generation; SenseNova reuses that generation space as the output channel for dense predictions.

Solves vs predecessors

DETR removed hand-built parts for one task, detection, but each vision task still had its own model and head. SenseNova-Vision removes the per-task head problem across the whole stack by turning each task into generation, so a single model spans detection through camera-pose estimation without architectural forks.

Method vs predecessors

DETR framed detection as set prediction with a fixed decoder; DiT used a transformer to generate images from noise. SenseNova-Vision combines the two ideas at a higher level: it uses a unified model's text-and-image generation space as the universal output format and drives task behavior through instructions and visual prompts plus a purpose-built instruction-response corpus, rather than through separate decoders.
