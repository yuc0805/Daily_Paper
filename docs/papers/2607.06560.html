Vision as Unified Multimodal Generation (SenseNova-Vision)

Han, Li, Deng, Chen, Shi, Cai, Liu, Lin, Wang et al. (SenseNova) · arXiv 2026 · link · Appears in: Multi-Modal

What

SenseNova-Vision poses many computer-vision tasks (detection, OCR, keypoints, segmentation, depth, surface normals, point maps, camera pose) as one generation problem inside a unified multimodal model. Natural-language instructions and optional visual prompts specify the task, region, and decoding convention; outputs are text for symbolic answers, images for dense spatial predictions, or mixed text-and-image for compositional tasks, with no task-specific heads. A single model matches leading task-specialized systems across structured understanding, dense geometric prediction, segmentation, and multi-view geometry.

Why

Computer vision is usually solved with a separate architecture and prediction head per task, which does not scale to a general-purpose foundation model. Prior generative multimodal models produced images from text but were not used to emit structured or dense predictions. The paper seeks one interface that covers perception, understanding, and generation without per-task engineering.

How

Diverse vision annotations are converted into instruction-response examples that live in the model's native text and image generation spaces, producing the 50M-example SenseNova-Vision Corpus. Starting from an off-the-shelf pretrained unified multimodal model, training runs mainly on this corpus with auxiliary multimodal data as a capability-preserving mixture, and needs no new prediction heads or architecture changes. Dense outputs such as depth and segmentation are produced as generated images.

Builds on

  • DALL-E 2 (Ramesh 2022)Hierarchical text-conditional image generation.
  • DiT (Peebles 2023)Transformer backbone for diffusion image generation.
  • Attention Is All You Need (Vaswani 2017)The shared Transformer architecture underneath.

Solves vs predecessors

DALL-E 2 and DiT generated images as the end product. SenseNova-Vision reuses that generative image space to solve perception tasks, so one model replaces a stack of task-specific detectors, segmenters, and depth networks. The failure mode it addresses is the per-task head: by making every output a generated text or image, adding a task becomes a data-conversion step, not an architecture change.

Method vs predecessors

The parents optimized image fidelity from text prompts; this work keeps a similar generator but changes the training target, turning labeled vision datasets into instruction-response pairs so the same next-token or image-generation objective covers detection, segmentation, and geometry. The contribution is the reformulation and corpus, not a new sampler.
