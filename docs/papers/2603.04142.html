Vivaldi: A Multi-Agent Framework for Interpreting Multivariate Physiological Time Series

Gabrielli, Velardi, Faralli, Prenkaj · arXiv 2026-03-04 · arXiv:2603.04142 · Appears in: Signal/Time Series, LLM-Health

What

Vivaldi is a role-structured multi-agent system that produces natural-language explanations of multivariate physiological time series. Each agent handles a distinct function (signal decomposition, clinical contextualization, synthesis). A controlled pilot with emergency medicine experts shows agentic pipelines improve explanation justification by +6.9 and relevance by +9.7 points for non-thinking and medically fine-tuned models, though gains shrink for frontier reasoning models.

Why

Interpreting physiological time series (ECG, PPG, accelerometry) in clinical settings requires both signal-level analysis and medical context. Prior work either trains end-to-end sensor-language bridges (Sensor2Text) or uses a single LLM controller with tool calls (TS-Agent), but neither approach separates the distinct cognitive tasks of signal analysis, clinical knowledge retrieval, and explanation synthesis. Single-agent systems also provide no mechanism for internal cross-checking between these functions.

How

Vivaldi assigns specialized roles to separate LLM agents in a structured pipeline. A signal analyst agent decomposes the multivariate input into temporal patterns and anomalies. A clinical context agent maps these patterns to known medical conditions and thresholds. A synthesis agent merges both outputs into a coherent explanation. The system was evaluated in a controlled clinical pilot where emergency medicine experts rated explanation quality on justification, relevance, and clarity scales.

Builds on

  • TS-Agent (Liu 2025)Single-agent LLM controller for time-series reasoning with iterative tool calls; Vivaldi extends this to multi-agent with specialized clinical roles.
  • Foundation Models for Biosignals (Gu 2025)Surveys self-supervised FMs for biosignals; Vivaldi uses these as signal-processing backends within the agent pipeline.
  • Sensor2Text (Chen 2024)Trained sensor-to-language bridge; Vivaldi avoids alignment training by distributing interpretation across cooperating agents.

Solves vs predecessors

TS-Agent showed that an LLM with tool calls can reason about time series without alignment training, but it used a single controller for all cognitive tasks and was not evaluated with domain experts on clinical data. Vivaldi fixes the single-controller bottleneck by splitting the pipeline into specialized roles, and adds clinical validation that prior work lacked. The key finding — that agentic pipelines help weaker models more than frontier models — also provides practical deployment guidance missing from TS-Agent.

Method vs predecessors

Compared to TS-Agent, Vivaldi replaces the single observe-think-act loop with a multi-agent pipeline where each agent has a fixed role and passes structured intermediate outputs to the next. Compared to Sensor2Text, Vivaldi avoids training a sensor-language bridge entirely, relying instead on agent orchestration for the sensor-to-language translation. The evaluation methodology also differs: Vivaldi uses expert clinician ratings rather than automated metrics.
