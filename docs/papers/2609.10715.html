NCP-ArchPreview Technical Report: Moving towards Latent Space Language Models through Next Concept Prediction

Liu et al. (28 authors) · arXiv 2026-09-11 · arXiv:2609.10715 · Appears in: LLM

What

NCP-ArchPreview adds a second autoregressive objective above next-token prediction. The model builds a concept vocabulary by product-quantizing its own hidden states, then trains a dedicated Concept Module to predict the next discrete concept, where a concept spans several tokens. The predicted concept is fed back down to the token level to condition subsequent token generation, and the concept objective and the token objective are trained jointly end to end. The architecture was scaled to 8.9B parameters trained on 5.73T tokens of Dolma-3, which the authors report as the largest latent-space language model trained so far.

Why

Next-token prediction asks the model to commit its entire predictive effort to one unit ahead, which means long-range structure has to be carried implicitly. Latent-reasoning work has argued for years that a model should be able to plan in a hidden space above the token, but the approaches that tried it kept the latent stream continuous and unsupervised, so there was no loss to train the latent level against. That limited these methods to post-training reasoning interventions on modest models, and left open whether a latent objective helps at pretraining scale at all.

How

The hidden states of the running model are product-quantized into a discrete codebook, which turns the latent space into a vocabulary with addressable entries. Because the codebook index of a future position is a concrete label, the Concept Module can be trained with a standard prediction loss to name the next concept. That predicted concept is then injected back into the token-level stream as conditioning, so the coarse prediction steers fine-grained generation rather than sitting beside it. Both losses are optimized together throughout pretraining, and the token-level autoregressive interface is preserved, so generation and decoding are unchanged from a standard language model.

Builds on

  • Coconut: Reasoning in a Continuous Latent Space (Hao 2024)Established that reasoning state can be carried in hidden vectors instead of emitted tokens; this work quantizes that state so it can be predicted.
  • Attention Is All You Need (Vaswani 2017)Supplies the token-level autoregressive backbone, which is kept intact underneath the concept level.
  • Latent Reasoning: A Survey (Zhu 2025)Names the missing supervision signal for latent states that product quantization is proposed to provide.

Solves vs predecessors

Coconut showed that a model can reason in a continuous latent stream, but that stream is unsupervised: nothing tells the model what the latent state at a future position should be, so the method works as a post-training reasoning intervention and does not give pretraining a second objective. The specific failure mode is that a continuous latent has no label, so it cannot be scored. Product quantization fixes exactly that, because the codebook index of a future hidden state is a discrete target the Concept Module can be trained against. The consequence is scale: the concept objective runs across 5.73T pretraining tokens at 8.9B parameters rather than being fitted afterward on a small set of reasoning traces.

Method vs predecessors

Compared with a standard transformer, the difference is the prediction horizon. Vaswani 2017 defines one prediction unit, the next token, and every gradient at a position is about that unit. NCP-ArchPreview keeps that head and adds a second one whose unit spans multiple tokens, so each position carries gradients about both a local continuation and a coarser future state. Compared with Coconut, the latent space changes from continuous to discrete and from inference-time to pretraining-time, and a feedback path is added so the concept prediction conditions token generation rather than replacing it. The cost is an extra module, a codebook that must be maintained as hidden states drift during training, and a joint loss whose balance is a new hyperparameter.
