UniCanvas: A Diffusion-based Unified Model for Text-in-Image Joint Generation

Yang, Chen, Yu, Yang, Zhen, Ma, Shen, Gan · arXiv 2026-06-02 · arXiv:2606.04264 · Appears in: Multi-Modal

What

UniCanvas unifies multimodal generation inside a single diffusion model by treating language as something to draw: instead of producing discrete text tokens, the model renders text as visual patterns on the shared pixel canvas during image synthesis. Experiments show improvement over previous unified models.

Why

Unified vision-language models face a split: autoregressive VLMs reason across modalities but generate poor images, while diffusion models generate photorealistic images but incoherent text. Hybrid architectures that bolt a token head onto a diffusion backbone inherit the weaknesses of both. The paper bets that the discrete text head is the component to remove.

How

The model builds on the observation that language can be embedded within visual representations, so textual semantics can be read directly from images. Diffusion is framed as a world model of visual change on a shared canvas; language output becomes a visual pattern the model learns to draw in place, making text and image generation one synthesis process in one embedding space.

Builds on

  • DDPM (Ho 2020)The pixel-space denoising objective UniCanvas runs on.
  • DALL-E 2 (Ramesh 2022)Made text an input condition for diffusion; UniCanvas makes text an output of the same canvas.

Solves vs predecessors

Diffusion predecessors fail at coherent text generation — both as rendered glyphs inside images and as a language output channel. UniCanvas addresses this by never leaving pixel space: language is generated as visual patterns, removing the broken token head rather than repairing it.

Method vs predecessors

Where DDPM defined the denoising objective and DALL-E 2 added CLIP-prior text conditioning, UniCanvas changes what the canvas carries: interleaved multimodal content where text is drawn, not emitted.
