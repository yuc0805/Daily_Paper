Infini Memory: Maintainable Topic Documents for Long-Term LLM Agent Memory

See paper · arXiv 2026-06-09 · arXiv:2606.10677 · Appears in: Agent

What

Infini Memory is a text-based persistent memory architecture for LLM agents: memory is a set of topic documents, each a semantic unit that collects related evidence, preserves metadata, and revises facts over time, instead of an append-only log or a vector store of isolated snippets.

Why

Agent memories that only append or only embed cannot express fact revision: when the world changes, stale and contradictory entries accumulate and retrieval quality decays over months of operation. The Huang 2026 survey flagged maintainability as an open problem; this paper is a direct answer.

How

Each topic document acts as the unit of both writing and retrieval. New evidence is routed to its topic, merged with existing content, and contradictions are resolved by revising the document rather than appending a competing entry. Metadata preserves provenance so revisions remain auditable. Summary is abstract-level; benchmark numbers were not available in accessible sources at digest time.

Solves vs predecessors

Append-only and embedding-only memories fail at fact revision: the agent retrieves both the old and the new version of a fact and cannot tell which holds. Topic documents with revision semantics fix this by making the current state of knowledge explicit and the history auditable.

Method vs predecessors

Where ExpWeaver and MemoPilot (yesterday's digest) move memory into latent space for efficiency, Infini Memory argues the opposite direction: plain text is what keeps long-term memory maintainable and inspectable. Where ToolkenGPT embedded knowledge into vocabulary, this approach keeps knowledge outside the model entirely.
