Infini Memory: Maintainable Topic Documents for Long-Term LLM Agent Memory

See arXiv listing · arXiv 2026 · link · Appears in: Agent

What

Infini Memory stores an agent's long-term memory as topic-structured text documents rather than a flat log or a vector store. Each topic document collects related evidence, keeps metadata, and is revised over time, so memory stays consistent and current across a long task.

Why

Flat conversation logs grow without bound and vector stores lose factual consistency over long horizons, so an agent's memory becomes large, stale, and internally contradictory. The paper targets a memory structure that stays maintainable as the task runs.

How

Memory is organized by topic. Each topic document acts as a semantic unit for collecting related evidence, preserving metadata, and revising facts as new information arrives, which supports more accurate retrieval than an undifferentiated store.

Solves vs predecessors

Where the survey describes categories of agent memory without choosing one, Infini Memory picks document-structured topic memory with revision, addressing the consistency failure that flat logs and vector stores both show on long-horizon tasks.

Method vs predecessors

Instead of embedding-based retrieval over a flat store, the method keeps human-readable topic documents that can be revised in place, which makes stale-fact correction explicit rather than implicit in embedding similarity.
