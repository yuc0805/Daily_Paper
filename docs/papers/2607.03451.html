SkillOpt-Lite: Better and Faster Agent Self-evolution via One Line of Vibe

Shen, Li, Zhang (LMMs-Lab) · arXiv 2026 · link · Appears in: Agent, Reasoning

What

SkillOpt-Lite reframes agent skill self-evolution as zeroth-order optimization and reduces the pipeline to three parts, each justified by theory or need: file-system trajectory exploration, consensus attribute mining, and independent validation gating. It converges faster than the full SkillOpt method and improves LiveMath by 8.8 points on GPT-5.5 and 25.4 points on GPT-5.4-nano, letting the nano model pass the larger standard GPT-5.4. Extended to full harness optimization, it reaches 0.7758 on SpreadsheetBench with GPT-5.4-nano, above GPT-5.5 at 0.7620.

Why

Methods that let agents improve their own skills have grown complex, with many components whose contribution is unclear. The paper asks what a minimal viable pipeline for skill optimization looks like, where every part earns its place. Prior planning and search methods act per episode and do not produce a reusable, improvable skill library, so they leave open how to optimize the skills and harness themselves.

How

Skill optimization is cast as zeroth-order optimization, mapping classical ideas (central difference, trust regions) to agent skills, with the twist that skill trajectories give interpretable feedback rather than blind numerical perturbations. Grounded in PAC learning, three principles are kept: explore trajectories on the file system, mine attributes that recur across successful runs, and gate accepted changes with independent validation. Because every agent component is treated as editable code, the same loop extends to full harness optimization.

Builds on

  • ADaPT (Prasad 2023)As-needed task decomposition for agents.
  • LATS (Zhou 2024)Language agent tree search at inference time.
  • ToolkenGPT (Hao 2024)Tool use through learned tool embeddings.

Solves vs predecessors

ADaPT and LATS improve behavior within a single episode (decompose now, search now) but discard what they learned afterward. SkillOpt-Lite instead persists and optimizes reusable skills across episodes, so a small model armed with improved skills can pass a larger model that runs a standard pipeline. It also cuts the pipeline overhead that full SkillOpt carried, converging faster.

Method vs predecessors

Where the parents plan or search over actions, SkillOpt-Lite optimizes the skills and harness as code through a numerical-optimization loop with convergence and generalization arguments. Interpretable trajectories play the role that gradients play in first-order methods, which is a different mechanism from tree search or on-demand decomposition.
