PROVE: Synthesize and Reward — Reinforcement Learning for Multi-Step Tool Use in Live Environments

Abdelaziz, Munawar, Basu, Crouse, Gunasekara, Katrekar, Kapanipathi (IBM) · arXiv 2026 · link · Appears in: Agent

What

PROVE trains LLMs for multi-step tool orchestration using RL against 20 stateful MCP servers exposing 343 tools. It introduces an automated data synthesis pipeline that generates validated multi-turn tool-call trajectories grounded in live server state, plus a multi-component programmatic reward that requires no external judge model.

Why

Training LLMs to orchestrate multi-step tool calls faces three coupled obstacles: realistic stateful execution environments are costly to build, synthetic training queries are detached from actual server state (causing tool calls to fail), and recall-based RL rewards incentivize verbose calling patterns. Prior agent training relied on expensive judge models or hand-crafted trajectories.

How

PROVE builds 20 stateful MCP servers with session-scoped state isolation. An automated pipeline generates multi-turn trajectories via dependency-graph-guided conversation simulation grounded in live-sampled server state. The programmatic reward combines graduated validity scoring, dependency-aware coverage, an adaptive efficiency penalty with complexity-scaled call budget, a tool-name signal, and an argument-value matching bonus. Four models are trained with GRPO using 13K examples and identical reward hyperparameters.

Builds on

  • ToolkenGPT (Hao 2024)Embedded tool identifiers as special tokens for efficient tool selection.
  • ADaPT (Prasad 2023)Introduced as-needed decomposition and planning for multi-step tasks.
  • LATS (Zhou 2024)Used tree search over agent actions with LLM-based value functions.

Solves vs predecessors

ToolkenGPT, ADaPT, and LATS focused on tool selection and planning mechanisms but did not address the training data problem: generating realistic multi-turn trajectories that execute against live stateful environments. PROVE solves this by grounding synthetic data in real server state and replacing expensive judge-model rewards with a compact programmatic signal, making RL training for tool use practical at 13K examples.

Method vs predecessors

Where ToolkenGPT modified the token vocabulary and ADaPT/LATS designed inference-time search strategies, PROVE operates at the training data and reward level. The dependency-graph-guided conversation simulation is new — it ensures generated queries reference entities that exist in the server. The multi-component programmatic reward is more structured than the binary or scalar rewards used in prior agent RL work.
