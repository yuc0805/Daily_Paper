Personalizing Embodied Multimodal LLM Agents over Long-term User Interactions (POLAR)

Lee, Park, Lee · arXiv 2026 · arXiv:2605.26256 · Appears in: Agent

What

POLAR is a memory-augmented framework for embodied agents that serve the same user across many sessions. It organizes prior interactions into a multimodal knowledge graph that separates semantic memory (stable facts about the user and environment) from episodic memory (specific past events), and conditions the agent's actions on retrieved memory so behavior reflects the user's history rather than a generic policy.

Why

Embodied agents that interact with one user over time need to remember both durable facts and specific events, but a single flat memory store mixes the two and retrieves poorly. Prior agent-memory work mapped the design space without committing to a structure suited to long-term personalization, which is the gap POLAR targets.

How

Interactions are written into a multimodal knowledge graph with a semantic layer (facts) and an episodic layer (events). At decision time the agent retrieves relevant nodes from both layers and conditions its multimodal policy on them, so repeated interactions accumulate into personalized behavior.

Builds on

Solves vs predecessors

The Memory Mechanisms Survey described options but did not solve the long-term personalization case; a flat memory store fails to separate stable facts from one-off events, so retrieval degrades over many sessions. POLAR fixes this by splitting memory into semantic and episodic layers tied to a single user.

Method vs predecessors

Where the surveys are descriptive, POLAR is a concrete system: a multimodal knowledge graph with explicit semantic and episodic layers plus retrieval-conditioned action, rather than a single undifferentiated memory buffer.
