MetaForge: A Self-Evolving Multimodal Agent that Retrieves, Adapts, and Forges Tools On Demand

Wei, Min, Dong et al. · arXiv 2026-06 · arXiv:2606.01801 · Appears in: Agent

What

MetaForge is a multimodal agent that does not depend on a fixed tool set. When a task needs a capability it lacks, the agent retrieves a related tool, adapts it, or writes a new one, and then keeps the result for later reuse. The target is open-ended visual and multimodal tasks where the needed operations cannot be listed ahead of time.

Why

Tool-using agents usually work from a fixed library or generate a tool for one task and discard it. On open-ended tasks this means the agent re-solves the same sub-problems repeatedly and cannot accumulate capability. The paper targets agents whose tool set should grow with experience.

How

The agent combines retrieval of existing tools, adaptation of close matches, and generation of new tools when none fit, with a retain step that stores forged tools for future retrieval. Over a sequence of tasks the stored set grows, so later tasks reuse or adapt earlier tools instead of starting from nothing.

Builds on

  • PyVision (Zhao 2025)Generates vision tools at run time; MetaForge adds storage and reuse of those tools across tasks.
  • ToolkenGPT (Hao 2024)Represents tools as callable token embeddings; a fixed-vocabulary precursor to on-demand tool forging.
  • DeepEyesV2 (Hong 2026)Agentic multimodal model that interleaves perception and tool use within a task.

Solves vs predecessors

PyVision forges a tool for the current problem and then discards it; ToolkenGPT and DeepEyesV2 select or call tools but from a set that does not grow. MetaForge fixes the "no accumulation" failure mode by retaining and retrieving forged tools, so capability carries over between tasks.

Method vs predecessors

The novelty is in tool persistence and self-improvement rather than tool generation itself. Where predecessors stop at generate-and-use, MetaForge closes the loop with retrieve, adapt, forge, and retain, sitting in the same agent community (0) as PyVision and DeepEyesV2.
