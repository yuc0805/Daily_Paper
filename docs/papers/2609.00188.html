ZimaBlue: Evolving Generalizable World Action Models through Scalable Video Pre-training

Wu, Yang, Zhou, Sun, Liu, Yu, Zhang, Li, Qi, Duan (Joy Future Academy) · arXiv 2026 · link · arxiv_id: 2609.00188 · Appears in: World Model / RL, Video Action Recognition

What

ZimaBlue is a framework for learning World Action Models from large-scale video rather than from action-labelled robot data. Training proceeds in three stages: causal embodied video pre-training on human and robot egocentric video, video-action mid-training that grounds the learned visual dynamics in heterogeneous robot trajectories under a unified action representation, and specialization to a target robot for deployment. To make a generative world model usable for real-time control, an asynchronous slow-fast dual-system architecture pairs a high-capacity slow world model that supplies generalizable spatiotemporal representations with a lightweight fast branch that predicts actions at 30 Hz on an NVIDIA RTX 4090. On real-robot zero-shot evaluations, scaling from target-robot data alone to more than 120,000 hours of embodied video raises success from 36.1 percent to 77.8 percent, with the largest gains on unseen tasks.

Why

Robotic manipulation faces a supply problem rather than a modelling problem: robust generalization needs broad physical experience, and action-labelled robot trajectories are expensive to collect and narrow in the diversity they cover. Egocentric video is the opposite on both counts, abundant and diverse, capturing object interactions, contact dynamics, tool use, and long-horizon behaviour across many environments, but it carries no action labels, so it cannot be consumed by the standard imitation pipeline. Prior world-model work does not close this gap because it learns the model from the agent's own interaction data, which reintroduces the collection cost the video was meant to avoid. The second obstacle is practical: generative world models are too slow to close a control loop at useful rates, which has kept them out of deployed manipulation.

How

The curriculum separates learning dynamics from learning actions. Causal embodied video pre-training runs first on human and robot egocentric video with no action supervision, so the model learns how scenes evolve. Video-action mid-training then attaches control by grounding those dynamics in heterogeneous robot trajectories through a unified action representation that lets data from different robots contribute to the same model. Specialization to the target robot comes last. The slow-fast split decouples two rates that a single generative model conflates: the slow branch refreshes high-capacity spatiotemporal representations, while the fast branch consumes them and emits actions at 30 Hz, and the two run asynchronously so control frequency is not bounded by generation cost. The scaling evidence holds the action-labelled portion fixed and grows only the action-free corpus, which is what attributes the gain to the video.

Solves vs predecessors

Ha 2018 learned its world model from rollouts the agent collected itself, which caps the diversity of the model at the diversity of the agent's own exploration and reintroduces exactly the data cost that limits manipulation. ZimaBlue removes that dependency by learning dynamics from action-free human video, then paying the expensive labelled data only in a short grounding stage. Against DINO-WM, which takes a frozen visual representation as given and concentrates on planning in that latent space, the failure mode fixed is that a representation trained for recognition is not necessarily a representation of dynamics, so scaling the planner does not buy generalization to unseen tasks. The 36.1 to 77.8 percent zero-shot gain, obtained while the labelled set is held fixed, is the direct evidence for that.

Method vs predecessors

Where prior world models train dynamics and control jointly on interaction data, ZimaBlue orders them, learning dynamics without actions first and attaching a unified action representation second, which is what lets human video and multi-robot trajectories enter the same model. Where DINO-WM plans by search in a frozen latent space at inference, ZimaBlue trains a policy branch and pays no search cost per step, replacing planning compute with pre-training compute. The slow-fast asynchronous split is also new relative to all three predecessors, which run one model at one rate; separating representation refresh from action emission is what makes a generative world model run at 30 Hz on commodity hardware.
