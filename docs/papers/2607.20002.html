Post-Training in Time Series Foundation Models: A Unifying Framework

Xie, Odonnat, Xiao, Zan, Tiomoko, Pan, Palpanas, Oreshkin, Liu, Zhang · arXiv 2026-07-22 · arXiv:2607.20002 · Appears in: Signal/Time Series

What

Time series foundation models are pretrained once on broad collections of series and then reused, but pretraining alone does not give reliable behavior on a specific downstream dataset. This paper organizes the methods that sit between a pretrained model and its deployment into a single framework. It sorts post-training methods by where they act in the prediction pipeline, giving five families: parameter adaptation, context augmentation, model composition, output processing with uncertainty control, and compression with specialization. For each family it reviews representative methods, states their current limits, and lists open directions such as controlled adaptation, reliable context construction, uncertainty-aware composition, calibrated output processing, and deployment-aware specialization.

Why

Pretrained time series foundation models face domain shift, task heterogeneity, limited supervision, and compute limits when moved to a real task. A growing set of papers each propose one way to close this gap, but they are scattered and hard to compare because they intervene at different points: some change weights, some change the input context, some combine several models, some post-process outputs. Without a shared map, a practitioner cannot tell whether two methods compete or address separate problems. This paper supplies that map.

How

The organizing principle is the locus of intervention in the prediction pipeline. Parameter adaptation changes model weights (for example parameter-efficient tuning). Context augmentation adds information around the input without changing weights. Model composition combines a foundation model with other models or a language backbone. Output processing and uncertainty control adjust or calibrate the produced forecast. Compression and specialization shrink or narrow the model for deployment. Each family is reviewed with its representative methods and stated failure modes, and the paper closes with open directions per family.

Builds on

  • Chronos (Ansari 2024)A pretrained time series foundation model of the kind this framework post-trains; the "before" state the survey starts from.
  • TS-Agent (Liu 2025)An instance of context augmentation, where an LLM controller adds statistical evidence around a series rather than changing weights.
  • Time-LLM (Jin 2024)An instance of model composition and cross-modal alignment, reprogramming a language backbone for forecasting.

Solves vs predecessors

Individual method papers such as TS-Agent and Time-LLM each fix one problem for one pretrained model, but a reader cannot place them relative to each other or decide which to reach for under a given constraint. This paper fixes that specific gap: it shows that TS-Agent and Time-LLM answer different questions (what evidence surrounds the input versus how the backbone is reused) rather than competing on one axis, so the choice between them stops being a guess. It does not beat any single method; it removes the confusion of an unlabeled design space.

Method vs predecessors

Where Chronos delivers a pretrained model and each later paper adds one adaptation, this work adds no method and instead classifies methods by locus of intervention. Compared with a plain reading list, the framework is prescriptive: given a domain shift it points to parameter adaptation or context augmentation, given a compute limit it points to compression and specialization, and it marks which families still lack strong methods. The contribution is the axis of comparison, not a new model.
