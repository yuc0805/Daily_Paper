KVarN: Variance-Normalized KV-Cache Quantization Mitigates Error Accumulation in Reasoning Tasks

Huawei CSL · arXiv 2026-06-02 · arXiv:2606.03458 · Appears in: LLM

What

KVarN is a calibration-free KV-cache quantizer that applies Hadamard rotation followed by dual-scaling variance normalization across both axes of the K and V matrices. At 2-bit precision, it achieves 3-5x KV-cache capacity over FP16 while matching FP16 accuracy on reasoning benchmarks (MATH500, AIME24, HumanEval). It ships as a single vLLM flag with no calibration data required.

Why

Test-time scaling via long chain-of-thought reasoning improves accuracy but creates memory bottlenecks as the KV-cache grows during autoregressive decoding. Existing KV-cache quantization methods are evaluated under prefill-like settings where errors are bounded, but under autoregressive decoding, quantization errors accumulate across timesteps. The accumulation is driven primarily by incorrect token-level scales — a failure mode that current quantizers do not address.

How

KVarN first applies a Hadamard rotation to distribute outlier magnitudes across channels, then applies variance normalization with separate per-channel and per-token scales. The dual-scaling prevents any single token from dominating the quantization error, which is the root cause of error accumulation during autoregressive decoding. The method requires no calibration data and adds minimal computational overhead.

Builds on

  • DeepSeek-V3 (2024)Introduced Multi-head Latent Attention (MLA) for KV-cache compression at the architecture level; KVarN provides complementary compression at the quantization level.
  • DeepSeek-R1 (2025)Produces long reasoning traces that create the memory pressure KVarN addresses.

Solves vs predecessors

DeepSeek-V3's MLA compresses the KV-cache by projecting keys and values into a latent vector, reducing cache size at the architecture level. However, MLA requires training a model from scratch with the modified attention mechanism. KVarN works with any existing model — it is a post-training quantization method that can be applied to models already trained with standard attention, including DeepSeek-R1's reasoning traces.

Method vs predecessors

Where MLA (DeepSeek-V3) changes how the KV-cache is produced, KVarN changes how it is stored after production. The Hadamard-then-normalize pipeline is orthogonal to architectural choices: it could in principle be applied on top of MLA-compressed caches for further compression. The calibration-free property (no data needed, single flag) makes deployment much simpler than calibrated quantization methods.
