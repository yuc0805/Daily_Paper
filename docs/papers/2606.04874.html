Agent Planning Benchmark: A Diagnostic Framework for Planning Capabilities in LLM Agents

Sun, Wang, Song, He, Zhang, Liu, Yang, Cheng · arXiv 2026 · link · Appears in: Agent

What

APB is a planning-specific diagnostic benchmark with 4,209 multimodal cases across 22 domains and five settings that isolates planning failures from execution failures in LLM agent pipelines. It covers holistic planning, feedback-conditioned step-wise planning, and robustness under extraneous tools, broken tools, and unsolvable tasks.

Why

Existing agent benchmarks report only end-to-end success rates, making it impossible to tell whether a failure occurred because the agent made a bad plan or because it failed to execute a good plan. Without this diagnostic separation, improving agent systems is guesswork. Prior benchmarks also do not test calibrated refusal — whether the agent can recognize an unsolvable task and say so.

How

APB defines five evaluation settings with increasing difficulty. For each, it constructs task instances with known-correct plans and evaluates the agent's generated plan against that reference. The benchmark tests 12 multimodal LLMs and validates that APB-guided plan refinement (feeding APB diagnostic feedback back to the model) improves plan correctness and downstream execution on 200 ToolSandbox tasks and 200 tau-bench tasks.

Builds on

  • ADaPT (Prasad 2023)Proposed adaptive goal decomposition for agents; APB tests exactly this decomposition capability.
  • LATS (Zhou 2024)Combined tree search with LLM agents for planning; APB evaluates whether such search-based planners handle tool noise.
  • ToolkenGPT (Hao 2024)Addressed tool selection via embeddings; APB adds adversarial tool-noise robustness tests.

Solves vs predecessors

ADaPT, LATS, and ToolkenGPT proposed specific planning algorithms but evaluated them only on end-to-end task completion. APB provides the missing diagnostic layer: it can tell you that an agent's holistic planning is strong but its robustness to extraneous tools is weak, or that it plans well but refuses too infrequently on unsolvable tasks. This fine-grained feedback was not available from any prior benchmark.

Method vs predecessors

Where prior agent evaluations used a single pass-fail metric per task, APB introduces five orthogonal evaluation settings and scores plans independently of their execution. The benchmark design separates the planner from the executor, so the same diagnostic can be applied to any agent architecture regardless of its execution backend.
