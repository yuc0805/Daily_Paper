Agent Planning Benchmark (APB): A Diagnostic Framework for Planning Capabilities in LLM Agents

Sun, Wang, Song, He, Zhang, Liu, Yang, Cheng · arXiv 2026-06-03 · arXiv:2606.04874 · Appears in: Agent

What

APB is a planning-specific diagnostic benchmark with 4,209 multimodal cases across 22 domains and five settings. It separates planning failures from execution failures by testing holistic planning, feedback-conditioned step-wise planning, and robustness under extraneous tools, broken tools, and unsolvable tasks. Across 12 MLLMs, it reveals systematic weaknesses in long-horizon planning, tool-noise robustness, and calibrated refusal.

Why

Existing agent evaluations report only end-to-end success rates, making it impossible to determine whether failures stem from planning or execution. This conflation hinders targeted improvement. Furthermore, no prior benchmark systematically tests whether agents can refuse unsolvable tasks or handle noisy tool environments — both of which are critical for real-world deployment.

How

APB constructs cases across five settings: holistic planning (generate a full plan), step-wise planning with feedback, robustness under extraneous tools (irrelevant tools added), broken tools (tools that fail or return errors), and unsolvable tasks (tasks that cannot be completed with available tools). APB-guided refinement is validated on 200 ToolSandbox and 200 tau-bench tasks, showing consistent improvements in plan correctness and downstream execution metrics across three representative models.

  • LATS (Zhou 2024)Introduced tree search for agent planning; APB tests whether tree-search-style planning survives noisy environments.
  • Agent AI Survey (Durante 2024)Comprehensive survey of agent architectures; APB provides the diagnostic evaluation framework that the survey identified as missing.

Solves vs predecessors

ADaPT and LATS proposed planning algorithms but evaluated them on narrow task suites with clean tool environments. APB creates adversarial conditions — extraneous tools, broken tools, unsolvable tasks — that expose failure modes invisible in standard evaluations. The key new finding is that calibrated refusal (knowing when to say "this cannot be done") is systematically weak across all tested models, including frontier ones.

Method vs predecessors

Unlike ADaPT and LATS which are planning algorithms, APB is a diagnostic benchmark — it evaluates planning capability rather than proposing a new planning method. The five-setting design (holistic, step-wise, extraneous, broken, unsolvable) is more comprehensive than any prior agent benchmark. The validation on ToolSandbox and tau-bench shows that APB scores predict downstream execution success, establishing APB as an upstream diagnostic complement.
