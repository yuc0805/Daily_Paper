Hierarchical Sparse Attention Done Right: Toward Infinite Context Modeling (HiLS-Attention)

Hu, Wei, Gu, Zhang, Liang et al. (Tencent Hunyuan) · arXiv 2026 · arXiv:2607.02980 · Appears in: LLM

What

HiLS-Attention is a chunk-wise sparse attention that learns which chunks of the past to read directly from the language-modeling loss. Each query attends to each retrieved chunk on its own, and the per-chunk outputs are fused using retrieval scores that sit inside the forward attention, so those scores receive gradients and the retrieval is trained end to end. At in-domain context lengths it matches full attention, and it extrapolates to more than 64 times the training context length while keeping 90% retrieval accuracy. An existing full-attention model can be converted with light continued pretraining (about 50B tokens in the released 7B model).

Why

Scaling language models to long contexts is limited by the quadratic cost of dense attention and by poor length extrapolation past the training length. Chunk-wise sparse attention is cheaper, but earlier versions pick the wrong chunks often enough that they stay below full attention in quality. The missing piece was a way to learn chunk selection from the main training loss rather than from a separate fixed rule.

How

HiLS factorizes attention hierarchically. Each query attends independently with each retrieved chunk to extract chunk-specific information, then the outputs are combined according to chunk retrieval scores. Because the retrieval scores enter the forward attention computation, they are optimized directly by the language-modeling loss, giving end-to-end retrieval learning and native sparse training. Sparse key-value access keeps memory and compute low at long context, and the mechanism can be grafted onto a pretrained full-attention model through light continued pretraining.

Builds on

  • Attention Is All You Need (Vaswani 2017)Dense self-attention over all tokens; HiLS keeps the operator but learns to route each query to a few chunks.
  • iTransformerNearest time-series neighbor; applied attention across variables, while HiLS attacks the time axis that grows without bound.

Solves vs predecessors

Dense attention from the original Transformer cannot reach very long contexts because cost grows with the square of the length and quality drops past the training length. HiLS-Attention fixes both at once: sparse key-value access removes the quadratic cost, and learned chunk selection gives extrapolation to more than 64 times the training length, a regime where full attention fails.

Method vs predecessors

Earlier chunk-wise sparse attention chose chunks with a fixed scoring rule outside the main objective, so selection errors capped quality below full attention. HiLS instead places the retrieval scores inside the forward pass and trains them with the language-modeling loss, so the model learns its own retrieval. Against iTransformer, which re-purposed attention across the variable axis for forecasting, HiLS keeps the standard token axis but makes attention sparse and length-extrapolating.
