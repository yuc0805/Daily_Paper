RISE: Recursive Improvement via Self-Extrapolating Policy Distillation

Li, Yavuz, Joty (Salesforce AI Research) · arXiv 2026-09-04 · arXiv:2609.05295 · Appears in: Reasoning

What

RISE constructs a synthetic teacher directly from a model's own reinforcement learning trajectory. It measures the displacement between the current checkpoint and a trailing anchor checkpoint, in parameter space or in output logit space, and extrapolates along that direction, which converts a sparse outcome-induced parameter update into a dense token-level target with no external model and no privileged conditioning. Outcome rewards from RLVR ground the extrapolation toward correct reasoning while the extrapolated teacher refines token-level decisions, and the teacher is refreshed each iteration as the student improves. Across mathematical reasoning, multi-domain STEM, code generation and multi-turn agentic tasks, the method beats both RLVR-only training and on-policy self-distillation.

Why

On-policy distillation supplies dense per-token supervision for post-training, which is the property outcome-reward RL lacks, but its effectiveness is capped by the teacher. An external teacher introduces a distribution mismatch, since it was never trained on the states the student actually visits. Self-distillation with privileged conditioning avoids that mismatch but is limited by how much the model can exploit in context, so the teacher is only marginally better than the student. Both routes leave the same gap open: RLVR produces one bit of signal per rollout and has to spread it over an entire trajectory, and no existing teacher construction closes that density gap without importing an outside model.

How

The insight is that the displacement between two checkpoints of the same RL run already encodes the direction the reward was pushing the policy at every token, not merely at the graded outcome. Extrapolating past the current checkpoint along that displacement therefore yields a model that is a plausible improvement on the student while remaining on the student's own distribution, which is exactly the teacher on-policy distillation needs. The extrapolation is performed in parameter space or in logit space, and the resulting teacher supplies token-level targets that are combined with the ongoing RLVR objective. Because the anchor advances as training proceeds, each iteration builds a fresh teacher from the improved student, making distillation a recursive loop rather than a single compression step.

Solves vs predecessors

DeepSeek-R1 turns a sparse outcome reward into a parameter update and stops there, so every token in a long trajectory receives credit only through that single scalar. The specific failure this fixes is credit density: RISE reads the same update as a direction and steps further along it to manufacture per-token targets, so one graded outcome becomes supervision at every position. Relative to the on-policy distillation analysis added to this library on 2026-09-05, which concluded the bottleneck lies in the algorithm rather than in data volume, RISE accepts that diagnosis and replaces the teacher rather than the data, which is the intervention that diagnosis implies.

Method vs predecessors

Standard on-policy distillation obtains a teacher by picking a stronger model or by conditioning the same model on privileged information, and in both cases the teacher is a separate object from the training run. RISE takes the training run itself as the teacher's source, which removes the distribution mismatch by construction because the extrapolated point lies on the student's own optimisation path. Against Chain-of-Thought the contrast is where the reasoning improvement is stored: prompting elicits a better trace from a fixed model at inference, while RISE writes the improvement into the weights and does so using a signal the RL run was producing anyway. The cost of the approach is that it inherits whatever systematic bias the trajectory carries, since extrapolation amplifies the direction it is given without any independent check on whether that direction is correct.
