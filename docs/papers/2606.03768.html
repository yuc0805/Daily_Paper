HybridThinker: Efficient Chain-of-Thought Reasoning via Compressed Memory and Transient Thought Steps

Liu, Zhao, Liu, Ruan, Huang, Dong, Xiao, Wang, Li, Zhu, Xiao · arXiv 2026 · link · Appears in: Reasoning

What

HybridThinker compresses chain-of-thought traces by encoding completed reasoning steps into compact memory tokens while temporarily retaining the original thought steps for fine-grained detail access. A hybrid training scheme randomly masks some thought steps while keeping others accessible, preventing the model from bypassing memory compression.

Why

Extended CoT traces from reasoning models like DeepSeek-R1 can run to thousands of tokens, creating substantial computational and memory costs. Prior compression methods either truncate traces (losing information) or replace all thought steps with memory tokens (losing fine-grained detail needed for subsequent steps). Neither approach preserves both long-range recall and local detail.

How

Each completed thought step is compressed into a fixed set of memory tokens via a learned compression function. The original thought step text is also temporarily retained in the attention window. During training, a random subset of thought steps is masked (forcing the model to use only memory tokens for those steps), while the rest remain visible. This hybrid masking prevents the model from bypassing compression by always reading the original text. At inference, thought steps are retained temporarily and then dropped after the next step consumes them.

Builds on

  • Chain-of-Thought Prompting (Wei 2023)Established explicit reasoning traces as the format that HybridThinker compresses.
  • DeepSeek-R1 (2025)Produces the long reasoning traces (thousands of tokens) that create the efficiency problem this paper addresses.

Solves vs predecessors

Prior CoT compression methods faced a dilemma: fully replacing thought steps with memory tokens loses fine-grained information (subsequent reasoning steps become error-prone), but keeping all steps defeats the purpose of compression. HybridThinker resolves this by keeping both representations simultaneously and using hybrid training to ensure the model actually learns to use the compressed form.

Method vs predecessors

Where prior compression methods used a single modality (either full text or compressed tokens), HybridThinker uses dual representation with stochastic masking during training. The hybrid training scheme is the key methodological contribution: it is a form of dropout applied at the thought-step level rather than the neuron level, forcing the model to build robust compressed representations.
