Language Models Need Sleep

Lee, McLeish, Goldstein, Fanti · arXiv 2026 · link · Appears in: Mamba / SSM, LLM

What

A sleep-like consolidation mechanism for language models. During waking inference, the model uses standard transformer attention with a KV cache. Periodically, it enters a sleep phase where N offline recurrent passes distill accumulated context into persistent fast weights in SSM blocks via a learned local update rule. After consolidation, the KV cache is cleared. Performance scales with sleep duration N, with disproportionate gains on deeper reasoning tasks such as multi-hop graph retrieval and mathematical problem solving.

Why

Transformer attention provides rich context processing but at quadratic memory cost. SSM recurrence is memory-efficient but has limited representational capacity per step. Existing hybrid architectures interleave both in the same forward pass, forcing a fixed tradeoff. This paper proposes a temporal separation: attention does the heavy lifting during active processing, then sleep consolidation compresses the results into SSM state. This allows indefinite-length processing with bounded memory while preserving the quality of attention-derived representations.

How

The architecture augments a standard transformer with SSM blocks (Mamba-style). During waking inference, the model processes input normally, building a KV cache. When the sleep trigger fires (based on cache size or a scheduled interval), the model enters a sleep phase: it performs N recurrent passes over the cached context, updating SSM fast weights through a learned local rule. The local rule is parameterized as a small neural network that takes the current SSM state and the attention-derived context vector as input and outputs a weight update. After N passes, the KV cache is flushed. Subsequent waking inference reads from the updated SSM state as persistent memory. Training uses a combination of standard language modeling loss during waking and a consolidation loss during sleep that measures information retention after cache clearing.

Solves vs predecessors

Standard transformers (Vaswani et al.) face quadratic KV cache growth with sequence length. Hybrid attention-SSM models like HARMamba process both modalities simultaneously, which constrains the SSM component to operate within the same forward pass as attention. This paper solves both issues: the KV cache is periodically cleared (bounding memory), and the SSM component operates asynchronously during offline sleep passes (removing the simultaneity constraint). The result is a system where the quality of attention-based reasoning is preserved while the memory footprint remains bounded.

Method vs predecessors

Where HARMamba and similar hybrids interleave attention and SSM layers within each forward pass, this paper introduces a temporal phasing: attention-only during waking, SSM-update-only during sleep. The learned local update rule for SSM fast weights is also novel — previous SSM-based models used fixed or globally trained recurrence parameters, not a context-dependent local rule that adapts the state based on what was accumulated during waking inference.
