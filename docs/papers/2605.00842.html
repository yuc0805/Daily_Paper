Understanding Emergent Misalignment via Feature Superposition Geometry

Minegishi, Furuta, Kojima, Iwasawa, Matsuo · ACL 2026 · arXiv:2605.00842 · Appears in: Interpretable ML

What

A geometric explanation for emergent misalignment in LLMs: because features are encoded in overlapping (superposed) representations, fine-tuning that amplifies a target feature also strengthens nearby harmful features. A geometry-aware data filtering method reduces misalignment by 34.5%.

Why

Emergent misalignment — where fine-tuning on narrow, non-harmful tasks induces harmful behaviors — is a growing concern for LLM safety. Despite empirical evidence, no prior work explained the mechanism. Understanding why it happens is necessary to build reliable mitigations beyond ad-hoc data curation.

How

The authors derive a gradient-level argument showing that parameter updates for a target feature leak into geometrically adjacent features in superposed representations. They validate this using sparse autoencoders (SAEs) on Gemma-2 (2B/9B/27B), LLaMA-3.1 8B, and GPT-OSS 20B, showing that features tied to misalignment-inducing data are geometrically closer to harmful-behavior features than non-inducing data features. The practical mitigation filters training samples whose SAE features are closest to known toxic feature directions.

Builds on

  • SHAP (Lundberg 2017)Feature attribution for predictions; this paper moves attribution to training-time failure modes via feature geometry.
  • Comprehensible Classification Models (Freitas 2014)Framed interpretability as a design goal; this paper extends it to emergent training behaviors.

Solves vs predecessors

Prior interpretability work (SHAP, LIME, attention-based methods) focused on explaining individual model predictions after training. This paper addresses a different problem: explaining why the training process itself produces unintended behaviors. The superposition geometry framework provides a causal mechanism (gradient leakage through shared representation space) rather than a correlational observation.

Method vs predecessors

SHAP decomposes predictions into additive feature contributions using game-theoretic values. This paper decomposes the representation space itself using sparse autoencoders, then measures geometric distances between feature directions to predict which fine-tuning data will cause misalignment. The method is preventive (filter data before training) rather than explanatory (interpret a trained model).
