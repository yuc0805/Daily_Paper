HiMAE: Hierarchical Masked Autoencoders Discover Resolution-Specific Structure in Wearable Time Series

Lee, Tanade, Zhou, Lee, Thukral, et al. (Samsung Research America) · arXiv 2025-10-28 · arXiv:2510.25785 · Appears in: Signal/Time Series

What

HiMAE is a self-supervised framework for wearable physiological time series. It pairs masked autoencoding with a hierarchical convolutional encoder-decoder shaped like a U-Net, so it produces several embeddings at once, one per temporal scale, instead of a single collapsed embedding. Linear probes on each level then measure which resolution carries predictive signal for a given task, which turns resolution from a hyperparameter into a measurement tool. The model is small enough to run entirely on a smartwatch-class CPU with sub-millisecond inference.

Why

Wearable sensors produce long signals, but the field does not know which temporal scales carry the structure that downstream health tasks depend on. Most self-supervised models pick one resolution and collapse everything to it, which hides the question rather than answering it. Clinically meaningful events can arise at second-level timescales while other outcomes depend on slow dynamics, so a single universal resolution is an assumption rather than a finding. The paper sets out to test whether resolution is a real axis of representation learning and to build a model that exposes scale-specific structure instead of averaging it away.

How

The encoder is a hierarchy of convolutional stages, each producing an embedding at a coarser temporal granularity, trained by masked reconstruction of the input signal. The convolutional bias is deliberate: the authors argue wearable signals are long but low-dimensional and highly structured, so a transformer can overfit and blur scale-specific structure rather than reveal it. After pretraining, a linear probe at each hierarchy level reports how much predictive signal that scale holds, across 14 classification and regression tasks plus generative benchmarks. HiMAE reports state-of-the-art accuracy while being orders of magnitude smaller than foundation models that collapse scale.

Solves vs predecessors

MAE and How Mask Matters produce a single embedding from a flat encoder, which answers "how do I compress the signal" but not "at which temporal scale does this outcome live". HiMAE fixes that specific gap: by making each hierarchy level a distinct resolution and probing each one, it converts the masked-autoencoder into a discovery tool that names the scale carrying predictive signal. Relative to HARMamba, which also targets efficient wearable modeling, HiMAE solves the additional problem of interpretability across scales, which the state-space backbone does not address.

Method vs predecessors

Compared to flat MAE, HiMAE replaces the single encoder with a U-Net-style convolutional hierarchy and reads out one embedding per level rather than one global embedding. Compared to HARMamba's state-space sequence model, HiMAE uses convolutional receptive-field growth for efficiency and adds a per-level linear probe as an explicit measurement instrument. It sits in the same Health AI and Self-Supervised community as the SSL-for-HAR anchor in the library, but where that work scaled the dataset, HiMAE scales the analysis of which resolution matters.
