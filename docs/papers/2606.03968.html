QUBRIC: Co-Designing Queries and Rubrics for RL Beyond Verifiable Rewards

Zhang, Feng, Zhang, Yang, Yin, Liu, Zhang, Nigam, Yin, Zhao, Zhang · arXiv 2026 · link · Appears in: Reasoning

What

QUBRIC extends rubric-based reinforcement learning to tasks without verifiable answers by co-designing queries and rubrics. It rewrites open-ended queries into scenario-based evaluable questions, generates contrastive rubrics from teacher-policy gaps, and filters for learnability before GRPO training.

Why

RL for LLM reasoning has been most successful on tasks with verifiable rewards (math, code). Extending RL to open-ended tasks requires rubric-based rewards, but rubric quality is constrained by query structure: open-ended queries yield vague rubrics, and naively narrowing queries introduces fabricated references that cause all responses to fail (zero reward signal).

How

Teacher-derived key points ground the rewriting of open-ended queries into scenario-based, evaluable questions. Contrastive rubric generation turns teacher-policy gaps into query-level criteria. A learnability filter retains only informative query-rubric pairs for GRPO training. The framework is trained only on instruction-following data but transfers to held-out benchmarks spanning legal, moral, and narrative reasoning.

Builds on

  • DeepSeek-R1 (2025)Demonstrated RL for reasoning with verifiable rewards; QUBRIC extends this to non-verifiable tasks.
  • Chain-of-Thought Prompting (Wei 2023)Established the reasoning trace format that GRPO-based methods optimize.

Solves vs predecessors

DeepSeek-R1 relied on verifiable rewards (math answers, code test cases) which do not exist for most real-world reasoning tasks. Prior rubric-based RL methods optimized rubrics while treating the query distribution as fixed, leading to vague or impossible evaluation criteria. QUBRIC solves this by jointly optimizing queries and rubrics, ensuring that the evaluation criteria are both specific and achievable.

Method vs predecessors

Where DeepSeek-R1 used outcome-based verification and prior rubric methods fixed query structure, QUBRIC introduces a three-stage pipeline: query rewriting via teacher key points, contrastive rubric generation from teacher-policy gaps, and learnability filtering. The contrastive rubric generation is the key methodological contribution — it produces criteria that discriminate between good and bad responses rather than just listing desirable properties.
