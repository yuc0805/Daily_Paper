GRAIL: Gradient-Reweighted Advantages for RL with Verifiable Rewards

Pala, Toh, Poria · arXiv 2026 · link · Appears in: Reasoning

What

A token-level advantage reweighting method for reinforcement learning with verifiable rewards (RLVR). GRAIL computes gradient-activation saliency for each generated token — measuring how much that token influenced the verified outcome — and uses these saliency scores to reweight per-token advantages during policy optimization. It outperforms GRPO by 3.60% accuracy and 3.05% Pass@3 without requiring a process reward model.

Why

GRPO and similar RLVR methods assign uniform credit across all tokens in a response, treating a filler word and a critical reasoning step as equally responsible for the outcome. This is a coarse approximation. Process reward models (PRMs) can provide finer-grained credit, but they require expensive step-level annotations and separate model training. GRAIL provides token-level credit assignment using only gradient information from the policy itself, avoiding the PRM overhead entirely.

How

For each generated response, GRAIL computes the product of the gradient of the verified reward with respect to each token's hidden activation and the activation magnitude itself — a standard saliency measure from interpretability research. These saliency scores are normalized across the response to produce per-token weight coefficients. During GRPO-style policy optimization, the standard uniform advantage for each response is multiplied by these per-token weights before computing the policy gradient. Tokens with high saliency (those most responsible for the correct or incorrect outcome) receive proportionally larger gradient updates. The method adds negligible computational overhead beyond the backward pass that is already computed during training.

Builds on

  • DeepSeek-R1Introduced GRPO for reasoning with verifiable rewards, providing the baseline that GRAIL improves upon.
  • Chain-of-Thought PromptingEstablished that intermediate reasoning steps affect final answers, motivating the need for per-step credit assignment.

Solves vs predecessors

GRPO assigns uniform credit, which means tokens that merely restate the question or produce filler receive the same training signal as tokens that perform the key reasoning step. Process reward models fix this but at the cost of training a separate model on step-level annotations. GRAIL achieves token-level credit assignment without any additional model or annotation, using only gradient information that is already computed during training.

Method vs predecessors

The technical departure from GRPO is the per-token saliency reweighting. Instead of a single advantage value per response, each token gets advantage multiplied by its normalized gradient-activation saliency. This is conceptually similar to attention-based interpretability methods but applied in the RL training loop rather than post-hoc analysis. Compared to process reward models, the saliency computation is orders of magnitude cheaper because it reuses the existing backward pass.
