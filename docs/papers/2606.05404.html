TimeClaw: Harnessing Generalist Agents for Contextualized Time Series

Li, Jin, Bei, Zou, Kumar, Ning, Zhao, Ai, Jing, Tong, He · arXiv 2026-06-03 · arXiv:2606.05404 · Appears in: Signal/Time Series

What

TimeClaw is an agentic harness that gives a generalist LLM agent time-series-native runtime support. It combines executable temporal tools for grounded and auditable analysis, experience-driven capability evolution that turns successful trajectories into reusable analytical routines, and episodic multimodal memory that retrieves relevant past reasoning traces. Evaluation spans energy, finance, weather, traffic, and other real-world domains; code is public at github.com/iDEA-iSAIL-Lab-UIUC/TimeClaw.

Why

Time series are embedded in rich contexts, and practitioners run end-to-end workflows where forecasting is only one step. Generalist LLM agents are a natural interface for such workflows but operate primarily in text space, which is not aligned with structured temporal signals. Prior single-loop tool agents handle one reasoning episode at a time and relearn the same analysis on every new task, while alignment-trained models require paired data and training compute.

How

The harness wraps a frozen generalist agent with three runtime services. Executable temporal tools keep every numerical claim grounded in an auditable operation on the raw series. A capability-evolution loop promotes successful reasoning trajectories into reusable analytical routines, so the agent accumulates competence across tasks. An episodic multimodal memory stores reasoning traces and retrieves relevant ones for new queries. The abstract reports improved benchmark performance but no numeric deltas; the preprint runs 38 pages.

Solves vs predecessors

TS-Agent's loop is stateless across tasks: the operator library is fixed and nothing learned in one episode carries to the next, so repeated workflows pay full cost every time. TimeClaw fixes this by making experience persistent in two forms — reusable routines distilled from successful trajectories, and episodic memory of past reasoning traces — while keeping the auditability that motivated the tool-calling design in the first place.

Method vs predecessors

Compared to TS-Agent, TimeClaw widens the integration boundary from one operator loop to a full runtime: tools, a routine library that grows, and a retrieval memory. Compared to ChatTS, it avoids alignment training entirely and keeps capability outside the model. The memory component is the clearest import from the agents literature (community 0) into time series (community 4), adding a cross-community edge to the library graph.
