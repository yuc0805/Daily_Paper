CAST: Game Solvers as Turn-Level Teachers for LLM Agents

CAST authors · arXiv 2026 · link · Appears in: Reasoning

What

CAST adds dense turn-level credit to reinforcement learning from verifiable rewards (RLVR) for LLM agents in long-horizon games. It observes that a game solver's state-value estimate already tells you whether an action helped: when the solver's value rises after an action, that action advanced the state toward success. CAST (Credit Assignment from Solver Teachers) converts these value changes into per-turn solver advantages and injects them into RLVR as dense feedback.

Why

Training LLMs to act in long-horizon games with RLVR relies on a reward that arrives only at the end, which reveals little about which individual turns determined success. Denser process signals could fill this gap, but existing sources of turn-level signal are hard to keep both cheap and accurate. CAST supplies a cheap, accurate source from a solver already available in game settings.

How

The solver's value change at each turn becomes a solver advantage added to the RLVR objective. Under a soft-optimal solver assumption, maximizing the solver advantage is equivalent to on-policy distillation from the solver, and it requires only scalar values rather than the teacher's full logits, which keeps the signal cheap to compute and store.

Builds on

  • DeepSeek-R1 (2025)RLVR with sparse final rewards; CAST keeps the frame and adds a dense per-turn term.
  • LATS (Zhou 2024)Uses value estimates at search time; CAST uses solver value changes at training time.
  • Chain-of-Thought Prompting (Wei 2023)Reasoning via prompting; CAST supervises the reasoning trace at the process level.

Solves vs predecessors

DeepSeek-R1's sparse terminal reward is exactly what makes long-horizon credit assignment hard: the model cannot tell which turn mattered. CAST fixes this by supplying a dense per-turn advantage, so the gradient carries process-level information rather than only the final outcome.

Method vs predecessors

Where LATS applies a value estimate at search time to steer tree rollouts, CAST applies a solver's value changes at training time to shape the policy gradient. Where R1 trains from outcome-only verifiable rewards, CAST reframes solver-advantage maximization as on-policy distillation using scalar values, avoiding the cost of matching teacher logits.
