Group Entropy-Controlled Policy Optimization (GEPO)

InternLM (Intern Large Models) · arXiv 2026 · link · Appears in: Reasoning

What

GEPO is a lightweight extension of GRPO for reasoning RL. It estimates per-group entropy from grouped samples already drawn and shapes advantages asymmetrically: it damps positive advantages in low-entropy groups to reduce over-exploitation and damps negative advantages in high-entropy groups to preserve exploration. The extra cost is small because the entropy estimate reuses existing rollouts.

Why

RL fine-tuning runs on mixtures of tasks that sit in different entropy regimes under one policy, so a single global or token-level entropy control cannot match all of them. GRPO's normalized advantages also pick up an entropy-dependent bias, which makes advantage signals across prompt groups statistically not comparable. A method is needed that adapts exploration pressure per group without a heavy extra pass.

How

GEPO conditions advantage shaping on the entropy of each prompt group. Low-entropy groups (the policy is already confident) get their positive advantages attenuated so the model does not over-commit; high-entropy groups (still uncertain) get their negative advantages attenuated so useful exploration is not punished. Because the entropy is read off the grouped samples GRPO already produces, the change adds little compute.

Builds on

  • DeepSeek-R1 (2025)Made GRPO-style reward RL the standard reasoning recipe; GEPO refines its advantage normalization.
  • DeepSeek-V3 (2024)Base-model lineage behind the R1 reasoning recipe.

Solves vs predecessors

DeepSeek-R1 applied one reward-normalization scheme uniformly, which treats an easy low-entropy prompt and a hard high-entropy prompt as if they need the same exploration pressure. GEPO fixes the resulting entropy-dependent bias so advantage signals become comparable across groups, which stabilizes training on heterogeneous task mixtures.

Method vs predecessors

Where R1's GRPO normalizes advantages within a group but ignores how confident that group is, GEPO makes the shaping a function of group entropy. It is the same reward-RL backbone with an entropy-conditioned correction rather than a new optimizer.
