SenseNova-U1.5: Towards Native Unified Visual Intelligence

Diao, Wang, Ding, Deng, Chen et al. (65 authors) · arXiv 2026-09-10 · arXiv:2609.11929 · Appears in: Multi-Modal

What

SenseNova-U1.5 is an 8B mixture-of-transformers model that understands, reasons about and generates visual content inside a single architecture with no separate vision encoder and no variational autoencoder. Its visual interface is trained by spatially coherent patch reconstruction at native resolutions up to 4K. Post-training optimizes separate experts for visual aesthetics, bilingual text rendering, infographic generation and image editing, then consolidates those capabilities through multi-expert on-policy distillation.

Why

A model that reads images and a model that makes them have historically been joined by an interface: a frozen vision encoder feeding a language model, or a variational autoencoder supplying a latent space for a diffusion backbone. Each interface is a place where the representation used for understanding and the representation used for generation stop being the same thing, which limits how much the two capabilities can support each other. The concrete symptom is that models generate well but follow complex structured instructions poorly, because the instruction is parsed in one representation and rendered in another.

How

The model predicts image patches directly in the same transformer stream that handles text, with a spatially coherent patch reconstruction objective standing in for what an autoencoder would otherwise provide. Training scale comes from curated generation and editing data, reformulated tasks, structural prompt enhancement, and support for native resolutions rather than fixed-size crops. Post-training runs specialist optimization per capability and then folds the specialists back into one model by on-policy distillation, so serving does not require several experts. Training code covering supervised finetuning, reinforcement learning and on-policy distillation is stated as forthcoming.

Builds on

  • BLIP-2 (Li 2023)The frozen-vision-encoder bridging design that "encoder-free" is defined against.
  • Stable Diffusion (Rombach 2022)The latent-diffusion pipeline whose variational autoencoder this architecture removes.
  • DiT (Peebles 2023)Established the transformer as a generative backbone, but kept the autoencoder that this work also drops.

Solves vs predecessors

BLIP-2 attaches a pretrained vision encoder to a frozen language model through a learned bridge, which gives understanding without giving generation, and Stable Diffusion generates inside a variational autoencoder's latent space, which gives generation without giving understanding. The shared failure mode is that structured instruction following falls between the two: a model that parses a layout instruction in one representation must hand it across an interface to something that renders. Removing both interfaces is the fix proposed here, and the evidence offered is generalization rather than fidelity, since the model handles long, complex and structured visual instructions despite little structured data in its generation training.

Method vs predecessors

DiT took the partial step, swapping the U-Net for a transformer while keeping the variational autoencoder, so the generative backbone unified but the representation did not. SenseNova removes the autoencoder as well and pays for it with the patch reconstruction objective, which is what supplies the spatial structure the autoencoder used to provide. The other difference is in post-training: instead of a single reinforcement learning stage, capability-specific experts are trained and then merged by on-policy distillation, which is a way to get specialist quality without serving specialist models. The claim that this path is better than a strong interfaced pipeline rests on the transfer result, so that is the part to check against the fidelity tables when the code is released.
