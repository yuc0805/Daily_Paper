Stop When Reasoning Converges: Semantic-Preserving Early Exit for Reasoning Models

Min, Vaccarino, Chen, Wu, Yona, Cheng (UIC, Google Research, UIUC) · arXiv 2026 · paper · Appears in: Reasoning

What

A semantic-preserving early exit method for large reasoning models that detects when chain-of-thought reasoning has converged by measuring semantic similarity between consecutive reasoning windows. When successive steps stop introducing new information, generation stops early.

Why

Large reasoning models (e.g., DeepSeek-R1) often generate far more reasoning tokens than needed, continuing to think after the solution has stabilised. Existing early-exit methods use answer-level signals like trial-answer consistency, but these can trigger prematurely during self-correction. No prior method distinguishes genuine convergence from premature answer stability.

How

The method measures semantic similarity between consecutive windows of reasoning tokens using an embedding model. When the similarity exceeds a threshold for several consecutive windows, the method infers that the reasoning trajectory has converged — successive steps are repeating established conclusions rather than introducing new progress. At that point, generation is terminated early. The threshold is calibrated to avoid cutting off genuine self-correction.

Builds on

  • DeepSeek-R1 (DeepSeek-AI 2025)The reasoning model whose overthinking behavior this method addresses.
  • Chain-of-Thought Prompting (Wei 2023)Established the reasoning-via-generation paradigm that early exit optimises.

Solves vs predecessors

Chain-of-Thought introduced explicit reasoning traces but had no mechanism to control their length. DeepSeek-R1 trained reasoning via RL but also lacks adaptive stopping. This paper provides an inference-time stopping criterion that preserves answer quality while reducing token waste.

Method vs predecessors

Where CoT uses fixed-length reasoning and DeepSeek-R1 generates until an end token, this method monitors the semantic content of the reasoning process itself. The key difference from answer-based early exit is that it tracks reasoning novelty rather than answer stability, avoiding premature exit during active self-correction phases.
