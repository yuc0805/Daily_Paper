Human-Inspired Memory Architecture for LLM Agents

arXiv 2026-05-08 · arXiv:2605.08538 · Appears in: Agent

What

A biologically grounded memory architecture for LLM agents with six cognitive mechanisms: sleep-phase consolidation, interference-based forgetting, engram maturation, reconsolidation upon retrieval, entity knowledge graphs, and hybrid multi-cue retrieval.

Why

Current LLM agents lack principled mechanisms for managing persistent memory across long interaction horizons. Most approaches either stuff everything into the context window (which does not scale) or use retrieval-augmented generation (which treats memory as a flat key-value store without consolidation or forgetting). The Rethinking Memory Mechanisms survey (Huang 2026) identified these architectural gaps but did not propose concrete solutions.

How

The architecture implements each cognitive mechanism as a modular component. Sleep-phase consolidation runs offline between episodes to merge and compress related memories. Interference-based forgetting removes memories that conflict with newer, more reliable information. Engram maturation gradually increases the stability of memories that are repeatedly accessed. Reconsolidation allows memories to be updated when they are retrieved in new contexts. An entity knowledge graph maintains structured relations, and hybrid multi-cue retrieval combines semantic similarity with temporal recency and frequency cues.

Solves vs predecessors

Huang 2026 identified that current agents treat memory as either a growing context window or a flat retrieval store, with no mechanism for consolidation, forgetting, or maturation. This paper directly implements those missing mechanisms as concrete architectural modules, turning Huang's survey-level observations into a working system.

Method vs predecessors

Compared to LATS's within-episode search state and ADaPT's within-episode task decomposition, this architecture operates across episodes. Compared to standard RAG-based memory (retrieve top-k similar memories), this system adds temporal decay, interference resolution, and offline consolidation. The cognitive science grounding differentiates it from purely engineering-driven memory designs.
