CARDEA: Auditable Reasoning Grounded in Spatial Evidence for End-to-End Coronary Angiography Interpretation

Lee, Hou, Ng, Wang, Chang · arXiv 2026-09-07 · arXiv:2609.06931 · Appears in: LLM-Health

What

CARDEA is a unified large vision-language model that runs a coronary angiography pipeline end to end, from raw multi-view video through keyframe selection to two study-level diagnoses, dominance classification and complexity assessment. Its reasoning trace is required to cite bounding boxes, a scheme the authors call Chain-of-Box, so a clinician can see which image regions a conclusion rests on. It was trained only on public datasets and only on closed-ended tasks; report generation was held out of training entirely and evaluated zero-shot on an external cohort.

Why

Coronary angiography is the reference standard for diagnosing coronary artery disease, but readings differ substantially between observers. Existing systems improve consistency and then stop at a prediction, leaving the intermediate reasoning unavailable for inspection. A clinician cannot check a number, which limits adoption regardless of accuracy. Prior interpretability work in medical imaging produces saliency maps after the fact, which explain a model's attention but are not the object the model was optimized to produce, so they can disagree with the stated reasoning.

How

Training runs in three stages. Visual feature alignment fits the model to coronary angiography features. A self-distilled Chain-of-Box cold start synthesizes box-citing reasoning traces from the model itself rather than from human annotation, which avoids the cost of collecting traces. Reinforcement learning with verifiable rewards then optimizes against the closed-ended labels, with an added Chain-of-Box reward that pays for bounding-box use inside the reasoning trace. The verifiable part of the reward is the closed-ended answer, and the box reward shapes where the model looks while getting there.

  • UNI: General-Purpose Self-Supervised Model for Pathology (Chen 2023)The medical-imaging foundation-model alignment recipe that the first training stage follows.
  • Foundation Models for Biosignals: A Survey (Gu 2025)Names auditability as the blocking issue for clinical adoption; this is one concrete answer to that.

Solves vs predecessors

UNI produces strong pathology representations and stops at the representation, so any downstream diagnosis is still a number with no inspectable derivation. DeepSeek-R1 produces long reasoning traces, but the trace is natural language, and a natural-language justification in a medical image setting can be fluent and still not correspond to anything in the image. CARDEA fixes that specific failure by making the trace cite bounding boxes, which are checkable against the image in a way sentences are not. The result that supports the design is a transfer effect: only the verifiable-reward stage raised zero-shot report generation, to 0.686 vessel-severity macro-F1 from 0.513 for the untuned base model, against an always-normal floor of 0.312. Supervised imitation on the same closed-ended tasks did not produce that lift.

Method vs predecessors

Against DeepSeek-R1, the reward is composite rather than purely outcome-based: correctness plus a behavioral term for box use, which is a way of shaping the reasoning process without step-level labels. Against UNI, the pipeline extends past representation learning into an end-to-end system that selects keyframes and emits study-level conclusions. The accuracy is not free. CARDEA trailed a dedicated classifier on in-distribution dominance classification and only drew level under domain shift, at 0.91 accuracy with a 95 percent confidence interval of 0.86 to 0.95, and matched two interventional cardiologists on complexity assessment at 0.90 accuracy. The paper is explicit that clinical use would require prospective validation.
