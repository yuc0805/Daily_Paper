Organize then Retrieve: Hierarchical Memory Navigation for Efficient Agents

See arXiv listing · arXiv 2026-06 · arXiv:2606.11680 · Appears in: Agent

What

HORMA is a working-memory mechanism for LLM agents on long-horizon tasks. It organizes past experience into a file-system-like hierarchy in which short summarized entities link back to the corresponding raw trajectories, so the agent can reach detail on demand without keeping everything in its context window. The method runs in two stages: structured memory construction, then navigation-based retrieval.

Why

LLM agents are stateless, so every long-horizon task forces all relevant information into a growing input context, which degrades reasoning, raises cost, and adds latency. Existing fixes use lossy compression or similarity-based retrieval, and both tend to drop the temporal order and causal links that multi-step tasks depend on. The paper aims for a memory that keeps detail reachable while keeping the working context small.

How

During construction, experience is summarized into entities arranged in a hierarchy, with each summary holding a pointer to the raw trajectory it came from. During retrieval, the agent navigates this structure rather than running a flat similarity search, so it can move from a high-level summary down to the exact raw record when a step needs it. The design treats working memory as a cost-and-latency problem and measures efficiency alongside task quality.

Solves vs predecessors

The Memory Mechanisms Survey listed compression and similarity retrieval as the standard tools. HORMA argues both lose temporal and causal structure on multi-step tasks, and fixes that specific failure by keeping a pointer from every summary back to its raw trace, so detail is never discarded, only deferred.

Method vs predecessors

Where prior memory either shrinks the context with lossy summaries or retrieves flat chunks by embedding similarity, HORMA adds an explicit hierarchy and a navigation step. Retrieval becomes a traversal from coarse to fine rather than a single nearest-neighbor lookup, which is what lets it recover ordered, causally linked detail.
