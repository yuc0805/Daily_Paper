M3Exam: Benchmarking Multimodal Memory for Realistic User-Agent Interactions

Authors per arXiv listing · arXiv 2026-06 · arXiv:2606.07402 · Appears in: Agent

What

M3Exam is a query-centric benchmark for multimodal conversational memory, built on realistic user-agent interactions rather than synthetic dialogue. Evaluation is multi-dimensional and covers cross-modal grounding — recalling what the user showed, not only what the user said — and implicit information inference. This page is abstract-level; benchmark sizes and baseline numbers were not in accessible sources on the day of indexing.

Why

Agent memory mechanisms have multiplied — logs, vector stores, topic documents, latent state — but each is evaluated on its own private setup, so claims about what memory design works under realistic multimodal use cannot be compared. A shared, interaction-grounded benchmark is the missing measurement instrument.

How

The benchmark organizes evaluation around queries against an interaction history that mixes text and visual content. Dimensions include cross-modal grounding and implicit inference, which separate retrieval hit-rate from actual memory use: an agent can fetch the right snippet and still fail to connect it to what was shown earlier.

Builds on

  • Rethinking Memory Mechanisms of Foundation Agents (Huang 2026)Catalogued the mechanisms this benchmark now measures on common ground.
  • Agent AI: Surveying Multimodal Interaction (Durante 2024)Described the multimodal user-agent interaction setting the benchmark instantiates.

Solves vs predecessors

The surveys identified mechanisms and settings but left evaluation fragmented: each memory paper reports on incompatible private tests. M3Exam fixes the comparability failure by fixing the task distribution and the query types, so mechanism papers can be ranked on the same footing.

Method vs predecessors

Where the parent surveys are descriptive taxonomies, M3Exam is an instrument: query-centric construction from realistic interactions, with explicit dimensions for cross-modal grounding and implicit inference. It connects the agents-and-memory line (community 0) to vision-language (community 3) through the requirement that memory span modalities.
