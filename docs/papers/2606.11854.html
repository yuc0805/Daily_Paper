Fine-tuning Multi-modal LLMs with ART: Art-based Reinforcement Training

See arXiv listing · arXiv 2026-06 · arXiv:2606.11854 · Appears in: Multi-Modal

What

ART adapts a frozen multimodal LLM by optimizing only its raw visual input. Gradients are backpropagated into a plain pixel array, so any fine-tuning objective can be used, and the optimized image ends up looking like task-relevant computational artwork. Because the model itself is untouched, the method stays usable inside high-throughput serving engines.

Why

The two common parameter-efficient fine-tuning methods both edit the model's computational graph: LoRA inserts extra weights between layers, and soft prompting inserts extra trainable tokens. That editing is not fully supported by precompiled, preoptimized engines like vLLM, so adapting a deployed model is awkward. The paper looks for a way to specialize a frozen multimodal model without changing anything inside it.

How

ART places all trainable parameters in the input image rather than the model. It optimizes the pixels directly through backpropagation against the chosen objective, combining adversarial reprogramming (repurposing a frozen model through its input) with parameter-efficient fine-tuning and reinforcement-style training for reasoning. After training, the only change at deployment is the image shown to the model, so the serving graph is preserved.

Solves vs predecessors

LoRA and soft prompting both require modifying a precompiled model, which blocks clean use in high-throughput engines. ART removes that requirement by moving the trainable parameters out of the model and into the pixels, so a frozen, already-served model can be specialized without graph surgery.

Method vs predecessors

Soft prompting learns extra input tokens; ART learns the input image instead, in raw pixel space. This keeps the soft-token idea but applies it where the model is frozen and precompiled, trading token-space adaptation for image-space adaptation.
