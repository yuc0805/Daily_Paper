Introspective X Training: Feedback Conditioning Improves Scaling Across All LLM Training Stages

Cui, Lu, Jung, Akter, Kim, Qu, Acuna, Prabhumoye, Choi, Ammanabrolu · arXiv 2026 · link · Appears in: LLM

What

IXT is a training method that uses a thinking reward model to annotate data with natural language critique-based feedback, then prefix-conditions training samples with this feedback so that quality-aware token weighting begins at the earliest stage of the LLM pipeline (pretraining). On 7.5-12B dense transformers trained up to 18 trillion tokens, IXT yields up to 2.8x compute efficiency and reaches performance on math and code that models trained without feedback conditioning cannot achieve regardless of additional compute.

Why

Current LLM pipelines treat pretraining as quality-agnostic: all tokens receive equal weight for billions of gradient steps. Quality-aware signals (reward models, human preferences) appear only during post-training. This wastes compute on low-value data during the most expensive phase of training. Prior work on data filtering or curriculum learning addressed data selection but did not incorporate reward-model feedback directly into the training objective at pretraining time.

How

A thinking reward model generates natural language critique for each pretraining sample. The critique is prepended as a prefix to the training data, and the model learns to condition on this prefix during standard autoregressive training. This is inspired by offline reward-conditioned RL, where the reward signal is embedded in the input rather than used as a gradient modifier. The method applies uniformly across pretraining, SFT, and RL stages.

Solves vs predecessors

DeepSeek-R1 showed that RL can unlock reasoning ability in LLMs, but the reward signal only shapes the model during post-training, after pretraining representations have already been formed. IXT solves this temporal gap by introducing reward-derived quality signals from the very first pretraining step. Data filtering methods (e.g., quality classifiers for pretraining data) address a related problem but make binary keep/discard decisions; IXT instead provides continuous, fine-grained quality feedback that the model learns to condition on.

Method vs predecessors

Where DeepSeek-R1 uses reward signals as gradient modifiers via policy gradient objectives, IXT encodes reward information as input prefixes, following the offline reward-conditioned RL paradigm. This means no special RL training loop is needed — standard next-token prediction suffices. Where curriculum learning orders training data by difficulty, IXT keeps all data but annotates each sample with quality information, letting the model itself learn how to weight different quality levels.
