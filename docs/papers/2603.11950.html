Learning Transferable Sensor Models via Language-Informed Pretraining (SLIP)

SLIP authors · arXiv 2026 · arXiv:2603.11950 · Appears in: Signal/Time Series

What

SLIP pretrains a sensor encoder so its representations align with language and transfer across different sensor setups. It combines contrastive alignment between signals and text with a sensor-conditioned captioning task, reuses a frozen decoder-only language model through cross-attention, and uses a patch embedder that accepts variable sequence lengths and sampling rates at inference without retraining. Across 11 datasets it reaches 77.14% average linear-probe accuracy (a 5.93% relative gain over the strongest baseline) and 64.83% accuracy on sensor question answering.

Why

Most sensor self-supervised methods optimize reconstruction or forecasting, which the authors argue does not capture the semantic structure needed for classification. Recent sensor-language alignment methods help but assume a fixed sensor configuration: a set channel layout, signal length, or sampling rate. That assumption breaks when a deployment changes devices or resolutions, so the learned model does not transfer. SLIP targets configuration-agnostic, language-aligned representations.

How

SLIP trains two objectives together: a contrastive loss that pulls signal and text embeddings together, and a captioning loss where the frozen language model, attached through cross-attention, describes the signal. The patch embedder maps variable-length, variable-rate inputs into tokens, so one model handles many configurations at inference. The combination supports zero-shot transfer, signal captioning, and question answering from a single pretrained encoder.

Builds on

  • Sensor2Text (Chen 2024)Aligns one fixed sensor configuration with language; SLIP removes the fixed-configuration limit.
  • SSL for HAR (Yuan 2024)Self-supervised pretraining without language; SLIP adds a language target for semantic structure.
  • Time-LLM (Jin 2024)Reprograms a frozen LLM for forecasting; SLIP reuses a frozen LLM via cross-attention for alignment and captioning.

Solves vs predecessors

Sensor2Text aligns signals with language but ties the model to one channel set, length, and rate, so it does not transfer when the sensor setup changes. SLIP fixes that failure mode with a patch embedder that accepts variable configurations at inference, so a single pretrained encoder serves new setups without retraining. It also addresses the gap in SSL for HAR, where reconstruction-style objectives miss the semantic structure that helps classification, by adding the language alignment and captioning targets.

Method vs predecessors

Compared to Sensor2Text, SLIP keeps the signal-language alignment idea but replaces fixed input handling with a flexible patch embedder and adds a captioning objective. Compared to SSL for HAR, it shifts from purely self-supervised reconstruction to contrastive language alignment. Compared to Time-LLM, which reprograms the LLM input for forecasting, SLIP attaches the frozen LLM through cross-attention and uses it for both discriminative alignment and generative captioning.
