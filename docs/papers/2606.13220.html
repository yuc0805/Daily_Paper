LLM-as-an-Investigator: Evidence-First Reasoning for Robust Interactive Problem Diagnosis

See arXiv listing · arXiv 2026 · link · Appears in: Agent

What

The paper frames interactive problem diagnosis as evidence-gathering before conclusion. Rather than committing to a hypothesis and then justifying it, the agent is structured to collect evidence first and let the diagnosis follow from what it found. The setting is multi-turn interaction where the agent asks, observes, and revises.

Why

Planning and search agents tend to commit to an early hypothesis and then defend it, which fails when the first guess is wrong. In interactive diagnosis, where information arrives over several turns, an early wrong commitment is costly. The motivation is robustness against premature conclusions.

How

The agent reorders its loop so evidence collection precedes commitment: it gathers observations across turns and forms the diagnosis from accumulated evidence rather than from an initial guess. This evidence-first control is the structural change relative to plan-first or search-first agents.

Builds on

  • ADaPT (Prasad 2023)As-needed decomposition and planning of a task into sub-plans.
  • LATS (Zhou 2024)Language agent tree search over action sequences.

Solves vs predecessors

Where ADaPT decomposes a task into sub-plans on demand and LATS searches over action trees, this paper reorders the loop so evidence collection precedes commitment, because premature hypotheses are the failure mode both planning and search inherit. The claim is robustness when the first guess is wrong.

Method vs predecessors

The parents optimize how to plan or search given a goal; this paper changes when the agent commits, putting evidence before hypothesis. It is a control-flow change to the agent loop rather than a new planner or search algorithm.
