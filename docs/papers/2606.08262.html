Causal Semantic Alignment for LLM-based Time Series Forecasting (CVAformer)

Authors per arXiv listing · arXiv 2026 · paper · Appears in: Signal/Time Series, Causal Inference

What

CVAformer (Causal Variable-level Alignment Transformer) forecasts time series with a pretrained language model backbone. It splits each input variable into an invariant component (stable semantics) and a dynamic component (short-term fluctuation) before aligning the series with word embeddings, then applies a causal backdoor intervention so the dynamic component does not bias the alignment. The result is a less spurious mapping between temporal patterns and the language model embedding space.

Why

Language-model-based forecasters align temporal patterns with pretrained word embeddings, but most treat each series as a single entangled signal. Dynamic fluctuations and invariant semantics are mixed, and the dynamic part acts as a confounder: it influences both the invariant embedding and the aligned output, which introduces spurious correlation. Prior alignment methods did not separate these components or remove the confounding.

How

The method disentangles each variable into invariant and dynamic parts just before alignment, then uses backdoor adjustment to block the confounding path from the dynamic component to the aligned embedding. Alignment is done at the variable level rather than per time step, following the channel-as-token view, so each channel is summarized before being matched to the embedding space.

Builds on

  • Time-LLMEstablished alignment of time series patches with frozen language model embeddings; CVAformer adds a causal step to that alignment.
  • GPT4TSShowed a frozen pretrained transformer can serve as a general time series backbone; CVAformer keeps the frozen-backbone idea.
  • iTransformerIntroduced variable-level tokenization; CVAformer aligns at the variable level on top of this.
  • Causal Inference Intro (Pearl)Provides the backdoor adjustment used to remove the dynamic confounder.

Solves vs predecessors

Time-LLM and GPT4TS align raw temporal patterns with language embeddings but leave invariant semantics and dynamic fluctuation entangled, so the alignment can latch onto spurious correlation driven by the dynamics. CVAformer fixes this failure mode by separating the two components and removing the confounding path with a backdoor intervention, giving an alignment that depends on stable semantics rather than transient noise.

Method vs predecessors

Where iTransformer made the channel the unit of tokenization and Time-LLM matched patches to word embeddings, CVAformer keeps the variable-level view but inserts a causal model: invariant and dynamic factors are modeled explicitly and the dynamic factor is intervened on. This brings Pearl-style backdoor adjustment, from the causal inference part of the library, into the time-series-plus-LLM alignment pipeline, a combination not present in the three time-series parents.
