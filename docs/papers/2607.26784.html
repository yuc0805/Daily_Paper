SkillRise: Agentic Reinforcement Learning for Cross-Task Skill Evolution

Yao, Chen, Lu, Xu, Sun, Guo, Liu, Shen et al. · arXiv 2026-07-29 · arXiv:2607.26784 · Appears in: Agent

What

SkillRise is a reinforcement learning framework in which a single policy alternates between solving a task and curating an evolving skill document that it passes to the next related task. Credit assignment is decoupled: solving is supervised by the current task outcome, and curation is supervised by discounted downstream outcomes. On ALFWorld, WebShop, and ScienceWorld it reaches the best Pass@1 among compared methods, with gains of 2.3 to 8.5 percentage points over the strongest baseline, and it shows test-time scaling across tasks, meaning performance rises with longer sequences of related tasks even when each is attempted only once.

Why

Standard agentic reinforcement learning treats each task as an independent episode, so an agent cannot carry a reusable solution pattern from one task to a related one. Existing skill-learning approaches either focus on repeated attempts of a single task or use multi-stage pipelines that entangle extraction, retrieval, and execution and add runtime overhead. The paper's goal is a single training paradigm that lets an agent extract, refine, and reuse transferable skills across tasks without a separate multi-stage pipeline.

How

SkillRise organizes related task instances into progressively harder sequences. One policy handles both roles: it solves the current task and it edits a skill document that is fed directly into the next task. The reward is split so that the solving behavior is credited by the current outcome and the curation behavior is credited by discounted downstream outcomes, which is what teaches the policy to write skills that help later tasks rather than only the current one.

Solves vs predecessors

DeepSeek-R1 improves a policy within a single task using outcome rewards, so nothing learned transfers explicitly to a related task. SkillRise fixes the failure mode "each task starts from scratch" by adding a second learning signal that rewards writing down transferable skills, so a related later task benefits from what an earlier one discovered.

Method vs predecessors

Compared to DeepSeek-R1's single within-task advantage, SkillRise uses two decoupled credit signals, one for solving and one for curation with discounted downstream reward. Compared to multi-stage skill pipelines, it keeps a single policy and a single document, which lowers runtime overhead while still separating the two behaviors through the reward rather than through separate modules.
