Light-Omni: Reflex over Reasoning in Agentic Video Understanding with Long-Term Memory

Nie, Wei, Feng, Fu, Shan (Nanjing University) · arXiv 2026 · arXiv:2607.05511 · Appears in: Multi-Modal

What

Light-Omni is a multimodal agent for long video streams that answers reflexively instead of through slow iterative reasoning. It keeps two states built in a single forward pass: a global state, a fixed-size multimodal script consolidated from episodic memory by hierarchical merging, and a parametric latent state, conditioned on the global context, that drives actions and produces retrieval embeddings. Against M3-Agent it reports a 2.4% average accuracy gain, a 12.1x speedup, and 2.6x better GPU memory use, with near-constant ~2.3s latency regardless of video length. It also works as a plug-in memory system for existing multimodal LLMs.

Why

Agentic video models keep long-term memory but usually rely on detective-style iterative reasoning, searching then aggregating evidence, which is slow and expensive. The paper argues that heavy reasoning is mostly compensating for missing global context and poor retrieval alignment. If the global context and retrieval were built directly, the iterative loop would be unnecessary, cutting latency and memory cost.

How

Light-Omni maintains a global state, a finite-sized multimodal script continuously consolidated from episodic memory through hierarchical merging that keeps recent detail and summarizes past events. Conditioned on this global context, it generates a parametric latent state that directly drives autonomous actions and produces retrieval embeddings with low latency. The coupled design yields semantically aligned retrieval and reflexive answers in one forward pass, and the same memory module can be attached to existing multimodal LLMs to raise their accuracy and efficiency.

Solves vs predecessors

Iterative-reasoning video agents pay prohibitive latency and memory cost that grow with stream length. Light-Omni removes the search-then-aggregate loop by building global context and retrieval directly, so latency stays near-constant (~2.3s) regardless of video length while accuracy rises against M3-Agent.

Method vs predecessors

Where the Memory Mechanisms Survey described many possible memory schemes, Light-Omni fixes one: a consolidated global script plus a latent action state trained to drive both actions and retrieval. Where short-clip action-recognition methods encode a fixed window, Light-Omni compresses an unbounded stream into a fixed-size state through hierarchical merging, trading exact recall of old frames for constant-time response.
