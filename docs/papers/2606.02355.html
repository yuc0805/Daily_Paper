SIRI: Self-Internalizing Reinforcement Learning with Intrinsic Skills for LLM Agent Training

Authors from Xiamen University, Meituan, Macao Polytechnic · arXiv 2026 · link · Appears in: Agent

What

SIRI is a three-phase reinforcement-learning method that lets a long-horizon agent discover, validate, and absorb reusable skills without any external skill generator and without a skill bank at inference time. It warms up the policy to collect successful skill-free trajectories, then has the policy summarize compact skills from its own successful rollouts and validate them by comparing skill-augmented against skill-free runs, and finally distills only the helpful skill-guided action tokens back into the plain policy. The deployed agent keeps the benefit of skills while carrying no extra context or retrieval cost.

Why

Skill-based agents usually depend on an external module to generate skills during training or on a retrieval step to pull skills at inference. Both raise engineering complexity, lengthen the context, and add deployment latency. The paper aims to keep the accuracy gains of reusable skills while removing the external generator and the runtime skill bank.

How

Phase one warms up the policy with a group-relative RL update to acquire basic interaction ability and gather successful plain trajectories. Phase two is self-skill mining: the current policy summarizes short skills from its own successful rollouts and checks each by running paired skill-augmented and skill-free episodes. Phase three distills only the skill-guided action tokens that measurably help, using trajectory-level utility and action-level advantage, so the useful behavior moves into the plain policy weights.

Builds on

  • DeepSeek-R1 (2025)Reinforcement learning to bring out reasoning behavior; SIRI turns RL toward mining and internalizing skills.
  • ADaPT (Prasad 2023)As-needed decomposition with an external planner; SIRI removes the external module and mines skills from the policy's own rollouts.

Solves vs predecessors

DeepSeek-R1 produces long reasoning traces but does not compress recurring procedure into reusable, cheap-to-run skill; ADaPT structures tasks but leans on an external decomposition module. SIRI fixes the runtime cost by validating self-mined skills against a skill-free baseline and distilling only the beneficial action tokens into weights, so nothing extra is retrieved or prompted at inference.

Method vs predecessors

Where ADaPT keeps planning external and R1 keeps reasoning in-context, SIRI internalizes procedure into the policy through a measured self-distillation loop. This sits next to the DeepSeek-R1 to Chain-of-Thought bridge already in the library, which contrasted reasoning-via-RL with reasoning-via-prompting; SIRI extends the RL side from eliciting reasoning to compressing and reusing skill.
