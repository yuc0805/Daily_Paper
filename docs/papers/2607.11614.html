Extending LLM Context via Associative Recurrent Memory

Rodkin et al. · arXiv 2026 · link · Appears in: LLM

What

The paper gives a training recipe for extending the usable context of a language model using an associative recurrent memory transformer. It combines continued pre-training, synthetic long-context data, curriculum learning, and selective placement of associative memory into chosen layers rather than all of them. The augmented model processes inputs well past its original context limit while keeping the added memory machinery in only a few layers.

Why

Standard attention has a fixed window and quadratic cost, so very long inputs either do not fit or become expensive. Adding recurrent memory everywhere is heavy and hard to train. The paper looks for a recipe that extends context reliably without paying full attention over everything and without destabilizing training.

How

The method carries a compressed associative memory state across input segments and injects that memory into selected layers only. Training proceeds through continued pre-training on synthetic long-context data with a curriculum that grows input length gradually. The reported finding is that layer placement and the data curriculum matter more than adding memory to every layer.

Solves vs predecessors

The Transformer holds all information inside a fixed window, so long inputs overflow it. This paper adds a recurrent associative memory that carries compressed state across segments, extending effective context without full quadratic attention. Where the memory survey only catalogued options, this work turns one option into a working recipe that holds up past the original limit.

Method vs predecessors

Rather than enlarging the attention window or adding memory to all layers, the method places memory selectively and relies on a length curriculum during continued pre-training. That selective-layer choice is the main technical difference from both plain attention and uniform memory augmentation.
