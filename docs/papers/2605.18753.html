DashAttention: Differentiable and Adaptive Sparse Hierarchical Attention

Huang, Gonçalves, Alvetreti, Li, Han, Ponti, Martins, Treviso · arXiv 2026 · paper · Appears in: LLM

What

DashAttention is a two-stage hierarchical sparse attention mechanism that replaces the non-differentiable top-k block selection used in methods like NSA and InfLLMv2 with alpha-entmax, a differentiable sparse transformation. This allows each query to adaptively select a variable number of key-value blocks — fewer for locally focused queries, more for globally dependent ones — while keeping the entire attention hierarchy end-to-end trainable.

Why

Hierarchical sparse attention methods reduce the quadratic cost of full attention by first selecting relevant KV blocks at coarse resolution and then applying fine-grained attention within them. However, existing methods use top-k selection, which assumes every query needs exactly the same number of blocks (an unrealistic assumption) and blocks gradient flow between the selection and attention stages. This prevents the model from learning to optimise its own sparsity pattern during training.

How

The first stage applies the alpha-entmax transformation to coarse block-level attention scores, producing a sparse distribution where the number of non-zero entries varies per query. This sparse distribution serves as a differentiable prior for second-stage softmax attention over the selected tokens. Because alpha-entmax is differentiable everywhere — including at the boundary between zero and non-zero — gradients flow through the full hierarchy. The authors prove that DashAttention is non-dispersive: attention mass concentrates on genuinely relevant tokens rather than spreading uniformly across selected blocks. A GPU-aware Triton implementation achieves speedup over FlashAttention-3 at inference.

Solves vs predecessors

The original Transformer uses dense O(n^2) attention, making long-context modeling expensive. Subsequent methods (NSA, InfLLMv2) introduced hierarchical sparse attention but relied on top-k, which is non-differentiable and assumes fixed sparsity per query. DashAttention solves both problems: it is fully differentiable and adapts the sparsity level per query, achieving full-attention accuracy at 75% sparsity while dominating the Pareto frontier at higher sparsity regimes.

Method vs predecessors

Where the Transformer applies dense softmax over all positions, and NSA/InfLLMv2 apply a hard top-k filter followed by softmax on survivors, DashAttention applies alpha-entmax (a smooth, sparse alternative to softmax) at the block selection stage. The key technical difference is that alpha-entmax produces exact zeros while remaining differentiable at the sparsity boundary, enabling the coarse selection stage to be trained jointly with the fine attention stage. The non-dispersive property is a direct consequence: alpha-entmax concentrates mass rather than spreading it, unlike softmax which always assigns non-zero weight to every block.
