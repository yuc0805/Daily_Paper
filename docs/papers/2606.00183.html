Agentic Transformers Provably Learn to Search via RL

Yang, Huang, Liang, Chi · arXiv 2026 · link · Appears in: Reasoning, Agent

What

A theoretical proof that transformer policies trained with reinforcement learning on k-ary tree environments acquire depth-first search (DFS) capabilities. The paper identifies the minimal mechanism: two attention heads, one for trajectory tracking and one for failure detection and backtracking. A key result is depth generalization — policies trained on depth-1 and depth-2 trees correctly search deeper trees at test time.

Why

Prior work (LATS, ADaPT) showed empirically that transformers can execute search-like behaviors, but without formal guarantees about when or why this works. Understanding the mechanism matters for two reasons: it tells us the minimal architectural requirements for search capability (two heads suffice), and the depth generalization guarantee means we do not need to train on the hardest instances to handle them.

How

The authors construct a k-ary tree search environment where the agent must find a goal node by choosing branches at each depth level. They analyze the RL training dynamics of a two-layer transformer with two attention heads. Head 1 implements a trajectory-tracking pattern: it attends to the sequence of past actions to maintain the current path. Head 2 implements failure detection: it attends to reward signals and triggers a backtracking action when a dead end is encountered. The proof shows that gradient-based RL training converges to weights that implement this two-head DFS mechanism, and that the learned weights generalize to deeper trees because the per-step logic (choose next branch or backtrack) is depth-independent.

Builds on

  • Chain-of-Thought PromptingShowed that LLMs can perform multi-step reasoning, raising the question of whether systematic search can also emerge.
  • Language Agent Tree Search (LATS)Introduced explicit tree search as a planning mechanism for LLM agents, which this paper shows can emerge implicitly from RL.
  • ADaPTProvided empirical evidence that RL-trained transformers acquire planning behaviors, which this paper now proves formally.

Solves vs predecessors

LATS requires an explicit search module bolted onto the LLM. ADaPT demonstrated learned planning but without formal guarantees. This paper shows that neither an explicit search module nor training on hard instances is necessary — RL on simple trees produces a policy that provably generalizes to harder ones. The two-head mechanism is also a minimal characterization: prior work could not tell you how many parameters or heads are sufficient for search.

Method vs predecessors

Where LATS implements search as an external algorithm that calls the LLM repeatedly, this paper shows search emerging as an internal computation within the transformer's forward pass. The proof technique analyzes the attention patterns that RL training converges to, identifying the specific trajectory-tracking and failure-detection roles of each head. This is a constructive proof — it does not merely show existence but identifies the exact mechanism.
