Environment-free Synthetic Data Generation for API-Calling Agents

Apple · arXiv 2026 · link · Appears in: Agent

What

This paper generates synthetic tool-call training data for API-calling agents without a live executable environment. Instead of executing real services to collect trajectories, the data pipeline itself produces the API surface and its responses. The result is a cheaper path to large, diverse API-calling datasets, most useful for the long tail of tools that have no public sandbox.

Why

Tool-calling agents are normally trained on trajectories that need a live environment: real APIs to call, real state to observe, real errors to recover from. Standing up and maintaining that environment is the main bottleneck to scaling agent training data, and most tools of interest have no sandbox to record against. Prior tool-use work assumed such an environment exists.

How

The pipeline synthesizes both the tool interface and the call-and-response supervision, so agent trajectories can be produced offline. This removes the dependency on executing real services and lets data volume and tool diversity scale with generation rather than with sandbox availability.

Builds on

  • ToolkenGPT (Hao 2024)Learned tool-call embeddings assuming callable tools; this work removes that requirement.
  • ADaPT (Prasad 2023)As-needed task decomposition for planning agents that assumed an executable setting.
  • Agent AI Survey (Durante 2024)Framing survey for the agent systems this data trains.

Solves vs predecessors

ToolkenGPT assumed tools you can actually call to gather supervision, which does not scale to tools without sandboxes. This paper fixes that by synthesizing the call-and-response supervision directly, because the environment, not the model, is what does not scale.

Method vs predecessors

Where ADaPT and ToolkenGPT operate inside an executable environment, this work replaces the environment with a generative pipeline that fabricates consistent tool responses, shifting the cost from maintaining services to generating data.
