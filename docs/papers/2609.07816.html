Kalman Delta Networks: Uncertainty-aware Associative Memory

Bui, Huang, Ying (Yale University) · arXiv preprint 2026 · arXiv:2609.07816 · Appears in: MAMBA

What

Kalman Delta Networks reformulate the fixed-size recurrent memory of linear attention as a linear-Gaussian state-space model, for which the Kalman filter is the optimal recursive estimator, and use that filter as the write rule. The transition propagates the memory state together with its covariance, so the Kalman gain weights each residual write by accumulated evidence and observation reliability rather than by the current token alone. Delta-rule updates emerge as the special case that substitutes a token-wise isotropic surrogate for the predictive covariance and omits covariance tracking entirely.

Why

Linear attention is used in frontier models for long-context inference at constant decoding memory, and its bounded recurrent state forces an online decision at every token: what to write, and how strongly to overwrite existing associations, before knowing what future queries will ask for. Delta-rule models learn that strength from the current token embedding, which means the write cannot adapt to how much evidence the memory has already accumulated about the association being overwritten. A confident memory and an uninformed one are updated the same way, and nothing in the layer represents the difference.

How

Recurrent associative memory is written as a linear-Gaussian state-space model and updated by Kalman recursion, so the gain scales each write by predictive covariance and observation reliability. Exact tracking entails a dense, state-dependent Riccati recursion that is poorly suited to GPU-parallel linear-attention scans, so the paper introduces two scan-compatible approximations. Diagonal KDN projects each one-step posterior onto the diagonal Gaussian family through online mean-field variational inference; Isotropic KDN keeps a single uncertainty scalar per head. Both uncertainty recurrences take the form of Mobius maps, which compose associatively and therefore run as associative scans with logarithmic parallel depth. Reported result: across controlled pretraining at 750M and 1.3B parameters, KDN variants consistently improve perplexity and mean downstream accuracy over state-of-the-art linear-attention models.

Builds on

  • Mamba-2 (Dao 2024)Established the state-space duality that writes a linear-attention layer and a structured SSM as the same recurrence; KDN starts from that identification and changes what the recurrence estimates.
  • HiPPO (Gu 2020)Framed fixed-size recurrent state as optimal online compression of history under a fixed measure; KDN keeps the principled-write ambition and makes the compression adaptive.
  • Attention Is All You Need (Vaswani 2017)The softmax attention baseline whose unbounded KV cache linear attention replaces with the bounded state KDN is trying to manage well.

Solves vs predecessors

Mamba-2 unified linear attention and SSMs and then spent its effort making the shared recurrence fast, leaving the question of what the recurrence should be estimating untouched. HiPPO answered a version of that question but fixed the compression measure in advance, so the transition is static and the same input is absorbed identically regardless of what the state already holds. Delta-rule models made the write strength input-dependent but read it off the current token, so it still cannot reflect accumulated evidence. KDN fixes that specific failure mode: by carrying a covariance, a token produces a large update when the relevant memory is uncertain and a small one when it is well determined, and the paper shows the delta rule is exactly what its own update degenerates to when the covariance is replaced by an isotropic constant.

Method vs predecessors

HiPPO derives a fixed transition matrix from an orthogonal-polynomial measure and Mamba-2 makes the transition input-dependent but scalar-times-identity in its efficient form, in both cases tracking a state and no second moment. KDN tracks state and uncertainty jointly, which is what supplies the Kalman gain. The obstacle is that the exact second-moment recursion is a dense state-dependent Riccati update, which is sequential and therefore incompatible with the parallel scan that makes these layers competitive. The resolution is structural rather than numerical: restricting the posterior to diagonal or isotropic families turns the uncertainty recurrence into a Mobius map, and Mobius maps compose associatively, so the parallel scan survives. That is the same move Mamba made for the state recurrence, applied one level up to the covariance.
