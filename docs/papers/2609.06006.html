Memory in Deep Time-Series Models

Nguyen, Nguyen, Nguyen, Do, Nguyen, Le · arXiv preprint 2026 · arXiv:2609.06006 · Appears in: Signal (Time Series)

What

A survey arguing that recurrent networks, transformers, structured state-space models, retrieval-augmented predictors, time-series foundation models and tool-using agents are usually studied as separate architectural eras when they are better read as successive answers to one question: how does a time-series model retain and access information beyond its immediate input? Existing methods are placed on a spectrum from internal memory, held in parameters and fixed-size states, to external memory that is addressable, retrievable and increasingly maintained by an agent. Three classes of external memory are then reviewed under a common account of what is retained, how it is written and read, and how it persists.

Why

Conventional time-series modeling faces a limitation that no single architecture removes: information relevant to a prediction may lie far outside any feasible input window, while compressing history into a fixed-size state discards material that may matter later. Organizing the literature by architecture hides this, because it separates methods that answer the same limitation and groups methods that answer different ones. Taxonomies arranged by how a language model is attached to a series have the same problem from the other direction, putting a state-space model and a retrieval-augmented forecaster in unrelated boxes.

How

The paper formulates the limitation as a memory problem and builds a taxonomy of memory mechanisms along the internal-to-external spectrum. Three classes of external memory are covered: explicit modules, retrieval augmentation, and agentic stores. Each is described by what it retains, how it is written and accessed, and how it persists, which makes mechanisms from different architectural eras directly comparable. A cross-cutting analysis maps mechanisms to time-series tasks and identifies gaps in both methods and evaluation, and the paper closes on open problems in systems that selectively retain, retrieve, revise and forget as temporal environments change. This is a survey, so it contributes a framework rather than measurements.

Builds on

  • TS-Agent (Liu 2025)The agentic-store end of the spectrum this survey defines, where an external agent maintains what the model remembers about a series.
  • LLMs for Time Series: A Survey (Zhang 2024)The previous organizing survey of this literature, arranged by how a language model is attached to a series rather than by what is retained.
  • Rethinking Memory Mechanisms of Foundation Agents (Huang 2026)Supplies the write, read, revise and persist vocabulary for agent memory that this paper carries over to numeric temporal data.

Solves vs predecessors

Zhang 2024 organized the field by interface and therefore could not say whether two methods were solving the same problem, since an SSM and a retrieval-augmented forecaster land in unrelated categories despite both addressing the finite-window limitation. Huang 2026 built the vocabulary for agent memory but applied it to language agents over text, leaving open whether it survives contact with numeric temporal data where the relevant history is periodic and drifting rather than propositional. This paper puts both on one axis and, in doing so, surfaces a gap neither predecessor could state: the surveyed mechanisms are all scored on downstream forecasting error, so there is no evidence about whether their memory actually retains, revises or forgets correctly.

Method vs predecessors

The organizing move is to make memory a first-class design dimension that is independent of the backbone, where the earlier surveys treated backbone choice as the primary axis and memory as an implementation detail of each backbone. Concretely, parameter memory, fixed-size recurrent state, explicit memory modules, retrieval augmentation and agentic stores are described with one set of questions rather than five sets of architectural details, which is what lets HiPPO-style compression and an LLM agent maintaining notes about a series appear as two positions on a continuum. The intermediate positions on that continuum are where the paper says the open problems are, and it is honest that the evaluation apparatus to compare them does not yet exist.
