# Learning Transferable Sensor Models via Language-Informed Pretraining (SLIP)

**Arxiv:** 2603.11950 | **Date:** 2026-06-28 | **Area:** time-series

## What it does
SLIP pretrains a sensor encoder so that its representations line up with language and transfer across different sensor setups. It pairs contrastive alignment between signals and text with a sensor-conditioned captioning task, reuses a frozen decoder-only language model through cross-attention, and adds a patch embedder that accepts variable sequence lengths and sampling rates at inference without retraining. Across 11 datasets it reaches 77.14% average linear-probe accuracy (a 5.93% relative gain over the strongest baseline) and 64.83% accuracy on sensor question answering.

- [MKICLA63] Time-LLM (Jin 2024) — adapts a frozen language model to time series by reprogramming the input.

## Delta from parents
Where Sensor2Text (Chen 2024) aligns one fixed sensor configuration with language, SLIP removes the fixed-configuration limit: its patch embedder takes variable channel counts, lengths, and resolutions, so one pretrained model serves many sensor setups. Where SSL for HAR (Yuan 2024) learns representations by reconstruction or contrastive objectives without language, SLIP adds a language target, which it argues captures the semantic structure that reconstruction misses for classification. Where Time-LLM (Jin 2024) reprograms a frozen LLM for forecasting, SLIP reuses the frozen LLM through cross-attention for both alignment and captioning. The result is a single encoder that does zero-shot transfer, captioning, and question answering across configurations.

## Why Leo should care
SLIP extends Sensor2Text, which the graph already marks as a cross-area bridge between bio-sensing and llm-health (community 4 to community 1). The new work pushes that bridge toward configuration-agnostic encoders, which is the practical blocker when a wearable study changes devices or sampling rates. The imported method is contrastive language-image style pretraining (the SigLIP and CLIP family from the vision-language community) applied to sensor signals. That transfer is now demonstrated, so the low-hanging version of "align signals with text" is closing; the remaining room is in handling configuration shift and in the captioning-for-reasoning direction.
