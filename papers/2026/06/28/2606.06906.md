# EASE-TTT: Evidence-Aligned Selective Test-Time Training for Long-Context Question Answering

**Arxiv:** 2606.06906 | **Date:** 2026-06-28 | **Area:** test-time-training

## What it does
EASE-TTT adapts a language model at inference time to answer questions over long contexts. It first selects evidence chunks for the question, then converts those chunks into a soft target over token positions that tells the model where to put attention. It uses that target to train only the query-side attention parameters at test time, then generates the answer from the original full context. On six LongBench QA tasks with three small decoder-only models, it gives the best macro-average over full-context inference, retrieval-only baselines, and query-only test-time training.

## Delta from parents
Where TTT Layers (Sun 2024) and TTT for Abstract Reasoning (Akyurek 2024) adapt the model with generic self-supervised objectives that do not know which input positions matter, EASE-TTT supplies a targeted signal: it points test-time adaptation at the evidence positions for the specific question. Where query-only test-time training adapts the query side but cannot find the evidence, and where retrieval methods find evidence but only expose it as input, EASE-TTT joins the two by turning retrieved evidence into an attention-supervision target for query-side adaptation. The model still reads the full context, so it keeps information that pure retrieval would drop.
