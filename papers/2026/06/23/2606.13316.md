# ReSum: Synergizing LLM Reasoning and Summarization with Reinforcement Learning

**Arxiv:** 2606.13316 | **Date:** 2026-06-23 | **Area:** reasoning

## What it does
ReSum is a reinforcement-learning method that trains a language model to compress its own reasoning trace through self-summarization. During training with verifiable rewards (RLVR), the model learns when to pause, write a short summary of the work so far, and continue from that summary rather than from the full running transcript. This keeps the reasoning shorter and reduces errors carried forward from a bad start. Reported results are an average accuracy gain of 4 percent with an 18.6 percent reduction in rollout length.

## Direct parents (in Leo's library)
- [Z5IWHZAE] DeepSeek-R1 (deepseek2025_r1, community 0) — established that reinforcement learning with verifiable rewards alone can drive long-horizon reasoning in a base model.
- [HBLPTRMY] Chain-of-Thought Prompting (wei2023_cot, community 0) — showed that producing intermediate natural-language steps improves accuracy on math and commonsense tasks.

## Delta from parents
Where DeepSeek-R1 used RLVR to make a model generate long reasoning chains, and Chain-of-Thought showed that writing out intermediate steps helps, both leave the model with no way to manage the growing length of its own trace; long rollouts then exhaust the context budget and let an early mistake propagate. ReSum keeps the RLVR setup but adds a learned control action — self-summarization — and a summarization-aware advantage estimate that compares trajectories with and without the summary phrase, so the model is rewarded for summarizing only when it helps. The result is shorter chains at higher accuracy, because the model learns to organize its own reasoning instead of relying on an external scaffold. This extends the DeepSeek-R1 to Chain-of-Thought bridge in your library (reasoning-via-RL versus prompting) one step further: the reinforcement signal now shapes not just whether the model reasons step by step, but how it budgets the length of that reasoning.

## Why Leo should care
Efficient long-horizon reasoning matters for any agent that has to run many tool calls or analysis steps under a fixed context window, which includes time-series reasoning agents. The self-summarization mechanism is a generic CV/NLP-side advance in RLVR; it is not yet applied to time-series or bio-sensing reasoning, so it is an open transfer (see Gap Watch).
