# WEQA: Wearable hEalth Question Answering with Query-Adaptive Agentic Reasoning

**Arxiv:** 2606.18147 | **Date:** 2026-06-27 | **Area:** time-series

## What it does
WEQA answers plain-language questions about wearable health data. A language-model controller writes an execution plan for each question and routes it to a matching set of tools (signal-analysis routines and pretrained wearable models), then composes the tool outputs into a natural-language answer. The routing is query-adaptive, so different question types call different tools. The framework reports 24% higher accuracy than baseline approaches with clinician-judged clinical soundness.

## Delta from parents
Where TS-Agent treated time-series reasoning as an agent calling fixed analysis tools, WEQA adds query-adaptive routing, because a fixed tool order is wrong when a sleep question and a cardiac question need different tools. Where Sensor2Text produced a description of a sensor window, WEQA produces an answer to a specific question, because a description is not yet an answer. The paper extends the cross-area bridge chen2024_sensor2text → liu2023_health_llm (bio-sensing to LLM-health) by pushing it toward agentic tool routing, so the bridge now reaches the agent community. It borrows the controller idea from LATS but applies it to sensor tools rather than web or code actions.
