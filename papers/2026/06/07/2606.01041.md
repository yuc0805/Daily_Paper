# ExpWeaver: LLM Agents Learn from Experience via Latent RAG

Encodes agent experiences as hidden states in the LLM's own representation space, retrieves them in latent space at each decoding step via cross-attention, and integrates via gated residual. End-to-end RL training. SOTA on 12/13 tasks, +6.8% over strongest baseline, token-efficient (no extra context overhead), strong cross-domain transfer (+16.32% zero-shot, +15.21% few-shot).

Key delta from Memory Mechanisms Survey (Huang 2026): moves memory from catalogue to implementation. From ToolkenGPT (Hao 2024) and LATS (Zhou 2024): replaces explicit text-based few-shot examples with latent experience retrieval.
