# Infini Memory: Maintainable Topic Documents for Long-Term LLM Agent Memory

**Arxiv:** 2606.10677 | **Date:** 2026-06-18 | **Area:** agent

## What it does
Infini Memory stores an agent's long-term memory as topic-structured text documents rather than a flat log or a vector store. Each topic document collects related evidence, keeps metadata, and is revised over time, so memory stays consistent and current across a long task.

## Delta from parents
Where the survey lays out the categories of agent memory, Infini Memory commits to one design point: document-structured topic memory with revision over time. The motivation is that flat logs grow without bound and vector stores lose factual consistency, so a maintainable topic-document structure keeps long-horizon facts both retrievable and current.

## Why Leo should care
Long-horizon memory is a recurring bottleneck for agents that run for hours. This is a concrete, named alternative to vector-store memory that he can compare against when reasoning about agent designs.
