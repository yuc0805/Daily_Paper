# CLAMP: Contrastive Self-Supervised Learning As Neural Manifold Packing

**Arxiv:** 2506.13717 | **Date:** 2026-06-03 | **Area:** self-supervised

## What it does
CLAMP recasts contrastive self-supervised learning as a manifold packing problem. It introduces a loss function inspired by short-range repulsive particle systems from physics (jammed packings). Each class forms sub-manifolds from augmented views, and the loss optimizes their sizes and positions via gradient descent on a packing energy. CLAMP achieves competitive performance with state-of-the-art SSL under standard linear evaluation on vision benchmarks.

## Delta from parents
Where standard contrastive methods (SimCLR, BYOL, etc.) use point-wise comparisons, CLAMP operates on manifold-level geometry. Yuan 2024's SSL for HAR uses conventional contrastive pretraining on sensor data at scale. CLAMP's packing loss provides a physically interpretable alternative with geometrically meaningful hyperparameters. The connection to jamming physics yields interpretable dynamics in embedding space.

## Why Leo should care
The manifold packing loss has not been tested on sensor or time-series data. If applied to wearable sensor SSL, it could produce better-separated activity manifolds than standard contrastive losses, particularly when the number of activity classes is small (where the theoretical gap between self-supervised and supervised CL is larger). This is an unported opportunity.
