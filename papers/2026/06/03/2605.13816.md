# Uncertainty-Driven Anomaly Detection for Psychotic Relapse Using Smartwatches

**Arxiv:** 2605.13816 | **Date:** 2026-06-03 | **Area:** llm-health

## What it does
This paper develops two smartwatch-based frameworks for daily psychotic relapse detection. The first forecasts cardiac dynamics and flags deviations between predicted and observed features as anomaly indicators. The second uses a multi-task formulation fusing sleep, motion, and cardiac signals. Both use Transformer encoders and output daily anomaly scores derived from predictive uncertainty estimated via an ensemble of MLPs.
