# TimeRecipe: A Time-Series Forecasting Recipe via Benchmarking Module Level Effectiveness

**Arxiv:** 2506.06482 | **Date:** 2026-06-03 | **Area:** time-series

## What it does
TimeRecipe is a benchmarking framework that systematically evaluates time-series forecasting methods at the module level rather than as monolithic architectures. It conducts over 10,000 experiments to assess which components (tokenization, normalization, attention variants, feed-forward layers, output heads) actually drive performance. The result is a "recipe" — a set of best module combinations per task type.

## Direct parents (in Leo's library)
- [YY67LF3R] PatchTST (Nie 2023) — One of the architectures decomposed; introduced patch tokenization for TS transformers.
- [QBX2TI2X] iTransformer (Liu 2024) — Another architecture decomposed; inverted the attention dimension.
- [HLTA8MDK] TimesNet (Wu 2023) — Decomposed; introduced 2D periodicity-based temporal variation modeling.

## Delta from parents
Where PatchTST, iTransformer, and TimesNet each proposed a complete architecture with jointly designed components, TimeRecipe disentangles these components and measures which choices actually matter. The finding is that module-level choices (e.g., the tokenization scheme and normalization strategy) often matter more than the overall architecture family.

## Why Leo should care
For anyone building TS forecasting models (especially for biosignal data), this provides an empirical guide to which architectural choices transfer. If patch tokenization works better than channel-mixing regardless of backbone, Leo can skip architecture search and directly adopt the winning modules for wearable data pipelines.
