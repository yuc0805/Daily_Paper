# Time-R1: Time Series Forecasting as Reasoning — A Slow-Thinking Approach with Reinforced LLMs

**Arxiv:** 2506.10630 | **Date:** 2026-06-03 | **Area:** time-series

## What it does
Time-R1 is a two-stage reinforcement fine-tuning framework that teaches LLMs to perform multi-step reasoning about time series forecasting. Stage one runs supervised fine-tuning as warmup adaptation. Stage two applies reinforcement learning with a custom multi-objective reward designed for time series, plus GRIP (Group-based Relative Importance for Policy Optimization), which uses non-uniform sampling to push the model toward effective reasoning paths. Experiments show improved forecast accuracy across diverse datasets.

- [I2CIT4I7] TS-Agent (Liu 2025) — Demonstrated LLM reasoning over time series via tool-use and evidence logging; Time-R1 instead internalizes reasoning via RL fine-tuning.
- [VSCNJG5J] ChatTS (Xie 2025) — Showed multimodal LLMs can align time series as a modality; Time-R1 takes a different route by training the LLM to reason about numeric sequences directly.

## Delta from parents
Where DeepSeek-R1 showed that RL can elicit chain-of-thought reasoning in general-purpose LLMs, Time-R1 transfers this paradigm to time series forecasting — a domain where prior LLM approaches used either prompt engineering or modality alignment. Where TS-Agent kept the LLM frozen and routed reasoning through external tools, Time-R1 trains the LLM weights to internalize time-series-specific reasoning via a two-stage pipeline. The GRIP mechanism goes beyond standard GRPO by weighting sample exploration by relative importance, which is the main technical novelty over the vanilla DeepSeek-R1 RL setup.
