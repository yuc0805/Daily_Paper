# MemReread: Enhancing Agentic Long-Context Reasoning via Memory-Guided Rereading

**Arxiv:** 2605.10268 | **Date:** 2026-06-01 | **Area:** reasoning

## What it does
MemReread is a framework for reasoning over long documents at linear cost. It reads the document as a stream and keeps a running memory, but when that memory cannot answer the question it decomposes the question and rereads the relevant source text, recovering facts dropped during the first pass. A reinforcement learning stage improves length extrapolation and decides how many rereading passes each question needs.

## Direct parents (in Leo's library)
- [BDY3HUCV] Memory Mechanisms Survey (Huang 2026, graphify_id huang2026_memory) — catalogs how foundation agents store, update, and retrieve memory and names retrieval-based recall as a weak point.
- [HBLPTRMY] Chain-of-Thought Prompting (Wei 2023, graphify_id wei2023_cot) — established step-by-step reasoning traces for LLMs.

## Delta from parents
Where Huang 2026 describes memory mechanisms and flags that retrieval loses evidence, MemReread removes the retrieval module and rereads the raw source on demand, because retrieval loses evidence both at memory-formation time and when an off-target query is issued. Where Chain-of-Thought produces one forward reasoning trace, MemReread reasons non-linearly by jumping back into the document, because a single pass cannot recover a fact the running memory already overwrote. The RL controller that sets the number of rereading passes is the new mechanism that keeps the rereading cost bounded. The question-decomposition step also relates to decomposition-planning agents ADaPT (Prasad 2023) [J8DYBKW2] and LATS (Zhou 2024) [77ERE7HA], but it decomposes a question to decide what to reread rather than to plan actions.

## Why Leo should care
The pattern — cheap running summary, plus on-demand revisiting of raw input only when the summary is insufficient — transfers directly to long physiological streams, where full attention over hours of signal is too expensive but discarding early evidence is also costly.
