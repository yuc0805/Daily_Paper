# The Efficiency Frontier: A Unified Framework for Cost-Performance Optimization in LLM Context Management

**Arxiv:** 2605.23071 | **Date:** 2026-06-01 | **Area:** llm

## What it does
This paper frames LLM context management as a single cost-performance optimization problem. Instead of ad hoc rules such as truncation, summarization, or caching, it proposes "The Efficiency Frontier," a unified way to reason about the trade-off so a system can pick a context strategy on the frontier rather than by guesswork.

## Direct parents (in Leo's library)
- [PHB9VRVM] Attention Is All You Need (Vaswani 2017, graphify_id vaswani2017_transformer) — introduced self-attention, whose cost grows with the square of context length.

## Delta from parents
Where the Transformer pays attention cost quadratic in context length, this work treats that cost as an explicit budget to be optimized against accuracy, because at long context the question shifts from "can the model attend" to "what context is worth paying for." It approaches long-context cost from the systems side, complementing modeling-side methods such as MemReread (2605.10268) that reduce cost by linear streaming plus selective rereading.

## Why Leo should care
If Leo runs long-context models over extended sensor or clinical text records, an explicit cost-performance frontier is a practical tool for deciding how much context to retain per query. The framing is method-agnostic and applies to any long-input pipeline.
