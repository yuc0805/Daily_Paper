# HiMAE: Hierarchical Masked Autoencoders Discover Resolution-Specific Structure in Wearable Time Series

**Arxiv:** 2510.25785 | **Date:** 2026-06-25 | **Area:** time-series

## What it does
HiMAE is a self-supervised framework for wearable physiological time series. It pairs masked autoencoding with a hierarchical convolutional encoder-decoder, so it produces one embedding per temporal scale rather than a single collapsed embedding. Linear probes on each level then measure which resolution carries predictive signal for a given task. The model is small enough to run on a smartwatch-class CPU with sub-millisecond inference.

## Direct parents (in Leo's library)
- [A5HBRQB9] MAE (He et al.) — introduced masked reconstruction as a self-supervised pretraining objective.
- [6INGKIJV] How Mask Matters / MAE Theory (Zhang 2023) — studied what the masking ratio and structure buy, in the Health AI and Self-Supervised community.
- [HE9X47KN] HARMamba (Li 2024) — an efficient wearable architecture built on a state-space model, the efficiency alternative HiMAE argues against.
- [2XWEG7AF] Foundation Models for Biosignals: A Survey (Gu 2025) — maps the wearable foundation-model landscape this paper extends.

## Delta from parents
Where MAE and How Mask Matters fixed a flat encoder and produced one embedding, HiMAE keeps the masked-reconstruction objective but uses a U-Net-style hierarchical convolutional encoder so each level corresponds to a distinct temporal granularity, because the question is which scale a physiological outcome lives at, not just how to compress the signal. Where HARMamba sought wearable efficiency through a state-space backbone, HiMAE gets efficiency from convolutional hierarchy and adds a resolution probe that HARMamba lacks. It competes directly with the SSL-for-HAR god node in the same community: same masked-pretraining family, but the contribution is the scale analysis instead of the dataset scale.

## Why Leo should care
This is in Leo's primary area and gives both a compact on-device wearable encoder and a reusable probe for asking which time scale carries a given physiological signal. On the porting axis: the masked-autoencoder objective from vision is now firmly applied to wearable time series with a convolutional hierarchy, so that transfer is closed off as low-hanging fruit.
