# UniCanvas: A Diffusion-based Unified Model for Text-in-Image Joint Generation

**Arxiv:** 2606.04264 | **Date:** 2026-06-12 | **Area:** multi-modal

## What it does
UniCanvas (Yang, Chen, Yu, Yang, Zhen, Ma, Shen, Gan) unifies multimodal generation inside a single diffusion model by treating language as something to draw: instead of producing discrete text tokens, the model renders text as visual patterns on the shared pixel canvas during image synthesis. This sidesteps the standard failure split — autoregressive VLMs reason well but generate poor images, diffusion models generate well but produce incoherent text. Experiments show improvement over previous unified models.

## Direct parents (in Leo's library)
- [GX7WR7KA] DDPM (graphify: ho2020_ddpm, community 3 god node) — established the pixel-space denoising objective UniCanvas runs on.
- [DUERBZGM] DALL-E 2 (graphify: ramesh2022_dalle2, community 3 god node) — layered text conditioning on top of diffusion; text is input, never output.

## Delta from parents
Where DDPM established pixel-space denoising and DALL-E 2 made text an input condition, UniCanvas makes the pixel canvas itself the carrier of language output, because the discrete token head is the component that breaks in unified models. This extends the graphify bridge zhu2020_cyclegan to ho2020_ddpm, which already crossed GAN-era and diffusion-era generative CV; the new work pushes the bridge further into vision-language unification within community 3.
