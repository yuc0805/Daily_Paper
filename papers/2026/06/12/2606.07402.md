# M3Exam: Benchmarking Multimodal Memory for Realistic User-Agent Interactions

**Arxiv:** 2606.07402 | **Date:** 2026-06-12 | **Area:** agent

## What it does
M3Exam is a query-centric benchmark for multimodal conversational memory, built on realistic user-agent interaction logs rather than synthetic dialogue. Evaluation is multi-dimensional and covers cross-modal grounding and implicit information inference — can the agent recall something the user showed it, not just something the user said. This note is abstract-level; benchmark sizes and baseline numbers were not in the sources accessible today.

## Delta from parents
Where huang2026_memory added a taxonomy of memory mechanisms and durante2024_agentai described the multimodal interaction setting, M3Exam adds measurement: a benchmark that scores whether memory actually works under realistic multimodal use, because mechanism papers have so far been compared on incompatible private evaluations. It connects the community 0 memory line to community 3 (vision-language) through the cross-modal grounding requirement.

## Why Leo should care
The benchmark template transfers: there is no longitudinal patient-agent memory benchmark over wearable streams, where the "modality" to remember is a signal episode rather than an image.
