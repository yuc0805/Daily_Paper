# Harnessing Generalist Agents for Contextualized Time Series (TimeClaw)

**Arxiv:** 2606.05404 | **Date:** 2026-06-12 | **Area:** time-series

## What it does
TimeClaw is an agentic harness that gives a generalist LLM agent time-series-native runtime support. It combines three components: executable temporal tools so every analysis step is grounded and auditable, experience-driven capability evolution that turns successful trajectories into reusable analytical routines, and episodic multimodal memory that retrieves relevant past reasoning traces. Evaluation covers energy, finance, weather, traffic, and other real-world domains. Code is public.

## Direct parents (in Leo's library)
- [I2CIT4I7] TS-Agent (graphify: liu2025_tsagent, community 4 god node) — established the tool-calling loop for time-series reasoning: a frozen LLM calls atomic statistical operators and logs evidence.
- [VSCNJG5J] ChatTS (graphify: xie2025_chatts, community 4) — the alignment-training alternative: teach the model to see the series rather than give it tools.
- [BDY3HUCV] Rethinking Memory Mechanisms of Foundation Agents (graphify: huang2026_memory, community 0) — catalogued agent memory designs and flagged maintainability and reuse as open problems.

## Delta from parents
Where TS-Agent gave an LLM a fixed operator library and an evidence log for a single reasoning episode, TimeClaw turns that loop into a persistent harness — tools plus skill formation plus episodic memory — because end-to-end workflows repeat, and a stateless operator loop relearns the same analysis every time. Where ChatTS aligned series with language through training, TimeClaw keeps the LLM frozen and moves capability into the runtime, extending the tool-use side of the community 4 design split. The memory component imports designs catalogued in huang2026_memory from community 0 into community 4, adding a new cross-community edge in the graph.
