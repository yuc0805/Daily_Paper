# Ultralytics YOLO26: Unified Real-Time End-to-End Vision Models

**Arxiv:** 2606.03748 | **Date:** 2026-06-02 | **Area:** computer-vision

## What it does
YOLO26 is a unified real-time vision model family spanning five scales (n/s/m/l/x). It uses a dual-head design for native NMS-free end-to-end inference, removes DFL entirely for a lighter detection head with unconstrained regression range, and introduces a training pipeline combining MuSGD (a hybrid Muon-SGD optimizer adapted from LLM training), Progressive Loss (shifting supervision toward the inference-time head), and STAL (a label assignment strategy guaranteeing positive coverage for small objects). It achieves 40.9-57.5 mAP on COCO at 1.7-11.8 ms T4 TensorRT latency. An open-vocabulary extension (YOLOE-26) supports text-, visual-, and prompt-free inference.

## Direct parents (in Leo's library)
- [liu2021_swin] Swin Transformer (Liu 2021) — Introduced hierarchical vision transformers that influenced modern detection backbones.
- [carion2020_detr] DETR (Carion 2020) — Pioneered end-to-end object detection with transformers, removing NMS.

## Delta from parents
Where DETR removed NMS via a set-prediction approach with Hungarian matching (at the cost of slow convergence), YOLO26 achieves NMS-free inference through a dual-head architecture that is much faster to train and deploy. Where Swin Transformer focused on hierarchical feature extraction, YOLO26 brings LLM training techniques (specifically MuSGD) into the vision pipeline — a noteworthy cross-pollination from the language model community into object detection.

## Why Leo should care
The MuSGD optimizer transfer from LLM training is an interesting example of method portability across domains. The STAL label assignment for small objects might have analogues in bio-signal event detection where rare, short-duration events (like arrhythmias) are easily missed by standard training.
