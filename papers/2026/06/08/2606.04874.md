# Agent Planning Benchmark: A Diagnostic Framework for Planning Capabilities in LLM Agents

**Arxiv:** 2606.04874 | **Date:** 2026-06-03 | **Area:** agent

## What it does
APB is a planning-specific diagnostic benchmark with 4,209 multimodal cases across 22 domains and five settings. It tests holistic planning, feedback-conditioned step-wise planning, and robustness under extraneous tools, broken tools, and unsolvable tasks. Across 12 MLLMs, APB finds systematic weaknesses in long-horizon planning, tool-noise robustness, calibrated refusal, and inference-time refinement. Validation on ToolSandbox and tau-bench shows APB-guided refinement improves downstream execution.

## Delta from parents
Where ADaPT and LATS proposed specific planning algorithms, APB steps back to ask: what specific planning sub-skills do agents actually fail at? The benchmark separates planning from execution, so a failure can be attributed to either the plan or its downstream execution. This diagnostic angle is missing from prior agent benchmarks that only report end-to-end success. Where ToolkenGPT focused on selecting the right tool, APB tests robustness when extraneous or broken tools are present — a more adversarial test of tool selection.

## Why Leo should care
APB provides a structured way to evaluate any agent pipeline on planning sub-capabilities. If Leo builds agents for automated experiment design or data processing pipelines, APB's taxonomy (holistic planning, robustness, refusal calibration) is a useful evaluation framework.
