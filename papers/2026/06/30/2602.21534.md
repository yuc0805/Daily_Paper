# ARLArena: A Unified Framework for Stable Agentic Reinforcement Learning

**Arxiv:** 2602.21534 | **Date:** 2026-06-30 | **Area:** agent

## What it does
ARLArena is a framework for training LLM agents with reinforcement learning in a stable way. It standardizes the environment interface, the reward bookkeeping, and the policy-update loop so that agentic RL runs do not diverge or collapse, which is a common problem when an LLM both acts and learns from sparse task rewards. ## Direct parents (in Leo's library)
- [Z5IWHZAE] DeepSeek-R1 — showed that reinforcement learning with a simple reward can train reasoning behavior in an LLM.
- [77ERE7HA] LATS — used tree search over language-agent actions to plan and backtrack.
- [J8DYBKW2] ADaPT — decomposed a task into sub-tasks as needed during planning.

## Delta from parents
Where DeepSeek-R1 applied RL to single-turn reasoning, ARLArena targets the multi-turn agent setting, where rewards arrive late and credit assignment across steps is the hard part. Where LATS and ADaPT improved planning through search and decomposition at inference time, ARLArena instead changes how the policy is trained, aiming for stable updates rather than a better search at test time. The contribution is training infrastructure and stability rather than a new planning trick.

## Why Leo should care
Stable agentic RL is the bottleneck that keeps tool-using agents from being trained end to end. If the stability claims hold, the same recipe could later train agents that operate over sensor or clinical data, which is the agent direction Leo watches.
