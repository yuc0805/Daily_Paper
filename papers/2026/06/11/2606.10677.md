# Infini Memory: Maintainable Topic Documents for Long-Term LLM Agent Memory

**Arxiv:** 2606.10677 | **Date:** 2026-06-09 | **Area:** agent

## What it does
Infini Memory proposes a text-based persistent memory architecture for LLM agents in which memory is a set of topic documents: each document is a semantic unit that collects related evidence, preserves metadata, and revises facts over time. This contrasts with append-only logs and vector stores of isolated snippets, and targets the long-term maintenance problems — contradiction, staleness, and unbounded growth — that flat retrieval memories do not handle. Summary is abstract-level; benchmark numbers were not available in accessible sources at digest time.

## Delta from parents
Where the Huang 2026 survey described memory write and read policies in the abstract, this paper commits to one opinionated structure — topic documents with revision semantics — because fact revision is difficult to express in append-only or embedding-only memories. The design choice runs opposite to the latent-memory direction of the papers in yesterday's digest (ExpWeaver, MemoPilot): Infini Memory argues that staying in plain text is what makes memory maintainable and auditable over months of agent operation.

## Why Leo should care
Long-running research assistants and clinical monitoring agents both need memories whose facts can be revised when the world changes. The topic-document pattern is also the same structure as this knowledge graph repository — area pages that accumulate and revise evidence — which suggests the pattern scales.
