# PulseLM: A Foundation Dataset and Benchmark for PPG-Text Learning

**Arxiv:** 2603.03331 | **Date:** 2026-06-26 | **Area:** time-series

## What it does
PulseLM is a large-scale dataset and benchmark that pairs raw PPG waveforms with natural-language question-answer items. It aggregates recordings from fifteen public sources, standardizes them into 10-second segments, and harmonizes the labels into twelve common physiological question-answering tasks. The release contains 1.31 million segments and 3.15 million closed-ended question-answer pairs, plus fixed preprocessing and evaluation protocols and baseline PPG-aware language models.

## Direct parents (in Leo's library)
- [ELYUE3NF] Sensor2Text (chen2024_sensor2text) — established natural-language description of wearable sensor streams for activity tracking.
- [2XWEG7AF] Foundation Models for Biosignals: A Survey (gu2025_biosignals) — mapped the design space of biosignal foundation models.
- [I2CIT4I7] TS-Agent (liu2025_tsagent) — framed time-series understanding as a language-driven reasoning task.

## Delta from parents
Where Sensor2Text produced free text from sensor streams in a single activity-tracking setting, PulseLM does the same waveform-to-language pairing at dataset scale and pins it into a graded closed-ended benchmark, because a shared scoring protocol is what Sensor2Text lacked. Where the biosignals survey described what foundation models for PPG should look like, PulseLM supplies the standardized data and evaluation those models need. The QA framing follows TS-Agent's view of signals as objects you query in language, but turns it into a fixed, reproducible test rather than an agent demonstration.

## Why Leo should care
This is in the center of the time-series and bio-sensing focus. It imports the vision-language question-answering format (an encoder plus an instruction-tuned language backbone) into PPG, so that recipe is now a ported, low-hanging item for PPG. The lasting value is a three-million-pair shared benchmark, which is what makes later method transfer measurable instead of anecdotal.
