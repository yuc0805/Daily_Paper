# HybridThinker: Efficient Chain-of-Thought Reasoning via Compressed Memory and Transient Thought Steps

**Arxiv:** 2606.03768 | **Date:** 2026-06-02 | **Area:** reasoning

## What it does
HybridThinker compresses chain-of-thought traces by encoding completed reasoning steps into compact memory tokens while temporarily retaining the original thought steps for fine-grained detail access. A hybrid training scheme randomly masks some thought steps (forcing the model to rely on memory tokens for those) while keeping others accessible. This prevents the model from bypassing memory compression entirely. Across four reasoning benchmarks, HybridThinker matches uncompressed baselines while advancing CoT compression state-of-the-art by 5.8 points average accuracy at similar inference time.

## Delta from parents
Where Wei (2023) and DeepSeek-R1 produce reasoning traces without any compression, and prior compression methods either truncate or fully replace thought steps with memory tokens (losing fine-grained information), HybridThinker keeps both: compressed memory tokens for long-range recall and temporarily retained thought steps for local detail. The hybrid training scheme is the key insight — it forces the model to actually learn compression rather than shortcutting through the retained steps.

## Why Leo should care
If reasoning models are going to be deployed on biosignal analysis tasks (e.g., clinical decision support from wearable data), CoT compression is a practical requirement. The memory-token approach could also be adapted for compressing long sensor input sequences.
