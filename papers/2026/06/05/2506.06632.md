# E2H Reasoner: Curriculum RL from Easy to Hard Tasks

**Arxiv:** 2506.06632 | **Date:** 2026-06-05 | **Area:** reasoning

## What it does
Introduces an easy-to-hard curriculum for reinforcement learning that enables small language models (1.5B to 3B parameters) to learn reasoning from RL. Standard GRPO fails on small models because the reward signal is too sparse — the model almost never produces correct answers on hard problems, so there is nothing to reinforce. E2H schedules tasks from easy to hard using a curriculum derived from approximate policy iteration, which provides convergence guarantees that vanilla GRPO lacks. The method produces significant accuracy improvements on models that otherwise fail completely during RL training.

## Delta from parents
DeepSeek-R1's GRPO works at the 671B parameter scale where the model can already produce occasional correct answers on hard problems, providing a bootstrap signal for RL. At 1.5B-3B parameters, this bootstrap fails — the model's initial policy is too weak to stumble onto correct solutions for hard tasks, creating a dead-reward problem. E2H solves this by starting RL training on easy tasks where even small models can occasionally succeed, then gradually increasing difficulty as the policy improves. The approximate policy iteration framework provides theoretical grounding: each curriculum stage is a policy improvement step with bounded suboptimality.

## Why Leo should care
Small models (1.5B-3B) are the only models that can plausibly run on wearable and edge devices. If RL-based reasoning is to reach on-device clinical inference — for example, a wearable that reasons about anomalous sensor patterns in real time — curriculum RL is likely a necessary ingredient. E2H provides the first evidence that this is feasible and supplies the theoretical framework to do it.
