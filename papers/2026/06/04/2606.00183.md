# Agentic Transformers Provably Learn to Search via RL

**Arxiv:** 2606.00183 | **Date:** 2026-05-29 | **Area:** reasoning, agent

## What it does
Provides a theoretical analysis of how transformer policies acquire depth-first search (DFS) capabilities through reinforcement learning in k-ary tree environments. The paper identifies a two-head mechanism: one attention head tracks the current action trajectory, while a second head detects dead-end failures and triggers backtracking. A central result is depth generalization — policies trained on trees of depth 1 and 2 can successfully search trees of greater depth at test time.

## Direct parents (in Leo's library)
- [wei2023_cot] Chain-of-Thought Prompting — Showed that language models can perform multi-step reasoning, raising the question of whether they can learn systematic search.
- [zhou2024_lats] Language Agent Tree Search — Introduced tree search as an explicit planning mechanism for LLM agents, which this paper now shows can emerge from RL alone.
- [prasad2023_adapt] ADaPT — Demonstrated adaptive planning with transformers, providing empirical evidence that RL-trained transformers can acquire planning behaviors.

## Delta from parents
Where LATS and ADaPT showed empirically that transformers can execute search-like behaviors (either through prompting or RL), this paper provides the first formal proof that RL training on shallow trees produces policies that generalize to deeper trees. The identified two-head mechanism (trajectory tracking + failure detection) is a clean theoretical characterization of what prior work observed only experimentally. This moves the field from "transformers seem to learn search" to "here is exactly how and why they do, and here is the formal guarantee on depth generalization."

## Why Leo should care
This is a theory paper, but it has practical implications for agent design. If two attention heads suffice for DFS, then agentic transformer systems might not need explicit search modules — the search capability can be trained in. The depth generalization result is particularly noteworthy: it suggests that training on simple tasks can yield agents that handle harder instances, which is relevant to any agentic pipeline Leo builds.
