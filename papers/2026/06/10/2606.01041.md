# ExpWeaver: LLM Agents Learn from Experience via Latent RAG

**Arxiv:** 2606.01041 | **Date:** 2026-06-01 | **Area:** agent

## What it does
ExpWeaver encodes past agent experiences using the LLM's own hidden states, retrieves relevant experiences directly in latent space at each decoding step via cross-attention aggregation and gated residual mechanisms, and optimizes the full pipeline end-to-end with reinforcement learning. This eliminates the separate RAG module and the token overhead of concatenating retrieved text into the context window.

## Direct parents (in Leo's library)
- [BDY3HUCV] Rethinking Memory Mechanisms (Huang 2026) — Surveyed memory architectures including retrieval-based approaches; ExpWeaver implements a latent-space variant of the retrieval-augmented memory pattern.
- [6RDHVVA2] ToolkenGPT (Hao 2024) — Showed that tool/knowledge embeddings can be integrated into the LLM decoding process; ExpWeaver applies the same principle to experience retrieval.

## Delta from parents
Where standard experience-retrieval methods (surveyed in Huang 2026) operate in text space — retrieving past trajectories by semantic similarity and pasting them into the prompt — ExpWeaver moves retrieval into the LLM's hidden-state space. This removes the token-budget bottleneck and couples retrieval with generation so the model can attend to relevant experience at every decoding step rather than only at the prompt boundary. Where ToolkenGPT embedded tool identifiers into the vocabulary, ExpWeaver embeds entire experience traces into the latent representation.

## Why Leo should care
The latent-RAG design pattern is broadly applicable. If Leo builds agents that operate over repeated time-series analysis sessions (e.g., a clinical monitoring agent that sees similar patient patterns), the ability to retrieve and attend to past experiences in latent space — without consuming context window — is a practical advantage. This is also methodologically interesting as a bridge between the agent community (Community 0) and the reasoning community: latent experience retrieval is a form of implicit reasoning over past interactions.
