# MemoPilot: Enhancing Test-Time Learning of LLM Agents via RL over Memory

**Arxiv:** 2606.08656 | **Date:** 2026-06-10 | **Area:** agent

## What it does
MemoPilot is a plug-in memory copilot that trains the memory-update process of a frozen LLM agent using multi-turn GRPO. It formulates memory updating as a sequential decision problem, introduces turn-wise reward signals with context-independent advantage estimation, and substantially improves test-time learning across repeated interactions without modifying the base LLM.

## Direct parents (in Leo's library)
- [BDY3HUCV] Rethinking Memory Mechanisms (Huang 2026) — Surveyed memory architectures for foundation agents; MemoPilot provides a concrete trainable instantiation of the "memory-as-policy" idea discussed there.
- [77ERE7HA] LATS (Zhou 2024) — Used tree search over agent actions; MemoPilot similarly optimizes multi-step agent behavior but focuses on the memory layer rather than action selection.
- [Z5IWHZAE] DeepSeek-R1 (2025) — The GRPO training recipe comes from the same family of group relative policy optimization used in R1.

## Delta from parents
Where Huang et al. (2026) surveyed memory mechanisms and identified the gap between hand-designed memory prompts and optimal memory policies, MemoPilot fills that gap with end-to-end RL training. Where LATS uses tree search over action trajectories, MemoPilot fixes the player LLM and only trains the memory update policy, keeping the approach modular and applicable to any frozen LLM.

## Why Leo should care
If Leo builds agentic systems for time-series analysis (following the TS-Agent direction), the question of how agents accumulate and reuse experience across sessions is central. MemoPilot shows that the memory-update process itself can be optimized via RL, which is a practical design pattern for any agent that runs repeatedly over similar data.
