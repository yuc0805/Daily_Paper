# Intern-S2-Mobius: Foundation Model with Decoupled Knowledge and Reasoning

**Arxiv:** 2608.14290 | **Date:** 2026-08-17 | **Area:** llm

## What it does
Mobius-v0 splits a transformer into a globally shared Memory block built from feed-forward layers that stores knowledge vectors, and several Reasoner blocks built from self-attention that query that memory repeatedly. Hidden states act as both cache and carrier between the two. A 7B model trained from scratch on this architecture matches a 7B transformer baseline using 62.6 percent of the baseline's training data, and Intern-S2-Mobius, continually pretrained from Qwen3.5-35B, matches downstream scores with close to a 4x end-to-end inference speedup.

## Direct parents (in Leo's library)
- [PHB9VRVM] Attention Is All You Need (Vaswani 2017) — the interleaved attention-plus-feed-forward block that Mobius takes apart.
- [2JCKA7GI] DeepSeek-V3 (2024) — showed that routing computation to a subset of parameters buys efficiency at scale.
- [WIGLUNFZ] ST-MoE (Zoph 2022) — established stable sparse expert routing in the feed-forward position.

## Delta from parents
Where the original transformer interleaves attention and feed-forward layers so that knowledge and computation are entangled at every depth, Mobius separates them into one shared memory bank and several reasoning modules that query it, because entanglement forces the model to re-store the same facts at many depths. Where DeepSeek-V3 and ST-MoE reduce cost by activating a sparse subset of feed-forward experts while keeping the layer stack intact, Mobius changes the stack itself and makes memory access an explicit, repeated read rather than a routed forward pass. The reported result is that this separation improves knowledge compression, which shows up as needing 62.6 percent of the data at 7B, and shortens the sequential compute path, which shows up as the roughly 4x inference speedup at 35B.

## Why Leo should care
An architecture that makes stored knowledge addressable separately from the reasoning path is useful for any domain where the knowledge component is small and the reasoning is repetitive, which describes physiological signal interpretation reasonably well. The 4x inference speedup at similar quality also matters for on-device settings. Treat the numbers as preliminary until an independent reproduction appears, since the comparison is against a self-trained baseline.
