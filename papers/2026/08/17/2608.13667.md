# Second Thought: Reasoning in Parallel as LLM Agents Act and Observe

**Arxiv:** 2608.13667 | **Date:** 2026-08-17 | **Area:** agent

## What it does
In the ReAct loop an agent reasons, acts, then waits for the environment, and during that wait its reasoning is idle. Second Thought is a training-free framework that forks four auxiliary reasoning branches the moment each Thought phase ends, decodes them concurrently with the main loop, and merges them back when the observation arrives. Across three agentic benchmarks and three reasoning models it lowers average turn count in all nine model-benchmark pairs and cuts main-thread decoding in six of them by up to 43 percent, roughly 20 percent on average in those settings. Pass@1 is statistically unchanged in seven of nine pairs, and the two significant changes are increases of 12.4 and 10.2 points.

## Direct parents (in Leo's library)
- [BZKDNHD6] SPRINT (Biju 2025) — reorganised reasoning traces so a model can parallelise its own chain of thought.
- [77ERE7HA] LATS (Zhou 2024) — searched over multiple reasoning and action branches inside the agent loop.
- [HBLPTRMY] Chain-of-Thought (Wei 2023) — established the sequential Thought phase this work is trying to get off the critical path.

## Delta from parents
Where SPRINT parallelises reasoning by post-training the model to emit branchable traces, Second Thought needs no training at all and instead exploits wall-clock time that the agent was already spending waiting on the environment, because the bottleneck it targets is idle latency rather than trace structure. Where LATS spends extra compute searching branches on the main thread and pays for it in latency, Second Thought moves the extra branches off the main thread entirely, so the compute-matched control it reports is the meaningful comparison: against that control it reaches strictly higher Pass@1 with 1.3 to 3.2 times less sequential decoding. Where chain-of-thought made the Thought phase the place where reasoning happens, this paper argues the Action and Observation interval is a second, unused place.

## Why Leo should care
The framing generalises past LLM agents: any system that alternates between computing and waiting on a slow external source has an idle window. Streaming physiological pipelines wait on the next sensor window by construction, so the same trick applies with the sensor buffer in place of the environment observation. Nothing in graphify Community 4 or 5 does this, so it is an open transfer rather than a closed one. The method is training-free, which makes it cheap to test.
