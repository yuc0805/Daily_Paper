# MobileMem: Learning from a Year of Mobile Experiences

**Arxiv:** 2608.13606 | **Date:** 2026-08-17 | **Area:** agent

## What it does
MobileMem is a benchmark and framework for on-device long-term memory in personal assistant agents, built on a year-scale collection of mobile experiences. A knowledge-grounded synthesis pipeline turns raw user-app sessions into coherent, temporally consistent long-horizon trajectories. The benchmark provides text-only and multimodal settings and tests multi-hop and temporal reasoning, knowledge updating when facts change, and inference of preferences the user never stated.

## Direct parents (in Leo's library)
- [BDY3HUCV] Memory Mechanisms of Foundation Agents (Huang 2026) — surveyed how agents store and retrieve memory, and identified the lack of long-horizon evaluation.
- [ICD9EG8Q] GLOBEM (Xu 2023) — multi-year behaviour dataset that established year-scale longitudinal collection as a workable protocol.
- [K4PR34NU] MindScape (Nepal 2024) — paired behavioural sensing with an LLM to generate personalised journaling prompts.

## Delta from parents
Where the Huang 2026 memory survey catalogued mechanisms and noted that benchmarks stop at conversation length, MobileMem supplies the missing evaluation at year scale, because mechanisms cannot be compared without a task that actually stresses them. Where GLOBEM collected multi-year passive sensing streams and framed the task as behaviour prediction, MobileMem collects a comparable time span of app interaction traces and frames the task as memory retrieval and belief updating, because the question is what the agent remembers rather than what it can classify. Where MindScape used a fixed window of sensing to condition one generation step, MobileMem requires the agent to carry state across a year and revise it when the user's situation changes.

## Why Leo should care
This is the memory-agent literature moving onto longitudinal personal data, which is the same substrate as wearable behaviour research. It sits on the graphify bridge between the agent community and the wearable sensing community: MindScape and GLOBEM are Community 5 nodes, the memory survey is Community 0, and MobileMem now connects them with a shared evaluation. The synthesis pipeline is also directly reusable — the same construction could produce year-scale trajectories from wearable streams rather than app sessions, which would give bio-sensing a long-horizon benchmark it currently lacks. In gap-watch terms this is a partial port: LLM memory methods have now been applied to app-interaction logs but not yet to continuous physiological signals.
