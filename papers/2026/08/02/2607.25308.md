# CAST: Game Solvers as Turn-Level Teachers for LLM Agents

**Arxiv:** 2607.25308 | **Date:** 2026-08-02 | **Area:** reasoning

## What it does
Adds dense turn-level credit to reinforcement learning from verifiable rewards (RLVR) for LLM agents in long-horizon games. Uses a game solver's state-value estimate: when the solver's value rises after an action, that action advanced the state. CAST (Credit Assignment from Solver Teachers) turns these value changes into per-turn solver advantages injected into RLVR. Under a soft-optimal solver assumption, maximizing the solver advantage equals on-policy distillation from the solver, using only scalar values rather than teacher logits.

## Delta from parents
Where DeepSeek-R1 trains with sparse final verifiable rewards, CAST keeps the RLVR frame but adds a dense per-turn credit term, because sparse terminal reward is the exact thing that makes long-horizon credit assignment hard. Where LATS uses a value estimate at search time to guide tree rollouts, CAST uses a solver's value changes at training time to shape the policy gradient. This extends the graphify cross-area bridge deepseek2025_r1 to wei2023_cot, which already crossed reasoning-via-RL and reasoning-via-prompting, by pushing toward process-level supervision of the reasoning trace rather than outcome-only supervision.

## Why Leo should care
A concrete, cheap mechanism for dense credit assignment that transfers beyond games: any setting with a value-like "solver" (a heuristic, a score, an early-warning model) can supply per-step signal. Relevant to the reasoning-agent methods Leo watches for porting. See the Tier D transfer hypothesis: a validated clinical deterioration score as the solver for a monitoring agent.
