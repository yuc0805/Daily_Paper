# Spatial Memory Agent: Experience-Grounded Procedure Memory for Spatial Intelligence

**Arxiv:** 2608.12743 | **Date:** 2026-08-16 | **Area:** agent

## What it does
SMA improves the spatial reasoning of a frozen vision-language model without updating any parameters and without calling external depth or 3D reconstruction tools at inference. In a verifiable spatial environment the agent answers, receives a reward, and runs verifier-guided reflection to compress the episode into a short transferable lesson. Each lesson carries a Transfer Reliability Score, initialised uniformly and recalibrated from whether later retrievals of that lesson led to correct answers. At deployment the memory is read-only and lessons are retrieved by a semantic filter combined with a similarity-and-TRS ranking. Across five spatial benchmarks and four base VLMs, SMA has the highest macro average in every base-model block and the best accuracy in most of the twenty evaluations.

## Delta from parents
Where the memory survey catalogued write and retrieve policies without a mechanism for deciding which stored item deserves trust, SMA attaches a scalar to each lesson and updates it from downstream retrieval outcomes, which turns memory quality into an online estimation problem rather than a fixed heuristic. Where LATS used reflection inside a single task episode to guide search, SMA moves the product of reflection outside the episode: the lesson is written once and read by later, different tasks, so reflection becomes a training-free knowledge accumulation step rather than a within-episode planner. Against PyVision the disagreement is about where spatial competence should live, in an external depth or reconstruction tool called at inference, or in retrieved text that steers a frozen model. This is a direct extension of the cross-area bridge `hao2024_toolkengpt` to `zhao2025_pyvision` in the library: both bridge nodes assume the agent reaches outside itself for capability, and SMA argues the same gain is available from memory alone.

## Why Leo should care
The Transfer Reliability Score is the part worth taking. It is a cheap online reliability estimate over stored items, and nothing about it is spatial or even visual. There is no ablation in the abstract separating the contribution of TRS from that of lesson distillation, so the score's value is not yet isolated.
