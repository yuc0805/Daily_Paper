# Zero-WAM: In-Context World-Action Modeling from Human Videos for Open-Ended Task Generalization

**Arxiv:** 2608.26103 | **Date:** 2026-08-30 | **Area:** world-model-rl

## What it does
Targets zero-shot cross-task generalization in manipulation, where a policy must execute a task never seen in training. The argument is that language models solved the analogous problem by moving task specification into the context, and that the natural in-context specification for manipulation is a human video, since it carries visual detail about intended task evolution that a sentence does not. Zero-WAM is a causal video-action model that executes unseen tasks by following in-context human video guidance. Because task-rich paired human-robot data barely exists, the authors build an automatic pipeline converting task-sampled robot trajectories into semantically matched human videos, yielding HumanGen, 74.2K human-robot in-context pairs.

## Delta from parents
Where DINO-WM built a world model in a frozen visual latent space and planned inside it for a fixed task family, Zero-WAM makes the task itself an input, because planning machinery does not help when the task specification is the missing piece. Where Navigation World Models conditioned prediction on the agent's own trajectory, this conditions on someone else's demonstration, which is what converts a world model into a policy for unseen tasks. Where VideoMAE learned task-agnostic video representations by masked reconstruction, the representation here must carry task intent across a human-to-robot embodiment gap, and the HumanGen synthesis pipeline substitutes for the paired data that learning that mapping would otherwise require.

## Why Leo should care
The reusable idea is in-context task specification: a new task is named by an exemplar placed in the context window rather than by a fine-tuning pass. Tier D flags the wearable-sensing version of this as an unported opportunity — specifying a new activity class with a single demonstration segment of raw sensor data. The synthesis pipeline is the second transferable piece, since it shows the paired-data shortage can be handled by generating matched exemplar-query pairs from existing labelled trajectories rather than collecting new recordings.
