# SkillRise: Agentic Reinforcement Learning for Cross-Task Skill Evolution

**Arxiv:** 2607.26784 | **Date:** 2026-08-03 | **Area:** agent

## What it does
SkillRise is a reinforcement learning framework in which a single policy alternates between solving a task and curating an evolving skill document that it passes to the next related task. Credit assignment is decoupled: solving is supervised by the current task outcome, and curation is supervised by discounted downstream outcomes. On ALFWorld, WebShop, and ScienceWorld it reaches the best Pass@1 among compared methods, with gains of 2.3 to 8.5 percentage points over the strongest baseline, and it shows test-time scaling across tasks.

## Delta from parents
Where DeepSeek-R1 improves a policy within a task using outcome rewards, SkillRise adds a second, cross-task learning signal that rewards writing down transferable skills, because the goal is reuse across related tasks rather than mastery of one. Where the memory survey catalogs how agents store and recall information, SkillRise makes the memory itself a learned object shaped by the reward function, so the skill document is trained rather than hand-designed.

## Why Leo should care
This is a secondary-interest paper (agents and reasoning). Its cross-task credit assignment and its idea of a reward-shaped, evolving skill document are transferable to time-series analysis: a single agent could curate reusable statistical-analysis skills across many datasets rather than re-deriving each analysis per dataset. The method imports agentic reinforcement learning from the LLM-agent line; that idea is not yet ported to time-series reasoning agents.
