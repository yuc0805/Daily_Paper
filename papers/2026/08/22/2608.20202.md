# MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use

**Arxiv:** 2608.20202 | **Date:** 2026-08-22 | **Area:** agent

## What it does
MemTrapBench measures a failure mode that existing memory benchmarks do not test: whether a retrieved memory that is faithfully recorded and semantically relevant nevertheless degrades reasoning on the current task. The benchmark separates two forms, Reasoning Fixation, where the model reuses a stored reasoning path that no longer applies, and Belief Distortion, where a stored claim overrides fresh evidence. Across two model families and five memory frameworks every memory strategy scored below the no-memory setting, with the strongest methods still dropping more than 10%. The authors propose AdaptiveMem, an inference-time instruction that tells the model to check for these traps, which recovers much of the loss without hurting standard memory benchmarks.

## Direct parents (in Leo's library)
- [BDY3HUCV] Rethinking Memory Mechanisms of Foundation Agents (Huang 2026) — catalogued how agent memory is written, stored and retrieved, and treated retrieval fidelity as the quality measure.
- [NEKX3K3N] Machine Theory of Mind (Rabinowitz 2018) — established that modelling a held belief, and modelling when that belief is wrong, are separate capabilities.

## Delta from parents
Where the Huang 2026 memory survey organised the field around whether the right item is retrieved, MemTrapBench shows that retrieving the right item is not sufficient and can be actively harmful, because a correct memory still carries a reasoning frame that may not transfer to the current instance. Where Machine Theory of Mind studied a model reasoning about *another* agent's false belief, this paper studies a model inheriting a false frame from its *own* stored history, which is the same false-belief problem turned inward. The finding that all five memory frameworks lose to the no-memory baseline is the number worth carrying: it says the field has been optimising retrieval accuracy against a metric that does not predict task performance.

## Why Leo should care
This is a direct warning for any longitudinal health agent. A system that stores a user's prior sleep or heart-rate summaries and retrieves them when interpreting today's recording is exactly the setup MemTrapBench penalises, because a stale physiological baseline is a faithful memory that distorts a current judgement. GLOBEM and MindScape in Community 5 both assume accumulated user history helps; no paper in that community tests whether it hurts.
