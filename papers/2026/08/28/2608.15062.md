# Gated Recurrent Transformers: Expressive Depth through Recurrent Modulation in Transformers

**Arxiv:** 2608.15062 | **Date:** 2026-08-28 | **Area:** llm

## What it does
Replaces most of a transformer stack with a single shared core block applied R times, bracketed by fixed-depth prelude and coda blocks. A lightweight elementwise update gate, conditioned on the hidden state, the prelude output and noise resampled at each step, controls how much the representation changes per recurrence, so the same weights behave differently at different depths. Under matched FLOPs, a 3-layer model matches a 12-layer GPT-2 Small baseline and leads Mixture-of-Recursions and heavy-tail depth sampling in all nine scale-by-budget cells. Under matched parameters and data, deeper recurrence reaches 2.76 validation loss against 2.84 for the non-recurrent counterpart. At large scale the trade is 63 percent fewer parameters and 59 percent less peak decoding memory for 10 percent higher compiled generation latency.

## Delta from parents
Where Mamba and HARMamba made a model recurrent along the sequence axis, this paper makes it recurrent along the depth axis and leaves attention over the sequence intact. The distinction matters because the two approaches relieve different constraints: sequence recurrence reduces the cost of long context, depth recurrence reduces parameter count and decoding memory at fixed context. Where plain weight sharing across layers has historically lost quality by forcing an identical transformation at every depth, the gate plus resampled noise restores per-step specialisation without per-step weights, which is what makes the 3-layer to 12-layer equivalence hold. The honest cost is latency, not quality: 10 percent slower generation for 63 percent fewer parameters.

## Why Leo should care
On-device sensing models are usually constrained by parameter storage and peak memory rather than by FLOPs, which is precisely the axis this method trades along. Community 2 in the graphify prior already contains the sequence-recurrence port into wearable sensing through HARMamba, but nothing in the library applies depth recurrence to a physiological encoder, so this remains open. The result is also a caution for any comparison table that reports layer counts as a proxy for capacity.
