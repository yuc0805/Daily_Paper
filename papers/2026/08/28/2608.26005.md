# VoiceMem: Streaming Dual-Brain Memory for Real-Time Interaction

**Arxiv:** 2608.26005 | **Date:** 2026-08-28 | **Area:** audio

## What it does
A memory architecture for duplex speech language models built from two parallel stores: an informational track that holds factual content from the conversation and an affective track that holds emotional and persona state. Both are read and written in streaming fashion during the conversation rather than between turns. Under top-5 retrieval the informational track beats Mem0 at top-200 by close to 30 points, meaning it finds the right item with a fortieth of the retrieved context. The affective track uses short-horizon and long-horizon attribution together with a two-node persona representation and reports the best published aggregate score across three persona benchmarks, an improvement of 4.29 points. Retrieval completes in 134 ms, which fits inside standard voice-activity-detection latency, so the memory adds no perceptible delay.

## Delta from parents
Where the Huang memory survey organised agent memory as an offline process running between turns, this paper puts read and write inside the turn and gives the system a latency budget it must meet, which changes what a memory design is allowed to cost. Where LTU showed that an audio encoder can be attached to a language model, VoiceMem separates what is being said from how it is being said and keeps two stores rather than one, because collapsing them into a single text summary discards the affective signal that HeAR argues is the useful part of an audio stream. The concrete result of that split is the retrieval efficiency number: top-5 beating a general memory system at top-200 suggests the gain comes from routing rather than from a better encoder.

## Why Leo should care
The design pattern is streaming memory over a continuous signal under a hard latency budget, and that pattern is not specific to speech. Continuous physiological streams have the same structure: a content channel, a state channel, and a real-time constraint that rules out batch summarisation. The imported method is agent memory from the language-model literature; the import is now closed for speech, and the separation of content from affect is the transferable piece rather than the speech pipeline itself.
