# Repo-To-Skill / DisCo: Distilling GitHub Repositories Into AI4AI Skills

**Arxiv:** 2609.02749 | **Date:** 2026-09-03 | **Area:** agent

## What it does
Names a missing layer in autonomous research agents, called operational knowledge: the know-how that separates knowing a method from making it work. DisCo distills that knowledge from repositories and papers into compact verified skills, in a task-agnostic pass over widely used repositories and a task-oriented pass for a specific job. The task-agnostic pass over 1,000 repositories produces the AREX-Skill Library of more than 5,000 verified skills across 20 areas and 178 capability families. With backbone, harness, and execution budget held fixed, the skill-equipped agent scores 134.3 percent higher on MLE-bench, 34.4 percent higher on PaperBench, 9.2 percent higher on FrontierCS, and 14.0 percent higher on PassNet.

## Delta from parents
Where ToolkenGPT compressed a tool's interface so the model could call it, DisCo compresses a repository's operating procedure so the model can configure it correctly, because the bottleneck being attacked is not invocation but correct use. Where the Memory Mechanisms survey treated memory as an episodic trace built during a run and therefore useful only after the agent has met a similar problem, DisCo builds a curated and verified library offline and shares it across tasks, removing that dependency. Where the Agent AI survey placed know-how outside the architecture by assumption, this paper argues the harness is complete and the missing piece is the content loaded into it, and it supports that by holding backbone, harness and budget fixed while varying only the skills.

## Why Leo should care
This extends `hao2024_toolkengpt`, which already bridges to `zhao2025_pyvision` in the library under the tool-using-agents relation, and pushes that bridge from tool invocation toward tool operation. The transfer to bio-sensing is direct and unported: filter cutoffs, artifact rejection thresholds, resampling conventions and normalization choices decide whether a physiological pipeline works, and they live in repository code rather than in method sections. An AREX-style distillation over standard wearable and physiological toolboxes would produce the artifact a time-series research agent currently lacks; Community 5 contains no analogue.
