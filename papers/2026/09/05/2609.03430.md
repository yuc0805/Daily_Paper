# Random Attention: Rethinking KV Cache Eviction for Efficient Reasoning

**Arxiv:** 2609.03430 | **Date:** 2026-09-05 | **Area:** llm

## What it does
Every prior KV cache eviction method scores each cached token by an estimate of how much it will matter later and keeps the top-scoring ones. This paper removes the score. Random Attention keeps the prompt and evicts uniformly at random within each attention head, and across four models and six reasoning tasks it matches the strongest prior evictor while serving 32 to 43 percent higher throughput in vLLM. Two controlled experiments explain the result: the prompt is the fragile part of the cache, and most of the measured gap between scorers is whether their signal happened to keep it; and the reasoning trace protects itself with redundancy in the text, where the model restates what it still needs, and across heads, where each head keeps its own copy.

## Direct parents (in Leo's library)
- [PHB9VRVM] Attention Is All You Need (2017) — graphify `vaswani2017_transformer`, Community 2. The KV cache and its linear growth are a direct consequence of this attention formulation.
- [743XA29Y] DeepSeek-V2 (2024) — llm area. Attacks the same memory bottleneck by compressing the cache into a low-rank latent rather than evicting from it.
- [Z5IWHZAE] DeepSeek-R1 (2025) — graphify `deepseek2025_r1`, Community 0. Produced the long RL-trained reasoning traces that make the cache a bottleneck, and the redundancy this paper exploits is a property of those traces.

## Delta from parents
Where DeepSeek-V2 reduced the per-token cost of the cache with a learned low-rank latent, Random Attention reduces the token count with no learning and no scoring at all, because its measurement shows that the information a cache holds about a reasoning trace is duplicated enough that which tokens survive stops mattering once the prompt is protected. The contribution is therefore diagnostic rather than architectural: it reassigns credit for the reported gains of a whole family of scoring methods to a single confound, prompt retention, and it names the property of the data that makes the scoring redundant. That property is specific to DeepSeek-R1-style traces, which is why the result would not have been available before long RL-trained reasoning existed.

## Why Leo should care
This is a clean negative result that closes a method family, and the argument is measurement rather than assertion. It is also the cheapest available template for a similar test on sensor context: a 1 Hz physiological record over weeks is more redundant than a reasoning trace, so the learned patch-selection modules in current time-series and LLM pipelines are exactly the kind of component this experiment design would test.
