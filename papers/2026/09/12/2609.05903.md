# EvoSafeHarness: Evolving Model- and Domain-Specific Harnesses for Securing Agents

**Arxiv:** 2609.05903 | **Date:** 2026-09-12 | **Area:** agent

## What it does
Searches for a deployable safety harness rather than hand-writing one, jointly optimizing a natural-language policy and the executable code that enforces it at every tool call, with the underlying model frozen. A fresh-context adversarial review step rejects rules that only fit the benchmark. On DecodingTrust-Agent the average attack success rate falls from 45.6 percent to 10.0 percent at a cost of 3.3 utility points, winning 14 of 15 cells. On AgentDojo it reaches 82.8 percent utility at 0.0 percent attack success, twice CaMeL's utility at the same operating point, and transfers unchanged to the unseen AgentDyn suites. Mean attack success stays below 20 percent under adaptive PAIR attacks at a refinement budget of 16.

## Delta from parents
Where ToolkenGPT and ADaPT made the agent's capability adaptive, this paper makes the agent's constraint adaptive, and it does so at the same granularity — the tool call — because the enforcement point has to sit where the effect is produced. Where ADaPT decomposed a task according to executor competence, this decomposes a policy according to domain semantics, and the analysis separates the two axes explicitly: domain semantics determine which safety relations and trajectory state are needed, while model and runtime behaviour determine how and where those relations are enforced. Against the Memory Mechanisms survey, this is a consumer of trajectory state rather than a contributor to it. The work extends the graphify cross-area bridge `hao2024_toolkengpt` to `zhao2025_pyvision`, which already crossed learned tool invocation and agentic vision with dynamic tooling; the new work pushes that bridge into governance, adding a searched policy layer over the tool interface both endpoints assume is open.

## Why Leo should care
Two reasons, neither about agent safety as a research area. First, the co-search of a natural-language specification together with the code that enforces it is a general pattern for turning a written protocol into an executable check, which is directly reusable for data-quality and eligibility rules in sensing studies. Second, the safety-utility frontier framing with a stated utility cost of 3.3 points is the kind of reporting that reviewers of applied health-AI work increasingly ask for, and this paper is a clean template for it.
