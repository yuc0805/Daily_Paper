# Memory in Deep Time-Series Models

**Arxiv:** 2609.06006 | **Date:** 2026-09-09 | **Area:** time-series

## What it does
Argues that recurrent networks, transformers, structured state-space models, retrieval-augmented predictors, time-series foundation models and tool-using time-series agents are usually studied as separate architectural eras when they are better read as successive answers to one question: how does a time-series model retain and access information beyond its immediate input? The paper organizes existing methods on a spectrum from internal memory, held in parameters and fixed-size states, to external memory that is addressable, retrievable and increasingly maintained by an agent. It then reviews three classes of external memory, namely explicit modules, retrieval augmentation and agentic stores, under a common account of what is retained, how it is written and read, and how it persists, and maps each mechanism to the time-series tasks where it has been evaluated.

## Delta from parents
Where Zhang 2024 organized the field by interface, asking how a language model is bolted onto a series, this paper organizes it by state, asking what the model keeps and how it is addressed, because the interface taxonomy puts an SSM and a retrieval-augmented forecaster in unrelated boxes even though both are answering the same limitation. Where Huang 2026 built the retain, retrieve, revise and forget vocabulary for language agents operating over text, this paper applies that vocabulary to numeric temporal data and finds that the evaluation side is missing: the surveyed methods are compared on forecasting accuracy, not on whether their memory holds. Where TS-Agent demonstrated that an external agentic store helps on specific reasoning tasks, this paper places that result as one point on a continuum whose other end is HiPPO-style parameter memory, and asks what the intermediate positions cost. The framing is deliberately backbone-independent, which is the substantive claim: memory is presented as a design axis orthogonal to whether the model underneath is a transformer, an SSM or a foundation model. It is a survey, so there are no new numbers to weigh.

## Why Leo should care
This is a map of the area Leo works in, drawn along an axis that cuts across the collection he already holds, so it is worth reading for the taxonomy rather than for a result. It also identifies an evaluation gap directly: the memory mechanisms in this literature are scored on downstream forecasting error, and there is no benchmark that tests retention, revision or forgetting on their own. That gap is a concrete opening for someone in bio-sensing, where the relevant history is months of a person's own baseline rather than a long context window, and where a model that cannot revise a stale baseline fails in a way that forecasting error does not surface. On the ported/unported question, agentic memory for time series is being actively closed off, and this survey is the sign that the closing is underway.
