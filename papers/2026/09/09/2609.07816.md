# Kalman Delta Networks: Uncertainty-aware Associative Memory

**Arxiv:** 2609.07816 | **Date:** 2026-09-09 | **Area:** mamba

## What it does
Reformulates the fixed-size recurrent memory of linear attention as a linear-Gaussian state-space model and uses the Kalman filter as the write rule. The transition propagates both the memory state and its covariance, so the Kalman gain weights each residual write by accumulated evidence and observation reliability rather than by the current token alone. Delta-rule updates fall out as the special case that substitutes a token-wise isotropic surrogate for the predictive covariance and omits covariance tracking. Because exact tracking requires a dense state-dependent Riccati recursion that does not parallelize, the paper introduces Diagonal KDN and Isotropic KDN, whose uncertainty recurrences are Mobius maps and therefore still run as associative scans with logarithmic parallel depth.

## Direct parents (in Leo's library)
- [JPKDWV2Q] Mamba-2 (Dao 2024) — established the state-space duality that writes a linear-attention layer and a structured SSM as the same recurrence, which is the identification KDN starts from.
- [5YQ4IKMA] HiPPO (Gu 2020) — framed fixed-size recurrent state as optimal online compression of history under a fixed measure, giving the idea of a principled rather than heuristic write rule.
- [PHB9VRVM] Attention Is All You Need (Vaswani 2017) — the softmax attention baseline whose unbounded KV cache linear attention replaces with the bounded state that KDN is trying to manage well.

## Delta from parents
Where Mamba-2 showed that linear attention and SSMs share one recurrence and then spent its effort making that recurrence fast on GPUs, KDN asks what the recurrence should be estimating and answers with the Kalman filter, because a linear-Gaussian state-space model has a known optimal recursive estimator and linear attention had simply not been using it. Where HiPPO fixed the compression measure in advance and derived a static transition from it, KDN lets the effective write strength move with a tracked covariance, so the same token produces a large update when the memory is uncertain and a small one when it is already well determined. Where delta-rule models learn write strength from the current token embedding, KDN shows that this is exactly its own update under an isotropic surrogate, and that carrying even a diagonal covariance beats it. The engineering contribution is as large as the reformulation: the exact Riccati recursion is unusable in a parallel scan, so the two approximations that preserve associativity are what make the idea trainable at scale. Reported result: across controlled pretraining at 750M and 1.3B parameters, KDN variants consistently improve perplexity and mean downstream accuracy over state-of-the-art linear-attention models.

## Why Leo should care
This puts a Kalman filter inside a sequence-model layer, so the estimator Leo already knows from classical time-series work becomes the write rule of a modern backbone. The import direction is the reverse of the usual pattern, moving from signal processing into language modeling rather than from CV or NLP into time series, which means the porting opportunity runs backwards from what the gap watch normally tracks. Nothing in his library applies uncertainty-tracked associative memory to physiological streams, and physiological streams are where the modeling assumption actually holds, since motion artifact on PPG and ECG produces genuinely heteroscedastic observation noise that a Kalman gain would downweight without being told to. That method is not closed off as low-hanging fruit; it has not been picked.
