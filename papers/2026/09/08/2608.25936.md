# One Symptom, Three Levers: A Critical Review of On-Policy Self-Distillation

**Arxiv:** 2608.25936 | **Date:** 2026-09-08 | **Area:** reasoning

## What it does
This is a review with no new experiments. It defines on-policy self-distillation as the case where the teacher is the model itself conditioned on privileged information the student will not have at test time, such as a reference solution, a plan, or environment feedback, so the teacher is no stronger than the student and only better informed. It argues that one failure mode, the progressive narrowing of the set of reasoning paths the model can produce, dominates the field, and organises the literature around three levers that govern it: how tokens are weighted, what the teacher is shown, and how the guidance changes over training. Scope is restricted to mathematical reasoning.

## Delta from parents
Where DeepSeek-R1 answered the question of how to get reasoning at all, this review takes the answer as settled and asks what the cheaper substitutes cost, which is a maturity signal about the subfield rather than a new capability. Where RISE proposed one specific self-teacher and reported wins on math, code and agentic tasks, this review names the failure mode that any such self-teacher inherits and separates the settled claims from the disputed ones, so RISE can be read as one setting of the three levers rather than as a standalone method. The review makes explicit a cross-area bridge already in the graph: DeepSeek-R1 and Chain-of-Thought are linked as reasoning-via-reinforcement-learning against reasoning-via-prompting, and self-distillation sits between them, using a prompted teacher to supply the dense signal that reinforcement learning does not.
