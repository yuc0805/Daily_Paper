# Recursive Code World Models: Building Complex Worlds through Recursive Scene Programs

**Arxiv:** 2609.11499 | **Date:** 2026-09-13 | **Area:** agent

## What it does
RCWM reconstructs a complex 3D world as executable code from a single reference image. A Recursive Scene Program holds the world as compositional scene code, and a construction solver calls itself: establish the whole, recursively reconstruct unresolved parts, then revisit the whole to fix composition. Reference-aligned views share one camera projection across recursion levels, and a vision-language coding agent compares the reference image against renders to decide whether to refine, descend, or return.

## Delta from parents
Where ADaPT recursed over a task plan and returned once subtasks succeeded, RCWM adds a mandatory return visit to the parent after the children are solved, because local refinement creates boundary and spatial-relation errors that only the parent scope can see. Where PyVision let an agent write throwaway tools per query, RCWM makes the program the artifact: the scene code is the world, so every refinement is an edit to a persistent, inspectable representation. Where Ha's World Models learned the simulator in latent weights, this line keeps the simulator in source code and pays for that with a construction problem, which is what the recursion solves. This extends the graphify cross-area bridge `hao2024_toolkengpt` to `zhao2025_pyvision`, which already crossed tool-using agents and vision; the new work pushes that bridge toward tool use that builds a persistent structured artifact rather than a per-query script.

## Why Leo should care
The transferable piece is the global-local-global control structure, not the 3D reconstruction. Any hierarchical signal decomposition has the same failure: refine a segment in isolation and the boundaries with its neighbours stop agreeing. A mandatory parent revisit after child refinement is a cheap, testable addition to segmentation and change-point pipelines. The caveat is that the paper reports comparative wins and ablations without headline numbers in the abstract, so the size of the effect needs the full text.
