# When Quantization Breaks Memory: Recurrent-State Write-Back in Low-Precision Temporal Inference

**Arxiv:** 2609.04490 | **Date:** 2026-09-07 | **Area:** time-series

## What it does
In a recurrent network the hidden state is written to memory at each step and read back at the next one, so the rule used to store it becomes part of the computation. The authors name this rule the recurrent-state write-back and isolate it in a GRU encoder-decoder that estimates two fluorescence lifetime parameters from high-noise time-resolved optical signals. Holding the trained model fixed and replacing continuous state propagation with deterministic 4-bit state storage raises the error on the short-lived component by roughly 70x and on the long-lived component by roughly 300x. The failure mode is that repeated small updates each fall below the write threshold, so the stored state stays nearly frozen while the network continues to propose change. Error feedback, residual memory and direction memory each carry the suppressed updates forward and recover most of the accuracy with no retraining. A precision sweep shows that increasing state precision can make a fixed recurrent solution worse, and the same failure and rescue reproduce in an independently trained LSTM, where the cell state is more sensitive than the hidden state.

## Delta from parents
Where HARMamba and Mamba argued that a compact recurrent state is what makes long sensor sequences affordable at the edge, this paper measures what happens when that state is actually stored at edge precision, and finds a failure that is invisible in the usual quantization accounting. The distinction it introduces is between quantizing the arithmetic and quantizing the state interface: the first perturbs each computation independently, while the second couples across time, because a rounded state is the input to the next step. That coupling is why the errors reach 70x and 300x rather than the few percent a weight-and-activation quantization study would report. The result also inverts a standard assumption, since a model trained against a 4-bit interface degrades when the state is later stored more precisely, which means bit-width is not the right variable and compatibility between the learned dynamics and the storage rule is. Relative to the Gu 2025 survey, which names edge deployment as an open problem, this paper supplies a specific mechanism and three post-training fixes for it.

## Why Leo should care
Every wearable and bio-sensing pipeline in Leo's library that reaches for a recurrent or state-space encoder does so on an efficiency argument, and this paper shows the efficiency argument has an unpriced term. The measurement is cheap to repeat: freeze a trained HARMamba or Bi-Mamba+ checkpoint, quantize only the state write, and see whether accuracy on activity or physiological targets collapses the same way. If it does, the three interventions here transfer directly, because none of them requires retraining. This sits next to the Gated DeltaNet quantization result from 2026-09-05 in Leo's library, which found the opposite outcome for a different recurrence, and the pair together suggests the real question is whether the update rule forgets injected state noise or accumulates it. The imported method is error-feedback quantization from the optimizer and gradient-compression literature, applied to state storage rather than to weights or gradients, and it is not yet closed off for wearable time series.
