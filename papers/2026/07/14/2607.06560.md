# Vision as Unified Multimodal Generation (SenseNova-Vision)

**Arxiv:** 2607.06560 | **Date:** 2026-07-14 | **Area:** multi-modal

## What it does
SenseNova-Vision casts every computer-vision task as text-and-image generation inside one multimodal model, with no task-specific heads. Natural-language instructions plus optional visual prompts specify the task, the target region, and the output convention; the model emits text for symbolic answers, images for dense predictions, or a mix. The authors convert many vision datasets into instruction-response pairs (the SenseNova-Vision Corpus) and continue training an off-the-shelf unified model on it. One model covers detection, OCR, keypoints, segmentation, depth, surface normals, point maps, and camera pose, matching task-specialized systems across these groups.

## Direct parents (in Leo's library)
- [QTFCR4G9] DETR (Carion 2020) — removed hand-built detection components by casting detection as set prediction.
- [YJ9TK993] DiT (Peebles 2023) — showed a transformer can drive high-quality image generation.

## Delta from parents
Where DETR removed task-specific components for one task, detection, SenseNova-Vision removes task-specific heads for the whole vision stack by casting each task as generation. Where DiT proved a transformer could generate images well, this paper reuses that generation space as the output channel for dense visual predictions such as depth and segmentation. The contribution is the single generation formulation plus the instruction-response corpus that makes one model span symbolic and spatial tasks without architectural changes.

## Why Leo should care
The unified "task as generation" recipe is a template for building one model that answers many question types over an input, which is attractive for signal analysis where classification, segmentation, and description are usually separate models. Porting a generation-space formulation to time-series or biosignals (one model that outputs a label, a segmented window, or a text summary on instruction) is not present in your library, so it is an open direction.
