# Light-Omni: Reflex over Reasoning in Agentic Video Understanding with Long-Term Memory

**Arxiv:** 2607.05511 | **Date:** 2026-07-14 | **Area:** multi-modal

## What it does
Light-Omni is a multimodal agent for long video streams that answers reflexively instead of through slow iterative reasoning. It keeps two states built in a single forward pass: a global state, a fixed-size multimodal script consolidated from episodic memory by hierarchical merging (recent detail kept, old events summarized), and a parametric latent state, conditioned on the global context, that drives actions and produces retrieval embeddings. This gives aligned retrieval and reflexive answers without search-then-aggregate loops. Against M3-Agent it reports a 2.4% average accuracy gain, a 12.1x speedup, and 2.6x better GPU memory use, with near-constant ~2.3s latency regardless of video length, and it also serves as a plug-in memory system for existing multimodal LLMs.

## Delta from parents
Where the Memory Mechanisms Survey laid out the space of agent memory designs, Light-Omni commits to one concrete design, a consolidated global script plus a latent action state, and shows it removes the need for iterative search. Where the Video Action Survey covered short-clip classification, Light-Omni handles hour-scale streams by summarizing them into a bounded state, because fixed-size memory is what keeps latency flat as the video grows. The contribution is the coupled global-plus-latent state that turns memory into a single-pass reflex.

## Why Leo should care
A bounded, continuously consolidated state that answers in near-constant time regardless of stream length is exactly the shape a wearable monitoring agent would need over continuous physiological data. No wearable-sensing entry in your library keeps such a consolidated health state, so this dual-state memory design is an unported opportunity for Community 5.
