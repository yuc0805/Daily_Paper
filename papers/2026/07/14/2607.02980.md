# Hierarchical Sparse Attention Done Right: Toward Infinite Context Modeling (HiLS-Attention)

**Arxiv:** 2607.02980 | **Date:** 2026-07-14 | **Area:** llm

## What it does
HiLS-Attention is a chunk-wise sparse attention that learns which chunks of the past to read directly from the language-modeling loss. Each query attends to each retrieved chunk on its own, and the per-chunk outputs are fused using retrieval scores that sit inside the forward attention, so the scores get gradients and the retrieval is trained end to end. At in-domain lengths it matches full attention, and it extrapolates to more than 64 times the training context length while keeping 90% retrieval accuracy. An existing full-attention model can be converted with light continued pretraining (about 50B tokens in the 7B release).

## Direct parents (in Leo's library)
- [PHB9VRVM] Attention Is All You Need (Vaswani 2017) — established dense self-attention where every token attends to every other token at quadratic cost.
- [QBX2TI2X] iTransformer (time-series) — nearest time-series neighbor; re-applied attention across variables rather than across time.

## Delta from parents
Where the Transformer made attention dense and quadratic, HiLS keeps the same attention operator but routes each query to a small set of learned chunks, because the quadratic cost is exactly what blocks long context. The novelty against earlier sparse-attention work is that the chunk retrieval scores enter the forward pass and are optimized by the language-modeling loss, rather than chosen by a fixed heuristic. Relative to iTransformer, which turned attention onto the variable axis to help forecasting, HiLS attacks the time axis directly, which is the axis that grows without bound in long recordings.

## Why Leo should care
Long biosignal recordings are the setting where dense attention runs out of memory and compute. A method that learns sparse chunk selection over the time axis, reaches 64 times the training length, and keeps sparse key-value access is a direct candidate to port into wearable foundation models. This transfer is not yet done in Communities 4 and 5, so learned sparse long-context attention over physiological signals is an open opportunity, not closed-off low-hanging fruit.
