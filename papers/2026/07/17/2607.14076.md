# From Pixels to States: Rethinking Interactive World Models as Game Engines

**Arxiv:** 2607.14076 | **Date:** 2026-07-17 | **Area:** world-model-rl

## What it does
This paper reviews interactive world models through the lens of a conventional game engine, which runs a recurrent action-state-observation loop where player actions update an explicit game state by fixed rules and observations are rendered from that state. It organizes existing methods along four axes: player action control, game state dynamics, state-observation persistence, and real-time generation, and discusses the trade-offs of each family. It also releases a data engine for Black Myth: Wukong with over 90 hours of gameplay carrying frame-aligned player actions, ground-truth game states, and observations, meant as a resource for state-aware world modeling.

## Delta from parents
Where the original World Models learn an implicit latent recurrent state and recent video generative world models predict pixels directly from actions, this paper argues that neither keeps an explicit, rule-following state that persists over long horizons, which is what makes a game world coherent. It reframes the target as the game engine's explicit action-state-observation loop and supplies a dataset with ground-truth states so models can be trained and measured against that structure rather than against pixel reconstruction alone. Parents sit in graphify Community 7 (Reinforcement Learning); the generative video backbone side connects to Community 3.

## Why Leo should care
The core argument, that predicting raw observations is not enough and an explicit persistent state matters, transfers to physiological signal simulation: a wearer's latent state (activity, stress, medication) could act as an explicit persistent state so a generator produces coherent multi-hour ECG or PPG under interventions instead of drifting sample by sample.
