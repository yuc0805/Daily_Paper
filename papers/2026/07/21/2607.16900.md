# Environment-free Synthetic Data Generation for API-Calling Agents

**Arxiv:** 2607.16900 | **Date:** 2026-07-21 | **Area:** agent

## What it does
Tool-calling agents are normally trained on trajectories that need a live executable environment: real APIs, real state, real errors. Standing up and maintaining that environment is the main bottleneck to scaling agent training data. This paper (Apple) generates synthetic tool-call training data without a live environment, so the API surface and its responses are produced by the data pipeline itself rather than by executing real services. The payoff is a cheaper path to large, diverse API-calling datasets, most useful for the long tail of tools that have no public sandbox.

## Delta from parents
Where ToolkenGPT assumed tools you can actually call to gather supervision, this paper removes the live environment and synthesizes the call-and-response supervision directly, because the environment, not the model, is what does not scale. Against ADaPT, which decomposed tasks assuming an executable setting, this work supplies training data for such planners without needing the setting to exist.

## Why Leo should care
Peripheral to time-series, but the environment-free data-generation idea transfers: bio-sensing agents that call analysis tools (peak detection, spectral transforms, classifiers) also lack cheap executable environments for training, and synthesizing tool-call supervision could bootstrap a signal-analysis agent. That transfer is not yet done.
