# Group Entropy-Controlled Policy Optimization (GEPO)

**Arxiv:** 2607.16850 | **Date:** 2026-07-21 | **Area:** reasoning

## What it does
GEPO is a lightweight extension of GRPO for reasoning RL. It notes that RL fine-tuning runs on mixtures of tasks in different entropy regimes under the same policy, so one global or token-level entropy control does not fit all of them, and GRPO's normalized advantages carry an entropy-dependent bias that makes advantage signals across prompt groups not comparable. GEPO estimates per-group entropy from existing grouped samples and shapes advantages asymmetrically: it damps positive advantages in low-entropy groups to reduce over-exploitation and damps negative advantages in high-entropy groups to preserve exploration. The extra cost is small because the entropy estimate reuses rollouts already drawn.

## Delta from parents
Where DeepSeek-R1 applied one reward-normalization scheme uniformly across all prompts, GEPO conditions the advantage shaping on each group's entropy, because a single normalization treats an easy low-entropy prompt and a hard high-entropy prompt as if they need the same exploration pressure. This is the same "one reward is too blunt" critique that role-aware GRPO variants raise, applied to entropy rather than to perception-versus-reasoning roles.

## Why Leo should care
Not a time-series paper, but the mechanism is portable. Per-group entropy shaping is a candidate fix for RL fine-tuning of time-series reasoning agents, where task difficulty and sequence length (as HEARTS shows) produce exactly the heterogeneous-entropy regimes GEPO is built for. That transfer to TS/bio is not yet done, so it is an open opportunity.
