# Extending LLM Context via Associative Recurrent Memory

**Arxiv:** 2607.11614 | **Date:** 2026-07-15 | **Area:** llm

## What it does
The paper gives a training recipe for extending the usable context of a language model using an associative recurrent memory transformer. It combines continued pre-training, synthetic long-context data, curriculum learning, and selective placement of associative memory into chosen layers rather than all of them. The claim is that the augmented model processes inputs well past its original context limit while keeping the added memory machinery in only a few layers.

## Delta from parents
Where the Transformer keeps all information inside a fixed-length attention window, this paper adds a recurrent associative memory that carries a compressed state across segments, so the effective context grows without full quadratic attention over everything. Where the memory survey catalogued mechanisms, this work commits to one and supplies the training curriculum that makes it hold up past the original limit, because placement (only certain layers) and data curriculum turn out to matter more than adding memory everywhere.
