# SIRI: Self-Internalizing Reinforcement Learning with Intrinsic Skills for LLM Agent Training

**Arxiv:** 2606.02355 | **Date:** 2026-07-15 | **Area:** agent

## What it does
SIRI is a three-phase reinforcement-learning method that lets a long-horizon agent discover, validate, and absorb reusable skills without any external skill generator and without a skill bank at inference time. It first warms up the policy to collect successful skill-free trajectories, then has the current policy summarize compact skills from its own successful rollouts and check them by comparing skill-augmented against skill-free runs, and finally distills only the skill-guided action tokens that help back into the plain policy. The result is an agent that keeps the benefit of skills while paying no extra context length or retrieval latency at deployment.

## Delta from parents
Where DeepSeek-R1 used RL to make a model produce long reasoning traces, SIRI uses RL to make a model mine and internalize its own skills, then removes those skills from the runtime so nothing extra is carried at inference. Where ADaPT relied on an external decomposition module to structure a task, SIRI has the policy summarize and validate skills from its own successful trajectories, because that removes the engineering cost and the dependence on a separate generator. This paper sits next to the deepseek2025_r1 to wei2023_cot bridge in your library, which already contrasted reasoning-via-RL against reasoning-via-prompting; SIRI pushes the RL side further, from eliciting reasoning to compressing and reusing procedural skill.

## Why Leo should care
The interesting move is the self-mining loop: the agent proposes skills, tests them against its own skill-free baseline, and keeps only the tokens with measured utility. That is a general recipe for turning transient in-context tricks into weights, and it is relevant to any agentic pipeline where inference latency and context budget matter.
