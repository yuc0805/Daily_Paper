# SearchOS-V1: Towards Robust Open-Domain Information-Seeking Agent Collaboration

**Arxiv:** 2607.15257 | **Date:** 2026-07-18 | **Area:** agent

## What it does
SearchOS is a multi-agent framework for open-domain information seeking that turns implicit search progress into explicit, persistent, shared state. It reframes the task as relational schema completion with grounded citations and externalizes the working state into four structures: a Frontier Task, an Evidence Graph, a Coverage Map, and a Failure Memory. A pipeline-parallel scheduler overlaps sub-agents and refills freed slots with tasks aimed at uncovered gaps, and a middleware harness records grounded evidence and reacts to stalls or budget exhaustion.

## Delta from parents
Where ADaPT decomposes a task on demand and LATS searches a tree of actions at inference time, SearchOS moves the hard part out of the reasoning trace and into persistent external state, because the failure mode it targets is loss of progress in a growing context window rather than weak planning. Where the memory-agent line keeps a running store to help a single agent remember, SearchOS makes that store shared and structured (Evidence Graph plus Failure Memory) so several sub-agents coordinate coverage without repeating each other's dead ends. The parents improved how an agent thinks; this paper improves what an agent writes down and shares.

## Why Leo should care
The reusable idea is the pairing of a Coverage Map with a Failure Memory: a compact external record of what remains uncovered and what has already been tried and failed. That pattern maps onto sensor-labeling and physiological-analysis agents, where an agent examining ambiguous windows could keep an explicit map of unresolved windows and failed feature extractors rather than re-deriving that state from a long transcript. This is a control-and-memory idea imported from multi-agent search; it is not yet applied to bio-sensing.
