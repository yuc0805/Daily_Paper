# RoboTTT: Context Scaling for Robot Policies

**Arxiv:** 2607.15275 | **Date:** 2026-07-18 | **Area:** test-time-training

## What it does
RoboTTT scales the visuomotor context of a robot policy to 8,000 timesteps without raising inference latency, by putting Test-Time Training inside a Vision-Language-Action policy. The recurrent state is a set of fast weights updated by gradient descent during both training and inference, so history is compressed into weight space rather than a growing token window. The training recipe combines sequence action forcing with truncated backpropagation through time.

## Direct parents (in Leo's library)
- [SFYVQXEG] Test-Time Training (TTT) — established adapting model weights at test time via a self-supervised objective.
- [2606.18043] Uncertainty Quantification for Flow-Based Vision-Language-Action Models — recent VLA policy work in the library.

## Delta from parents
Where standard TTT adapts a model to a single test instance with one or a few gradient steps, RoboTTT uses the same fast-weight update as the policy's working memory across thousands of steps, because a long-horizon robot needs to remember minutes of interaction rather than adapt once. It reports an 87% overall gain over a single-step baseline, completes a five-minute ten-stage assembly task that no baseline finishes, and shows an 8K-context model beating a 1K-context version by 62%, arguing context length is a new scaling axis.

## Why Leo should care
This is the clearest demonstration in his library that TTT fast weights can act as a scalable recurrent memory rather than a one-shot adaptation trick. It imported the TTT method into long-horizon control. The open transfer to bio-sensing: a wearable foundation model could hold multi-day sensor history in fast weights at constant inference cost, a direct answer to the long-context problem in continuous monitoring. That transfer is not yet closed off.
