# DSpark: Confidence-Scheduled Speculative Decoding with Semi-Autoregressive Generation

**Arxiv:** 2607.05147 | **Date:** 2026-07-13 | **Area:** llm

## What it does
DSpark is a speculative-decoding framework for high-concurrency serving. It adds a lightweight sequential module on top of a parallel drafter so drafted blocks carry within-block dependencies, reducing acceptance decay, and it schedules verification length per request from estimated prefix-survival probabilities so it does not waste compute verifying tokens likely to be rejected. Inside DeepSeek-V4's serving system it accelerates per-user generation by 60 to 85 percent at matched throughput versus the multi-token-prediction baseline.

## Delta from parents
Where DeepSeek-V3's multi-token prediction drafts several tokens in parallel but loses acceptance on later tokens, DSpark restores within-block dependency with a small sequential head and adds load-aware verification scheduling, because the bottleneck in high-concurrency serving is wasted verification, not draft speed. The change is at the serving-systems layer rather than the model-quality layer.
