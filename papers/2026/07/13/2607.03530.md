# MentalThink: Shaping Thoughts in Mental SVG World

**Arxiv:** 2607.03530 | **Date:** 2026-07-13 | **Area:** reasoning (also multi-modal)

## What it does
MentalThink lets a multimodal language model reason with an executable drawing surface instead of text alone. The model writes Scalable Vector Graphics (SVG) code as an intermediate reasoning step, renders it deterministically to an image, reads that image back, and revises the code over several turns. Training uses supervised fine-tuning for SVG syntax followed by multi-turn reinforcement learning that rewards useful inspection and revision. It reports 55.1% on VSIBench and 76.0% on MindCube.

## Delta from parents
Where Chain-of-Thought externalizes reasoning as text tokens, and DeepSeek-R1 uses reinforcement learning to reward correct final answers, MentalThink externalizes each reasoning step as executable SVG that is rendered and inspected, and rewards good revision of that drawing, because a rendered sketch is a checkable intermediate that text is not. It extends the graphify cross_area_bridge deepseek2025_r1 to wei2023_cot (reasoning-via-reinforcement-learning versus reasoning-via-prompting): the reinforcement-learning outer loop stays, but the textual thought becomes a visual, executable one.

## Why Leo should care
The transferable idea is a verifiable intermediate representation. For time-series or bio-sensing, an agent could draw a candidate waveform or segmentation, render it, and compare against the true signal. Imported method: executable-sketch reasoning from multimodal reasoning; not yet ported to Community 4 (Time Series + LLM), so the opportunity is open.
