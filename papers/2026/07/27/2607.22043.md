# Scaling Native Multimodal Pre-Training From Scratch

**Arxiv:** 2607.22043 | **Date:** 2026-07-27 | **Area:** multi-modal

## What it does
This paper studies how to scale a vision-language model that is trained from scratch on mixed image and text inputs, rather than bolting a vision encoder onto a finished language model. Under a fixed compute budget it measures the model size and token count that minimize loss, and finds that the best loss follows a predictable compute law while the compute-optimal model size and token count follow power laws. Language and multimodal objectives scale differently: the language allocation is nearly unchanged by how much multimodal data is in the mix, while the multimodal allocation is sensitive to it, so text-heavy mixtures only become efficient at larger model sizes. The authors derive an efficiency frontier that fixes model size, token count, and data mixture together, and report that native pretraining transfers positively into pure-text spatial reasoning.

## Delta from parents
Where Flamingo attached vision to a frozen or separately trained language model through late fusion, this paper trains both modalities together from the start and measures what that changes at scale. Where the transformer paper set the architecture, this work supplies the scaling recipe specific to mixed-modality training, showing that language and multimodal objectives do not share one allocation rule. The delta is a set of compute laws that tell you how to split parameters, tokens, and data mixture, which late-fusion work did not provide.
