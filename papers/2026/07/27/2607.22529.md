# Skill Self-Play: Pushing the Frontier of LLM Capability with Co-Evolving Skills

**Arxiv:** 2607.22529 | **Date:** 2026-07-27 | **Area:** reasoning

## What it does
This paper trains a language model to improve itself through self-play, using agent skills as the unit of practice. It sets up three parts that co-evolve in a reinforcement learning loop: a proposer that writes tasks conditioned on a sampled skill, a solver that tries to answer them and pushes its own limit, and a skill controller that reads execution feedback and updates or grows a skill library. Each skill gives a narrow scenario with checkable execution, while routing across many skills keeps the task set varied. On tool-use and reasoning benchmarks the method raises the ceiling of strong backbones and recovers models that started out misaligned.

## Delta from parents
Where DeepSeek-R1 trained reasoning against a fixed pool of verifiable problems, this paper makes the problem set itself a moving target: a proposer generates new tasks conditioned on skills, so the training distribution grows with the model. Where Chain-of-Thought fixed the reasoning format at inference time, Skill Self-Play moves the structure into training and lets a skill library expand over time. The core claim is that a skill is a useful middle ground between an environment with precise but narrow rewards and open-ended self-generation with unreliable rewards, because each skill keeps verification local while routing keeps variety global.
