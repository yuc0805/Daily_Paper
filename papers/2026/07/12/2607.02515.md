# PointDiT: Pixel-Space Diffusion for Monocular Geometry Estimation

**Arxiv:** 2607.02515 | **Date:** 2026-07-12 | **Area:** generative-cv (Community 3: Vision-Language & Generative)

## What it does
Estimates 3D geometry from a single image with a plain diffusion transformer that works directly in pixel and point-map space rather than a compressed latent space. The model is a plain ViT diffusion transformer that denoises raw 3D point-map patches conditioned on image tokens from a pretrained DINOv3 encoder, trained from scratch with no point-map tokenizer. Despite dropping the hybrid architectures and custom loss functions common in single-image reconstruction, it reports sharper geometry than latent-diffusion baselines and better behavior in ambiguous regions such as transparent objects.

## Direct parents (in Leo's library)
- [YJ9TK993] DiT — the diffusion transformer that replaced the U-Net denoiser with a plain transformer; PointDiT is a DiT applied to point maps.
- [GX7WR7KA] DDPM — the denoising diffusion framework that defines the training objective used here.
- [B7F2Q998] ViT — the plain vision transformer backbone the model keeps unchanged.

## Delta from parents
Where DiT and latent-diffusion methods compress images into a learned latent to make diffusion cheap, PointDiT argues the compression is unnecessary for geometry and denoises raw point-map patches in pixel space, because the latent tokenizer costs training complexity and can blur sharp structure. Where DDPM and DiT targeted image synthesis, this work retargets the same denoiser to a dense geometric-prediction task and conditions it on self-supervised DINOv3 features rather than class labels or text. The claim is that a minimalist pixel-space setup beats the more elaborate latent pipelines it descends from.

## Why Leo should care
The reusable idea is that dropping the latent tokenizer and denoising in the native signal space can improve a dense prediction task while simplifying the model. For bio-signal reconstruction and imputation, this is a testable transfer: run diffusion directly on raw waveform patches conditioned on a self-supervised encoder, instead of first learning a signal tokenizer. It is a secondary-area watch for Leo rather than a primary result.
