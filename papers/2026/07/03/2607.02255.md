# AgenticSTS: A Bounded-Memory Testbed for Long-Horizon LLM Agents

**Arxiv:** 2607.02255 | **Date:** 2026-07-03 | **Area:** agent

## What it does
AgenticSTS studies how memory should be given to a long-horizon LLM agent. The common approach appends every past observation, tool call, and reflection to the prompt, which grows without bound and mixes everything together so the effect of any single memory piece cannot be isolated. The authors propose a bounded contract: each decision starts from a fresh prompt assembled by typed retrieval, with no raw transcript appended, so the prompt stays a fixed size and each memory layer can be turned off on its own. They test this inside Slay the Spire 2, a stochastic deck-building game that needs hundreds of decisions per run, and release 298 tagged trajectories as a reusable testbed.

## Delta from parents
Where the Memory Mechanisms Survey catalogs memory designs but does not measure them under one controlled setup, AgenticSTS builds a harness where each memory layer can be ablated in isolation. Where LATS and ADaPT grow or branch their context as the task proceeds, AgenticSTS keeps the prompt bounded by rebuilding it through typed retrieval each step. The headline effect is modest and openly reported: adding a triggered skill layer moves wins from 3/10 to 6/10, which the authors call directional rather than decisive at that sample size (Fisher exact p about 0.37).

## Why Leo should care
The bounded-contract idea, keeping a fixed-size prompt built by typed retrieval instead of an ever-growing transcript, is directly relevant to any agent that reasons over long streams, including sensor and time-series agents. The paper is also a good model of careful evaluation: it reports the small sample size and the weak significance rather than overselling.
