# AutoTrainess: Teaching Language Models to Improve Language Models Autonomously

**Arxiv:** 2606.31551 | **Date:** 2026-07-02 | **Area:** agent

## What it does
AutoTrainess is a language-model agent for autonomous post-training. It exposes the operations of a training pipeline (planning, data preparation, training, evaluation, logging) as explicit agent-computer interfaces with workflows, rules, and execution constraints, instead of leaving the agent in a raw command-line environment. On PostTrainBench it scores 26.94 on average with GPT-5.4 (Codex) versus 23.21 for a command-line-only baseline, and lifts DeepSeek-V4-Flash (OpenCode) from 12.13 to 19.58.

## Delta from parents
ADaPT and LATS are the planning-decomposition bridge already recorded in Leo's library. Where ADaPT decomposed a task on demand and LATS searched over action trees, AutoTrainess fixes the action space ahead of time by wrapping the training pipeline in named interfaces, because a multi-hour training run needs reliable, repeatable operations more than open-ended search. Relative to ToolkenGPT's atomic tool calls, it drives a full long-horizon workflow with preserved experiment state.

## Why Leo should care
This is the agent line moving from short tool-use to running whole training experiments. For Leo the useful transfer is the interface idea: wrapping a fiddly experimental pipeline (for example, wearable-signal preprocessing, pretraining, and evaluation) in named, constrained operations so an agent can run and iterate it reliably.
