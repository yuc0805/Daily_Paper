# AtomiMed: Hierarchical Atomic Fact-Checking for Universal Clinical-Aware Medical Report Evaluation

**Arxiv:** 2606.31292 | **Date:** 2026-07-02 | **Area:** llm-health (bridge: hallucination)

## What it does
AtomiMed is an evaluation framework for generated medical reports. It decomposes a report into a hierarchy of atomic clinical facts (disease-level entities and attribute-level descriptors such as location, morphology, severity) and runs an agentic cross-verification loop between the ground-truth and predicted reports, imitating a multi-radiologist peer review. This separates detection accuracy from descriptive accuracy. The authors release MRGEvalKit for hierarchical extraction and OmniMRG-Bench covering X-ray, CT, MRI, and ultrasound; AtomiMed correlates with radiologist judgment better than n-gram and model-based metrics.

## Delta from parents
Where Med-VQA Hallucination measured hallucination on question answering, AtomiMed turns fact-level checking into an evaluation metric for full report generation, decomposing the report into atomic facts and verifying each, because a report-level overlap score cannot localize which specific claim is wrong. Relative to Verifiable Physio Reasoning, which pushed verifiability on the generation side, AtomiMed applies the same "make each claim checkable" principle to the evaluation side.

## Why Leo should care
It is in the LLM-Health area Leo tracks, and it offers a reusable idea for evaluating any structured clinical output: break the output into atomic, separately checkable claims and score detection and description apart. That pattern could apply to evaluating reports or summaries generated from physiological signals, not only imaging.
