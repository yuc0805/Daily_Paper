# SEED: Self-Evolving On-Policy Distillation for Agentic Reinforcement Learning

**Arxiv:** 2607.14777 | **Date:** 2026-07-19 | **Area:** agent

## What it does
SEED trains an LLM agent for long-horizon, multi-turn, tool-using tasks. It keeps outcome-based reinforcement learning but adds a self-distillation loop: one policy checkpoint acts in the environment, then reads back its own completed trajectories, writes short natural-language skills (reusable workflows, decisive observations, failure-avoidance rules), and distills the skill-induced change in action probabilities back into the plain policy. Teacher and student are the same evolving model, so the process improves itself without a fixed stronger teacher.

## Direct parents (in Leo's library)
- [Z5IWHZAE] DeepSeek-R1 — showed strong reasoning can emerge from outcome-based RL with a sparse final reward.
- [HBLPTRMY] Chain-of-Thought Prompting — established intermediate step-by-step reasoning inside a single forward pass.
- [BDY3HUCV] Memory Mechanisms Survey — catalogued how foundation agents store and reuse past experience.

## Delta from parents
Where DeepSeek-R1 optimized only against a sparse trajectory-level reward, SEED keeps that reward but distills hindsight skills back into the weights, because the sparse signal leaves intermediate agent decisions unsupervised. Where Chain-of-Thought produced reasoning as ephemeral text regenerated each run, SEED writes the useful part of a trajectory into an explicit skill and folds it into the policy, so the lesson persists. Where the Memory Mechanisms Survey stored experience in external retrieval buffers, SEED moves that memory into the policy parameters through self-distillation. It therefore extends the DeepSeek-R1 to Chain-of-Thought bridge already in the library (reasoning-via-RL versus reasoning-via-prompting) toward reasoning-via-RL-plus-self-distillation.

## Why Leo should care
This is the current front of agentic RL, and the "trajectory to skill to distillation" idea transfers directly to time-series reasoning agents such as TS-Agent. It imports no method from CV; rather it opens a self-distillation route that time-series agents have not yet used, so that transfer is still open.
