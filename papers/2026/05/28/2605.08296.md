# BenchHAR: Benchmarking Self-Supervised Learning for Generalizable Sensor-based Activity Recognition

**Arxiv:** 2605.08296 | **Date:** 2026-05-08 | **Area:** time-series, self-supervised

## What it does
BenchHAR provides a unified framework for evaluating how well self-supervised learning methods generalize in sensor-based human activity recognition on unseen target distributions. It curates a large-scale dataset of roughly 258K samples and benchmarks eight representative SSL methods across 12 encoder-classifier architectures. The main findings are that hybrid pretraining (reconstruction plus contrastive) works best, CNN encoders learn the most generalizable representations, more expressive classifiers help, scaling unlabeled data from the same activity classes improves performance but adding data from non-downstream classes does not, and custom-grade device data generalizes better than research-grade.

## Delta from parents
Where Yuan 2024 focused on scaling up SSL for HAR and showed that more data helps, BenchHAR takes a step back and asks which SSL method and which architecture actually generalize best when the target distribution shifts. The finding that non-downstream-class unlabeled data does not help is a useful negative result that refines the scaling story from Yuan 2024: it is not just more data, but more of the right data that matters. The benchmark also provides the first systematic comparison of SSL paradigms (contrastive, reconstructive, hybrid) specifically for HAR generalization.
