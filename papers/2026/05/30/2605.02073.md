# Enhanced LLM Reasoning by Optimizing Reward Functions with Search-Driven Reinforcement Learning

**Arxiv:** 2605.02073 | **Date:** 2026-05-30 | **Area:** reasoning

## What it does
The paper treats the RL reward function, not the model, as the object to optimize for mathematical reasoning. A frontier model proposes candidate rewards; each is screened by a short 500-step GRPO run on a fixed Llama-3.2-3B-Instruct base with LoRA and ranked by F1 on GSM8K, with ranked feedback passed into the next round. The best reward ensemble reaches F1 = 0.795 versus 0.609 for a base-rewards-only baseline.

## Delta from parents
Where DeepSeek-R1 ran RL to change the policy and Chain-of-Thought changed the prompt, this paper freezes the policy and searches the reward function instead, because it argues the reward is the under-used design lever once the base model is fixed. It keeps R1's RL machinery but moves the optimization target up a level, and it shows the gain comes from the ranked-feedback search loop (a random 5-reward control collapses to F1 = 0.047), not from simply adding reward terms.

## Why Leo should care
This is a cheap, fixed-model lever for reasoning, which matters when porting reasoning into time-series and health agents where labels are scarce and full RL fine-tuning is costly. The imported method is automated reward search driven by a frontier model. That import is not yet present for time-series or biosignal reasoning, so it is an open transfer rather than closed low-hanging fruit.
