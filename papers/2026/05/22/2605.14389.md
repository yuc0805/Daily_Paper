# Nexus: An Agentic Framework for Time Series Forecasting

**Arxiv:** 2605.14389 | **Date:** 2026-05-14 | **Area:** time-series

## What it does
Nexus is a multi-agent framework that decomposes time series forecasting into specialized stages: isolating macro-level temporal fluctuations (trend, seasonality), micro-level residual patterns, and contextual information from unstructured text. A synthesis agent combines the outputs. Evaluated on post-cutoff Zillow and stock data, it matches or outperforms SOTA TSFMs and LLM baselines.

## Direct parents (in Leo's library)
- [xie2025_chatts] ChatTS (Xie 2025) — Established alignment between time series and LLMs via a unified token representation for TS reasoning.
- [liu2025_tsagent] TS-Agent (Liu 2025) — Introduced single-agent LLM reasoning over time series with tool-calling for analysis and forecasting.
- [zhang2024_llm_ts_survey] LLMs for Time Series Survey (Zhang 2024) — Cataloged methods and identified the gap between numerical pattern models and context-aware reasoning.

## Delta from parents
Where ChatTS aligned time series with LLMs through unified representation and TS-Agent used a single reasoning agent, Nexus splits the reasoning into multiple specialized agents that each handle one facet of prediction (trend, residual, context). This decomposition matters because the LLM TS Survey identified that monolithic prompting conflates numerical and contextual reasoning, and Nexus shows that separating these stages yields better accuracy than either TSFMs alone or single-agent LLM approaches.

## Why Leo should care
This is directly in the TS + LLM integration area (Community 4). The multi-agent decomposition pattern could transfer to biosignal forecasting where clinical context (medications, activity) matters alongside raw physiological signals. The import from NLP/agent architectures (ADaPT-style task decomposition) to TS is now done for forecasting specifically, but the same pattern has not been applied to TS classification or anomaly detection — those remain open.
