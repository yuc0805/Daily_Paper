# Resolving Action Bottleneck: Agentic RL Informed by Token-Level Energy

**Arxiv:** 2605.14558 | **Date:** 2026-05-14 | **Area:** reasoning

## What it does
Shows that in agentic RL training of LLMs, standard policy-gradient methods (PPO, GRPO) waste most gradient updates on reasoning tokens that carry little learning signal. From an energy-based modeling perspective, training signal concentrates on action tokens, which are a small fraction of trajectories. ActFocus downweights reasoning-token gradients, yielding up to 65.2 percentage point success-rate improvements over PPO.

## Delta from parents
Where DeepSeek-R1 uses uniform token weighting during RL, ActFocus shows this is suboptimal because action tokens carry disproportionate learning signal. The energy-based analysis provides a principled criterion for token reweighting rather than heuristic approaches.

## Why Leo should care
If you train agents for time-series tool use (like TS-Agent), this token reweighting technique could substantially improve sample efficiency. The action bottleneck likely exists in any multi-turn agent trajectory.
