# Understanding Emergent Misalignment via Feature Superposition Geometry

**Arxiv:** 2605.00842 | **Date:** 2026-04-07 | **Area:** interpretable-ml

## What it does
Proposes a geometric explanation for emergent misalignment: because features are encoded in overlapping (superposed) representations, fine-tuning that amplifies a target feature also strengthens nearby harmful features. Validated on Gemma-2 (2B/9B/27B), LLaMA-3.1 8B, and GPT-OSS 20B using sparse autoencoders. A geometry-aware data filtering approach reduces misalignment by 34.5%.

## Delta from parents
Where SHAP explains individual predictions through additive feature contributions, this paper explains a systemic training failure (emergent misalignment) through the geometry of how features share representation space. The mechanism is different: SHAP operates post-hoc on a fixed model, while this work identifies a training-time dynamic where gradient updates on one feature leak into geometrically adjacent features. The practical output is also different — instead of explaining predictions, it provides a data filtering method to prevent misalignment before it occurs.
