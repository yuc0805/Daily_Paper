# Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces

**Arxiv:** 2605.02801 | **Date:** 2026-05-04 | **Area:** agent

## What it does
Formalizes RL for LLM multi-agent systems by modeling interactions as orchestration traces: temporal interaction graphs with events including sub-agent spawning, delegation, communication, tool use, aggregation, and stopping decisions. Identifies eight reward families and decomposes orchestration into five sub-decisions. Gap analysis reveals no explicit RL training for the stopping decision.

## Direct parents (in Leo's library)
- [prasad2023_adapt] ADaPT (Prasad 2023) — established as-needed decomposition and planning for single LLM agents
- [zhou2024_lats] LATS (Zhou 2024) — introduced language agent tree search combining planning, acting, and reasoning

## Delta from parents
Where ADaPT and LATS decomposed planning and search for single agents, this paper lifts the decomposition to multi-agent orchestration. The new dimensions are inter-agent communication, delegation routing, and aggregation — none of which appear in single-agent decompositions. The identification of the stopping-decision gap (no RL method trains for when to stop spawning agents) is a concrete open problem.

## Why Leo should care
The orchestration formalism could apply to multi-agent pipelines for scientific data analysis. The stopping-decision gap is relevant if Leo builds agent pipelines for sensor data processing where knowing when to stop querying sub-agents matters.
