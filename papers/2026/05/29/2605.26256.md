# Personalizing Embodied Multimodal LLM Agents over Long-term User Interactions (POLAR)

**Arxiv:** 2605.26256 | **Date:** 2026-05-29 | **Area:** agent

## What it does
POLAR is a memory-augmented framework for embodied agents that serve the same user across many sessions. It organizes prior interactions into a multimodal knowledge graph that separates semantic memory (stable facts) from episodic memory (specific past events), and conditions the agent's actions on retrieved memory so behavior reflects the user's history.

## Delta from parents
Where the Memory Mechanisms Survey described the space of agent memory and the Agent AI Survey mapped multimodal interaction in general, POLAR commits to one structure: a semantic-versus-episodic knowledge graph tied to a single user over time. The reason is that durable personalization needs both stable facts and recallable events, which a single flat memory store does not separate.

## Why Leo should care
Long-term, per-user memory structure is relevant to any deployed health or sensing agent that must track one person over time. The semantic/episodic split is a transferable design choice for bio-sensing assistants.
