# Rethinking RL for LLM Reasoning: It is Sparse Policy Selection, Not Capability Learning

**Arxiv:** 2605.06241 | **Date:** 2026-05-29 | **Area:** reasoning

## What it does
Through token-level analysis across several model families and RL algorithms, the paper argues that reinforcement learning does not teach new reasoning strategies. Its effect is sparse: only 1 to 3 percent of token positions change, those positions sit at high-entropy decision points, and the promoted token is almost always already in the base model's top-5 candidates. RL therefore selects among solutions the base model already contains.

A graphify cross-area bridge links DeepSeek-R1 and Chain-of-Thought as "reasoning-via-RL versus prompting." This paper extends that bridge. Where DeepSeek-R1 read RL as creating reasoning capability and Chain-of-Thought obtained reasoning from prompting, this work measures the RL gain at the token level and finds it small and local, closer to choosing among branches the prompted base model could already reach. It also continues the recent debate (Beyond Reasoning, Can RL Teach Long-Horizon) from the mechanistic side.

## Why Leo should care
It reframes what RL post-training buys for reasoning and suggests a cheaper substitute (targeted correction at sparse uncertain points). For a time-series reasoning agent, the same idea transfers: correct the few high-uncertainty operator-selection steps instead of fine-tuning the whole controller.
