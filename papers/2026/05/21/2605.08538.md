# Human-Inspired Memory Architecture for LLM Agents

**Arxiv:** 2605.08538 | **Date:** 2026-05-08 | **Area:** agent

## What it does
This paper presents a biologically grounded memory architecture for LLM agents comprising six cognitive mechanisms: sleep-phase consolidation, interference-based forgetting, engram maturation, reconsolidation upon retrieval, entity knowledge graphs, and hybrid multi-cue retrieval. The architecture provides a structured alternative to typical retrieval-augmented or context-window approaches.

## Delta from parents
Where Huang 2026 surveyed memory mechanisms broadly and identified sleep consolidation and forgetting as promising directions, this paper implements them as concrete modules. Where LATS maintains search state within a single episode and ADaPT decomposes tasks on the fly, neither addresses persistent cross-episode memory. This paper fills that gap with a structured architecture that manages memory across long interaction horizons using principles from cognitive neuroscience.

## Why Leo should care
Agent memory architecture is relevant if you build LLM agents for scientific workflows or time-series analysis (e.g., TS-Agent style systems that accumulate evidence logs). Understanding how memory consolidation and forgetting work in agent systems could inform the design of evidence management in iterative analysis pipelines.
