# Compact Latent Manifold Translation: A Parameter-Efficient Foundation Model for Cross-Modal and Cross-Frequency Physiological Signal Synthesis

**Arxiv:** 2605.13248 | **Date:** 2026-05-13 | **Area:** time-series, llm-health

## What it does
CLMT is a 0.09B-parameter framework for translating between different physiological signal modalities (e.g., ECG to PPG, EEG to EMG) and across sampling frequencies. It uses a Universal Tokenizer with Hierarchical Residual Vector Quantization to project heterogeneous biosignals into discrete latent manifolds, then performs cross-modal translation in this shared latent space.

## Direct parents (in Leo's library)
- [gu2025_biosignals / graphify] Foundation Models for Biosignals (Gu 2025) — Survey identifying cross-modal alignment of heterogeneous biosignals as an open problem.
- [ELYUE3NF] Sensor2Text (Chen 2024) — Bridged sensor data and language; CLMT instead bridges sensor modalities directly without going through text.
- [HDPXBLAP] SensorLM — Large-scale sensor-language model; CLMT takes the opposite approach with a tiny model for signal-to-signal translation.

## Delta from parents
Where the Biosignals survey (Gu 2025) identified cross-modal physiological signal alignment as unsolved, CLMT provides a concrete solution using hierarchical residual VQ. Where Sensor2Text and SensorLM bridge sensors to language, CLMT bridges sensors to sensors, removing the text bottleneck when the downstream task does not need language. The parameter efficiency (0.09B) is notable given that SensorLM uses orders of magnitude more data and parameters.

## Why Leo should care
This is directly in the bio-sensing space. Cross-modal signal synthesis is useful when one modality is cheaper or less invasive to collect than another (e.g., PPG from a wristband vs. ECG from chest electrodes). The VQ-based approach imports ideas from audio/speech codecs (hierarchical residual quantization) into biosignal processing. This transfer from audio to biosignals is now executed.
